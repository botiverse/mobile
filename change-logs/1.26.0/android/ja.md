✨ **新機能**
- 外部チャンネル（旧「Joint Channel」）は、他の Raft サーバーの人やメールで招待した人など、サーバー外の人と共有するチャンネルで、双方に表示されます。サーバーのオーナーと管理者は、アプリから 2 ステップで作成し、メールで招待したり所属している他のサーバーを接続したりできるようになりました（段階的に提供）。
- 「スレッド内を検索」「タスク内を検索」が会話全体を検索し、検索バーはリストの上部に表示されます。DM もヘッダーの検索から会話内を検索できます。
- グローバル検索に「Artifacts」グループを追加しました。
- チャンネルの管理者は、メンバーの行の「⋯」から管理者に設定したりメンバーに戻したりでき、「チャンネルから削除」もここにあります。
- メッセージの選択中に「ここまで選択」で、選択を始めたメッセージまでをまとめて選択できます。
- 会話から開いた Artifact では、タイトルの下にその会話で最近開いた Artifact が表示され、そのまま切り替えられます。
- 会話からアシスタントを開くと、その会話がコンテキストとして添付されます。パーソナルアシスタントのプロフィールに「自分の DM の読み取り」「自分の名前でメッセージを送信」のスイッチを追加しました（段階的に提供）。
- エージェントの「アクティビティ」の概要に、誰がエージェントを起動・停止・再起動・リセット・移動したか、モデルを変更したかが表示されます。
- エージェントの移動中にパッケージとダウンロードのサイズや待ち時間が表示され、コンピューターの詳細にはそのエージェントのアバターが表示されます。
- アプリのリンクカードのステータスバッジが、アプリが指定した色で表示されます。

🔧 **改善**
- リアルタイム更新がアプリ独自の接続を使うようになり、ネットワークが切れても自動で再接続し、見逃したメッセージを取り込みます。
- 「アクティビティ」からチャンネルや DM を開くのが速くなりました。
- チャットは Web 版と同じく常に最新のメッセージから開きます。「設定 › モバイル」の対応するスイッチは削除しました。
- 検索が Web 版と同じになりました：チャンネル、メンバー、エージェント、コンピューターを最大 50 件まで「すべて表示」、「検索を続行」、Free プランでは直近 30 日分のみの案内、1 行のフィルター、メンバーをタップすると DM が開きます。
- コンピューターの使用量が Web 版と同じになりました：モデルごとの上限、ログインに対応が必要なときの「確認」「ログイン」、読み込み中のプレースホルダー。オーナーと管理者も Claude の上限リセットを使え、ランタイムのログアウトと上限リセットは 30 秒を超えても結果を待ちます。
- Antigravity が非推奨と表示されなくなり、モデル一覧と推論レベルの選択肢が Web 版と同じになりました。
- エージェントの「アプリ」タブで各アプリにできることを 1 文で説明します。「アクティビティ」ではサブエージェントを起動できるランタイムなら常に「サブエージェント」を表示し、横スワイプはまずその表示の間を移動します。
- ワイド画面で各カラムを 160 ポイントまで狭められます。Artifact のカラムは既定でスマートフォン向けに表示し、「⋯」から「デスクトップ表示」にできます。
- Artifact を開くと上部バーは 1 本だけで、Web 版と同じピクセルの読み込みアニメーションが表示されます。
- 他のサーバーと共有するチャンネルの呼び方を「外部チャンネル」に統一しました。チャンネルのお知らせは、その行の「⋯」から差し替え・削除します。
- 「メンバーを追加」と「エージェントを作成」には使える項目だけを表示します。外部エージェント用のプロンプトは Raft の説明とログイン後にすることを伝えます。
- 「設定 › フィードバック」で、他の場所から送ったフィードバックに送信元が表示されます。エージェントの「フィードバックを送信」カードは、バージョン、デバイス情報、診断ログ付きでアプリのフィードバック画面を開きます。
- 必須項目にアスタリスクを付けなくなりました。横スクロールするフィルターは端がフェードし、選んだフィルターが見える位置に移動します。押したときやホバー時のフィードバックが増え、スクリーンリーダーでアバターから送信者のプロフィールを開けます。名前の入力欄で自動修正が働かなくなりました。
- Web 版の「ログイン中のデバイス」にこのアプリのバージョンが表示されます。Android のメモリ不足による終了のレポートに、各情報が終了の何分前に記録されたかが表示されます。

🐛 **修正**
- アプリの再起動時や保存されたログイン情報を読めないときに、下書きと未送信のメッセージが消えなくなりました。まだディスカッションのないタスクで書いた下書きも残ります。
- アプリ内の Web ページがクラッシュしてもアプリが閉じなくなりました。メッセージの下のタスクが更新されたときや、メッセージへ移動中のスレッドを離れたときに、まれにクラッシュする問題を修正しました。
- Raft のリンクがアプリで開きます。タスクのリンクはタスクを開き、チャンネルのリンク、他のサーバーへのリンク、Artifact 内のリンクもブラウザーに移動しなくなりました。
- 連続タップや通知でもページが一度だけ開きます。スマートフォンではリンクや通知が「タスク」「ファイル」カードを閉じてからそのメッセージを開きます。「複数のアプリウィンドウ」がオンのとき、通知はそのサーバーのウィンドウで開きます。
- 「アクティビティ」：読むとすぐに @ が消え、行に前の送信者が一瞬表示されなくなり、途中で切れた返信プレビューが全文として表示されなくなり、外部チャンネルの行に実際のアバターが表示されます。バッジとリストがより多くの場面で正確になります（段階的に提供）。
- 長く開いたままの Artifact が勝手に閉じなくなり、「⋯」の「リンクをコピー」が正しく動作します。
- サーバーを切り替えた後も一覧のエージェントのステータスがプロフィールと一致し、10 分ごとに再確認されます。
- エージェントのプロフィール：「生ログ」に過去の記録が表示され、戻ったときに空白のページにならず、保存済みのプロバイダーは「保存済みのプロバイダー」と表示され、他のサーバーのエージェントは説明とステータスを表示し、名前やアバターの変更がすぐに反映されます。
- アーカイブ済みのチャンネルは Web 版と同じく読み取り専用で開き、「アーカイブを解除」を表示します。タスクの操作は投稿できるチャンネルでだけ表示されます。
- 「保存済み」にタスクの会話で保存したメッセージが表示され、サーバーを切り替えると切り替わります。「コンピューター」とサーバー設定のページも同様です。
- 時間のかかる処理が終わると、アプリのカードが自動で更新されます。他の場所で「長いメッセージを折りたたむ」を切り替えると、すぐに反映されます。
- その他の小さな修正：Slack のメッセージがオフラインでも表示され、「公開アクセス」の設定が読み込めるようになり、コンピューターを接続したメンバーはキーの失効後も名前の変更と削除ができ、メンバー削除の説明はエージェントを別のコンピューターに移すよう案内し、外部チャンネルの招待失敗の表示がちらつかなくなり、選択リストの検索欄をタップしても黒い枠が出なくなり、枠付きのアバターの角がきれいになり、サーバーのアバターの縁と「保存済み」のアイコンが Web 版と同じになりました。
