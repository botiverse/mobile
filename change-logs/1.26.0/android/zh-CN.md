✨ **新功能**
- 创建频道改为两步。服务器所有者和管理员可以把频道设为「外部」，并在频道或频道成员里用邮箱邀请 Raft 以外的人，或直接连接自己的其他服务器（逐步开放）。
- 「搜索消息列」「搜索任务」会搜索整个对话，搜索栏在列表顶部；私信也可以从顶部的搜索在对话内搜索。
- 全局搜索新增「Artifacts」分组。
- 频道管理员可以点成员那一行的「⋯」设为管理员或降为成员，「移出频道」也在这里。
- 多选消息时，「选择到这里」可以一次选中到起始那条消息为止的所有消息。
- 从对话里打开的 Artifact，标题下会列出你最近在这个对话里打开过的 Artifact，可以直接切换。
- 从对话里打开助理时，会把这个对话作为上下文带上。你的个人助理资料页新增「读我的私信」「以我的身份发消息」开关（逐步开放）。
- Agent 的「动态」概览会显示谁启动、停止、重启、重置或迁移了它，以及谁改了模型。
- 迁移 Agent 时会显示打包和下载的大小以及等待时间；计算机详情里会显示上面 Agent 的头像。
- 应用链接卡片上的状态标签会显示应用指定的颜色。

🔧 **改进**
- 实时更新改用 App 自带的连接，断网恢复后会自动重连并补齐错过的消息。
- 从「动态」打开频道和私信更快了。
- 聊天总是从最新消息打开，与网页版一致；「设置 › 移动端」里的对应开关已移除。
- 搜索与网页版一致：频道、成员、Agent 和计算机最多显示 50 个并可「显示全部」，可以「继续搜索」，免费版会提示只搜索最近 30 天，筛选条只占一行，点成员会打开与对方的私信。
- 计算机用量与网页版一致：按模型显示额度，登录需要处理时显示「验证」或「登录」，读取时显示占位条。所有者和管理员也可以使用 Claude 额度重置；退出运行时登录和额度重置超过 30 秒时会等到结果出来。
- Antigravity 不再显示为已弃用，模型列表和推理强度选项与网页版一致。
- Agent 资料页「应用」用一句话说明每个应用能做什么；「动态」里能启动子 Agent 的运行时总会显示「子 Agent」，左右滑动会先在这几个视图之间切换。
- 宽屏上各栏最窄可以拖到 160 点；Artifact 栏默认按手机版排版，需要时可在「⋯」里打开「桌面模式」。
- 打开 Artifact 时只有一个顶栏，并显示与网页版相同的像素加载动画。
- 与其他服务器共享的频道统一叫「外部频道」。频道公告改为在这一行的「⋯」里替换或移除。
- 「添加成员」和「创建 Agent」只显示你能用的选项；外部 Agent 的提示词会说明 Raft 是什么、登录后要做什么。
- 「设置 › 反馈」会标出在其他地方提交的反馈来自哪里；Agent 发来的「提交反馈」卡片会打开 App 的反馈页，并附上版本、设备信息和诊断日志。
- 必填项不再显示星号；可左右滑动的筛选条在边缘渐隐，选中的筛选会滑到可见位置；更多地方有按下和悬停反馈，读屏时可以从头像打开发送者的资料；名称输入框不再自动更正。
- 网页端的「已登录设备」会显示此 App 的版本；Android 被系统因内存结束后的报告会注明每项细节记录于退出前多久。

🐛 **修复**
- 重新启动 App 或无法读取已保存的登录信息时，草稿和未发出的消息不会再丢失；在还没有讨论的任务里写的草稿也会保留。
- App 内的网页崩溃时 App 不再随之关闭；修复了消息下方的任务更新时、以及消息列跳转到某条消息时离开会偶尔闪退的问题。
- Raft 链接在 App 里打开：任务链接会打开任务，频道链接、你其他服务器的链接和 Artifact 里的链接不再跳到浏览器。
- 连点或点通知时页面只打开一次。在手机上，链接和通知会先收起「任务」「文件」卡片，再定位到那条消息。开启「多应用窗口」时，通知会在所属服务器的窗口里打开。
- 「动态」：阅读后 @ 标记立即消失，行不再短暂显示上一位发送者，被截断的回复预览不再当作完整消息显示，外部频道的行会显示真实头像。角标和列表在更多情况下保持准确（逐步开放）。
- 长时间打开的 Artifact 不再自己关闭，「⋯」里的「复制链接」可以正常使用。
- 切换服务器后，列表里的 Agent 状态与资料页一致，并且每 10 分钟重新同步一次。
- Agent 资料页：「原始日志」会显示之前的记录，返回时不再停在空白页，已保存的提供方显示为「已保存的提供方」，其他服务器的 Agent 会显示描述和状态，改名或换头像后立即更新。
- 已归档的频道像网页版一样以只读方式打开，并提供「取消归档」；任务操作只在你能发言的频道里出现。
- 「已保存」会显示在任务对话里保存的消息，切换服务器后会跟着切换，「计算机」和服务器设置页面也一样。
- 应用卡片在耗时操作完成后会自动更新；在其他地方切换「折叠长消息」后会立即生效。
- 其他小问题：Slack 消息离线时也会显示，「公开访问」设置可以正常加载，连接计算机的成员在密钥撤销后仍可改名和移除，移除成员的说明改为把 Agent 移到另一台计算机，外部频道邀请失败的提示不再闪现，点选择列表的搜索框不再出现黑框，带边框的头像四角干净，服务器头像描边和「已保存」图标与网页版一致。
