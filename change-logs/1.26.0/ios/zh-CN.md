**新功能**
- 外部频道（原「联合频道」）是和服务器以外的人共用的频道，对方可以来自其他 Raft 服务器，也可以是用邮箱邀请的人，双方都能看到。现在服务器所有者和管理员可以在 App 里分两步新建外部频道，并用邮箱邀请或连接自己的其他服务器（逐步开放）。
- WebM、MKV、FLV 等视频可以直接在 App 里播放；仍无法播放的文件会提供「下载」和「在其他应用中打开」。
- 「搜索消息列」「搜索任务」会搜索整个对话，搜索栏在顶部；私信可以从顶部搜索；全局搜索新增「Artifacts」分组。
- 频道管理员可以点成员那一行的「⋯」设为管理员或降为成员。
- 多选消息时，「选择到这里」可以一次选到起始那条消息。
- 从对话里打开的 Artifact 会列出你最近在这个对话里打开过的 Artifact。
- 从对话里打开助理时会带上这个对话作为上下文；助理资料页新增「读我的私信」「以我的身份发消息」开关（逐步开放）。
- Agent 的「动态」会显示谁启动、停止、重启、重置或迁移了它。
- 迁移 Agent 时会显示大小和等待时间；计算机详情会显示上面的 Agent。
- 应用链接卡片的状态标签会显示应用指定的颜色。

**改进**
- 实时更新改用 App 自带的连接，断网恢复后会补齐错过的消息。
- 从「动态」打开频道和私信更快了。
- 聊天总是从最新消息打开（「设置 › 移动端」里的对应开关已移除）。
- 搜索与网页版一致：频道、成员、Agent 和计算机最多 50 个结果，可以「继续搜索」，免费版会有提示，筛选条只占一行，点成员会打开私信。
- 计算机用量与网页版一致，可按模型显示额度；所有者和管理员也可以使用 Claude 额度重置，超过 30 秒也会等到结果。
- Antigravity 不再显示为已弃用，模型列表和推理强度与网页版一致。
- Agent 资料页：「应用」会说明每个应用能做什么，运行时支持时「动态」总会显示「子 Agent」。
- 宽屏上各栏最窄可拖到 160 点；Artifact 栏使用手机版排版，可在「⋯」里打开「桌面模式」。
- 打开 Artifact 时只有一个顶栏，并显示与网页版相同的像素加载动画。
- 共享的频道统一叫「外部频道」；频道公告在这一行的「⋯」里替换或移除。
- 「添加成员」和「创建 Agent」只显示你能用的选项；外部 Agent 的提示词会说明接下来要做什么。
- Agent 发来的「提交反馈」卡片会打开 App 的反馈页并附上诊断日志；「设置 › 反馈」会标出反馈来自哪里。
- 必填项不再显示星号，筛选条边缘渐隐，更多地方有按下反馈，VoiceOver 可以从头像打开发送者的资料，名称输入框不再自动更正。

**修复**
- 从其他 App 复制的图片又可以通过「粘贴」或 ⌘V 粘贴到输入框了。
- 重新启动 App 或无法读取登录信息时，草稿和未发出的消息不会丢失；新任务里的草稿也会保留。
- 修复了旋转屏幕、消息下方的任务更新、以及消息列跳转途中离开时的闪退。
- Raft 链接在 App 里打开，包括任务链接、其他服务器的链接和 Artifact 里的链接。
- 连点或点通知时页面只打开一次；在手机上，链接会先收起「任务」「文件」卡片。
- 「动态」：阅读后 @ 立即消失，行不再闪现上一位发送者，被截断的回复预览不再当作完整消息显示。角标在更多情况下保持准确（逐步开放）。
- 长时间打开的 Artifact 不再自己关闭，「复制链接」可以正常使用。
- 列表里的 Agent 状态每 10 分钟重新同步一次；外部 Agent 的最近在线时间和新邀请会实时更新。
- Agent 资料页：「原始日志」会显示之前的记录，返回时不再空白，其他服务器的 Agent 会显示描述、状态以及新的名字或头像。
- 已归档的频道以只读方式打开并提供「取消归档」；任务操作只在你能发言的频道里出现。
- 「已保存」会显示任务对话里的消息，并跟随服务器切换。
- 应用卡片在耗时操作完成后会自动更新。
- 其他小问题：Slack 消息离线显示、「公开访问」设置、密钥撤销后的计算机操作、移除成员的说明、邀请失败提示、选择列表的黑框、头像四角和图标。
