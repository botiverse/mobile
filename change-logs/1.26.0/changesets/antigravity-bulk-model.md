## zh-CN

Antigravity 不再是已弃用的运行时，与网页版一致：在计算机页批量「更换模型」时，Antigravity 的「AGY configured default」排在第一位并默认选中，确认后不会把 Agent 固定到 Antigravity 当前使用的模型；只有当所选模型列出了推理强度时，才会提供推理强度。Antigravity Agent 的资料页也会显示它的推理强度。

## en

Antigravity is no longer deprecated, and the app now matches the web: in a Computer's bulk Change model, Antigravity's "AGY configured default" comes first and is selected, so confirming doesn't pin agents to the model Antigravity happens to use today; a reasoning effort is offered only for a model that lists its levels. An Antigravity agent's profile also shows its reasoning effort.

## ja

Antigravity は非推奨ではなくなり、ウェブ版と同じ動作になりました。コンピューターの一括「モデルを変更」では、Antigravity の「AGY configured default」が先頭に表示されて選択済みになり、確定してもエージェントが Antigravity の現在のモデルに固定されません。推論レベルは、レベルを持つモデルを選んだときだけ表示されます。Antigravity エージェントのプロフィールにも推論レベルが表示されます。
