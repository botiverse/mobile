## zh-CN

Agent 资料页「应用」里的每个应用，现在用一句话说明它能做什么，并以应用为主语，例如「Stamp 可以用这个 Agent 的身份登录和发送通知」，不再列出原始权限范围。面向开发者的 Agent 清单链接不再显示。与网页版一致。

## en

Each app on an agent's Apps tab now says in one sentence what it can do, with the app as the subject, for example "Stamp can sign in as this agent and send notifications", instead of listing raw scopes. The developer-facing agent manifest link is no longer shown. This matches the web.

## ja

エージェントのプロフィールの「アプリ」では、各アプリでできることをアプリを主語にした一文で表示するようになりました（例：「Stamp ができること：このエージェントとしてログイン、通知の送信」）。これまでのように生のスコープは並べません。開発者向けのエージェントマニフェストのリンクは表示されなくなりました。Web 版と同じ表示です。
