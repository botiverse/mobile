## zh-CN

切换回另一个工作空间后，成员列表和首页里的 Agent 状态会重新同步，和 Agent 资料页一致。以前，如果这个工作空间在后台时一直保持着连接，切回来后列表可能还显示旧状态（例如显示“在线”，点进资料页却在“工作中”）。

## en

After you switch back to another workspace, agent status in the members list and on Home is refreshed and matches the agent's profile. Before, if that workspace had stayed connected in the background, the lists could keep showing an old status after you switched back (for example "Online", while the profile showed the agent working).

## ja

別のワークスペースに戻ったとき、メンバー一覧とホームの Agent のステータスが再同期され、Agent のプロフィールと一致するようになりました。これまでは、そのワークスペースがバックグラウンドで接続を保っていた場合、戻った後も一覧に古いステータスが表示されることがありました（一覧では「オンライン」なのに、プロフィールを開くと作業中など）。
