## zh-CN

任务的修改操作现在只在你能在该频道发言时出现，和网页版一致。在没有加入的公开频道或已归档的频道里，你仍然可以查看任务，但不会再看到改状态、改负责人、编辑标题和描述、删除任务、新建任务，以及消息菜单里的任务操作，这些操作原本只会失败。

## en

Task actions now show only where you can post in the task's channel, as on the web. In a public channel you haven't joined, or in an archived channel, you can still read its tasks, but you no longer see status and assignee changes, title and description edits, Delete task, New task, or the task items in the message menu, which could only fail there.

## ja

タスクを変更する操作は、Web 版と同じく、そのチャンネルに投稿できる場合にだけ表示されるようになりました。参加していない公開チャンネルやアーカイブ済みのチャンネルでも、タスクは引き続き閲覧できますが、ステータスや担当者の変更、タイトルと説明の編集、タスクの削除、新しいタスクの作成、メッセージメニューのタスク操作は表示されなくなりました。これらはそこでは失敗するだけでした。
