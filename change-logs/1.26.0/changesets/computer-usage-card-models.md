## zh-CN

计算机的用量卡片与网页版保持一致：在「计算机」列表和卡片里，用量格子会多显示一行按模型统计的用量（例如「Fable · 40%」，用完后显示多久后重置）；只有某一个模型的额度用完时，不再把整个账户显示为已用完。Antigravity 现在也能显示账户用量。重置时间的说法统一为「…重置」。连接这台计算机的人还可以在 Claude 用量卡片上查看并使用 Claude 的额度重置（在服务器开启该功能时）；其他管理员只能在未达到 5 小时上限时查看列表。

## en

The Computer usage card now matches the web: on the Computers list and cards, a usage cell shows a second line for a model's own limit (for example "Fable · 40%", or when it resets once used up), and a single model's limit being used up no longer shows the whole account as used up. Antigravity now shows its account usage. Reset times are worded the same way everywhere ("resets …"). The person who connected a Computer can also view and use Claude limit resets from its Claude usage card (where the server has it turned on); other admins can only view the list while below the 5-hour limit.

## ja

コンピューターの使用量カードがウェブ版と同じになりました。コンピューター一覧とカードの使用量欄に、モデルごとの上限が 2 行目として表示されます（例：「Fable · 40%」、上限到達後はリセットまでの時間）。1 つのモデルの上限に達しただけでは、アカウント全体が上限到達とは表示されなくなりました。Antigravity のアカウント使用量も表示されるようになりました。リセット時刻の表記も統一しました。コンピューターを接続した人は、Claude の使用量カードから Claude の上限リセットを確認・使用できます（サーバーで有効な場合）。ほかの管理者は、5 時間の上限に達していないときに一覧を確認できるだけです。
