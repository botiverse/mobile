## zh-CN

在频道里添加成员时，如果你没有创建 Agent 的权限，列表下方不再显示灰色的「创建 Agent」和权限说明，只保留你能用的选项。

## en

When you add members to a channel and can't create agents, the list no longer shows a greyed-out "Create agent" row and its explanation; only the options you can use are shown.

## ja

チャンネルにメンバーを追加するとき、エージェントを作成する権限がない場合は、グレー表示の「エージェントを作成」とその説明が表示されなくなりました。使える操作だけが表示されます。
