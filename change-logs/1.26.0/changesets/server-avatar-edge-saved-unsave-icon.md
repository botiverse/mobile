## zh-CN

深色模式下，服务器头像（主页顶栏、服务器切换器和服务器标签）恢复了与网页版一致的浅色描边。收藏列表中每条消息的取消收藏按钮改为与网页版相同的“移除书签”线框图标，读屏软件会将其读作“从收藏中移除”。

## en

In dark mode, the server avatar (on the Home bar, in the server switcher and on the server tab) has its light edge again, as on the web. The unsave button on each Saved message now shows the same outline "remove bookmark" icon as the web, and screen readers announce it as "Remove from Saved".

## ja

ダークモードで、サーバーのアバター（ホームのバー、サーバー切り替え、サーバータブ）に Web 版と同じ明るい縁取りが戻りました。保存済みの各メッセージの保存解除ボタンは Web 版と同じ線画の「ブックマーク削除」アイコンになり、スクリーンリーダーでは「保存済みから削除」と読み上げられます。
