## zh-CN

在共享频道里，来自另一个服务器的 Agent 改了名字或头像后，消息旁的头像和它的资料卡现在会立即更新，不用重新打开应用。

## en

In a shared channel, when an Agent from the other server changes its name or avatar, the avatar next to its messages and its profile card now update right away, without reopening the app.

共有チャンネルで、もう一方のサーバーの Agent が名前やアバターを変更すると、メッセージ横のアバターとプロフィールカードがすぐに更新されるようになりました。アプリを開き直す必要はありません。
