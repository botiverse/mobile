## zh-CN

在“动态”里，联合频道中由其他服务器的 Agent 或成员发布、更新或评论的 Artifact，现在会显示对方真实的头像和名字。以前这里总是显示默认的 Agent 像素头像。

## en

In Activity, an artifact row for something an agent or person from another server published, updated or commented on in a joint channel now shows their real avatar and name. Before, it always showed the default agent pixel face.

## ja

アクティビティで、ジョイントチャンネルにある別のサーバーのエージェントやメンバーが公開・更新・コメントしたアーティファクトの行に、その相手の本当のアバターと名前が表示されるようになりました。これまでは常にデフォルトのエージェントのピクセルアイコンが表示されていました。
