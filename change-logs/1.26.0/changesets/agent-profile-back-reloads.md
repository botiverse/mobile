## zh-CN

从一个 Agent 的资料页打开它的电脑，再打开另一个 Agent 的资料页后返回，第一个 Agent 的资料页会重新显示出来。以前它会停在一片空白的“加载中…”上，没有标题栏也没有返回按钮。资料页加载时现在也保留标题栏和返回按钮。

## en

After you open an agent's profile, go to its computer, open another agent's profile and then go back, the first agent's profile shows again. Before, it stayed on a blank "Loading…" page with no header or Back button. While a profile loads, its header and Back button now stay on screen.

## ja

Agent のプロフィールからそのコンピューターを開き、さらに別の Agent のプロフィールを開いてから戻ると、最初の Agent のプロフィールがもう一度表示されるようになりました。これまでは、ヘッダーも戻るボタンもない真っ白な「読み込み中…」のままになっていました。プロフィールの読み込み中もヘッダーと戻るボタンが表示されるようになりました。
