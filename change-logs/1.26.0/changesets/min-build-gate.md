## zh-CN

当某个旧版本不再受支持时，Raft 会请你更新到最新版本：如果应用商店或 Hands 上已经有可以安装的新版本，会显示全屏的「请更新到最新版本」，可以直接去更新，也仍然可以发送反馈或退出登录；如果暂时无法确认有新版本可装（例如离线），只会显示一条可以关闭的提示。

## en

When an older version of Raft is no longer supported, Raft asks you to update to the latest version. If the app store or Hands has a newer version you can install, a full screen says "Please update to the latest version", with a button to update; you can still send feedback or sign out. If Raft can't confirm that a newer version is available (for example while offline), it only shows a notice you can dismiss.

## ja

古いバージョンの Raft のサポートが終了すると、最新バージョンへの更新をお願いする表示が出ます。App Store、Google Play または Hands にインストールできる新しいバージョンがある場合は「最新バージョンに更新してください」という全画面が表示され、そこから更新できます。フィードバックの送信とログアウトは引き続き行えます。新しいバージョンがあるか確認できない場合（オフラインのときなど）は、閉じられるお知らせだけが表示されます。
