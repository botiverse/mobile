## zh-CN

服务器所有者打开「服务器设置 › 公开访问」时，这一栏又能正常加载和开关了。之前服务器去掉了已经下线的「访客加入」设置后，App 会把它当成读取失败，只显示加载失败。

## en

Server owners can load and change Server settings › Public access again. After the server dropped the retired Guest joining setting, the app treated its answer as a failure and showed only a loading error.

## ja

サーバーのオーナーが「サーバー設定 › 公開アクセス」を開くと、また正しく読み込んで切り替えられるようになりました。サーバー側で提供終了済みの「ゲスト参加」設定がなくなったあと、アプリはその応答を読み込み失敗として扱い、エラーだけを表示していました。
