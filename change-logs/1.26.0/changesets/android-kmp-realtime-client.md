## zh-CN

Android 上新增了一种实时连接方式（Beta），正式版默认关闭，可以在「设置 › 开发者」里打开，也会随服务器设置逐步开启；测试版默认开启。

## en

On Android there is a new realtime connection (Beta). It is off by default in release builds; you can turn it on in Settings › Developer, and it rolls out gradually with the server setting. Test builds have it on by default.

## ja

Android に新しいリアルタイム接続（ベータ）が加わりました。リリース版では既定でオフで、「設定 › 開発者」でオンにできます。サーバー側の設定に合わせて段階的にも有効になります。テスト版では既定でオンです。
