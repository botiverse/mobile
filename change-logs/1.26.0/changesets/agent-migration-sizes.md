## zh-CN

迁移 Agent 时，进度说明现在会显示大小：打包工作区时显示目前已处理的文件数和大小，目标计算机下载时显示进度百分比和已下载 / 总大小（压缩后），与网页版一致。

## en

While an agent moves to another computer, the progress line now shows sizes: how many files and how much has been packed so far, then how far the target computer's download is, as a percentage and how much of the total (compressed) it has, as on the web.

## ja

エージェントを別のコンピューターに移動するとき、進行状況の説明にサイズが表示されるようになりました。ワークスペースのパッケージ化中はこれまでに処理したファイル数とサイズを、移動先のコンピューターがダウンロード中は進捗率とダウンロード済み / 合計サイズ（圧縮後）を表示します。Web 版と同じです。
