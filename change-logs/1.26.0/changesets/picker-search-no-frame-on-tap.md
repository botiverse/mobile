## zh-CN

在选择列表（比如新建 agent 时选模型）里点搜索框，不再出现一圈顶到屏幕两边的黑色方框。用键盘切到搜索框时仍会显示焦点框。

## en

Tapping the search box in a picker (for example, choosing a model when you create an agent) no longer draws a black frame across the screen. Moving to the search box with a keyboard still shows the focus frame.

## ja

選択リスト（エージェント作成時のモデル選択など）で検索ボックスをタップしても、画面幅いっぱいの黒い枠が表示されなくなりました。キーボードで検索ボックスに移動したときは、これまでどおりフォーカス枠が表示されます。
