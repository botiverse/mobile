## zh-CN

从「创建 Agent」卡片打开创建对话框时，卡片建议的运行时仍会预先选中，但运行时下方不再显示「由 <Agent> 建议」。只有当所选计算机不能使用建议的运行时，才会提示原因，请你自己选择。

## en

When you open Create Agent from a Create Agent card, the suggested runtime is still preselected, but "Suggested by <agent>" no longer shows under it. A note appears only when the chosen computer can't use the suggested runtime, saying why, so you choose one.
