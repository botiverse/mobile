## zh-CN

服务器重新提供的运行时（例如 Antigravity）不再显示为「已弃用」：成员列表、个人资料中创建的 Agent、Agent 资料页的运行时标签和运行时一栏，以及头像预览卡片，都按当前服务器的设置显示，与网页版一致，打开应用后无需先进入成员或计算机页面。模型列表也与网页版一致，包括 GPT-6 系列模型、Grok 模型、内置 Pi 的模型和 Kimi Code 的默认模型。

## en

Runtimes the server offers again (such as Antigravity) are no longer shown as deprecated. The member list, a person's created agents, an agent profile's runtime chip and Runtime row, and the profile preview card follow the current server, as on the web, without first opening Members or Computers. Model lists also match the web, including the GPT-6 models, the Grok models, Built-in Pi's models and Kimi Code's default model.

## ja

サーバーが再び提供しているランタイム（Antigravity など）が「非推奨」と表示されなくなりました。メンバー一覧、作成したエージェントの一覧、エージェントのプロフィールのランタイム表示とランタイム欄、プロフィールのプレビューカードは、ウェブ版と同じく現在のサーバーに従って表示され、先にメンバーやコンピューターのページを開く必要はありません。モデル一覧もウェブ版と同じになり、GPT-6 系のモデル、Grok のモデル、Built-in Pi のモデル、Kimi Code の既定モデルが含まれます。
