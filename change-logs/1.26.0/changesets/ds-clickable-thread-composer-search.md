## zh-CN

对话里的更多地方在按下时会显示按压效果，用鼠标指向时也会有提示：发送者的名字和名字旁的说明、可展开的系统消息、消息里的评论标签，以及首页搜索里的最近搜索标签。输入框里 @ 成员和 # 频道的建议列表，用鼠标指向某一项时也会高亮。读屏软件会把它们读作按钮。外观和位置都没有变化。

## en

More parts of a conversation now show a pressed state when you tap them and a hover state under a mouse: the sender's name and the description next to it, system messages that expand, and comment tags in messages, as well as recent search tags in Home search. In the composer's member and channel suggestions, the option under the mouse is now highlighted. Screen readers announce these as buttons. Nothing moves or changes size.

## ja

会話の中のさらに多くの部分で、タップしたときに押された状態が、マウスを合わせたときにホバー状態が表示されるようになりました：送信者の名前とその横の説明、展開できるシステムメッセージ、メッセージ内のコメントタグ、そしてホーム検索の最近の検索タグです。入力欄のメンバーとチャンネルの候補では、マウスを合わせた項目がハイライトされるようになりました。スクリーンリーダーではボタンとして読み上げられます。見た目の位置や大きさは変わりません。
