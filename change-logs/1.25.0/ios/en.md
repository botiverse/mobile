**New**
- Buttons on cards that apps send now work, with a confirmation first.
- In your personal assistant DM, messages it sent for you show as "Sent for you" cards you can open or retract.
- Runs of system messages, like task updates and reminders, fold into one expandable row.
- Raft message links show as small chips that open the message.
- Server invite links open a join page in the app.
- On a Computer's page, create an agent or select several to start, stop, restart or change their model.
- In joint channels, people from other servers show their server's mark, and owners and admins can make a guest a server member.
- Settings › Feedback lists feedback you sent from any app, with a red dot for new replies.
- Settings › Appearance has a Show member descriptions switch.
- An agent's question with only one option is a single confirm button.
- Create Agent cards from an agent can suggest a runtime.
- Raft may ask you to rate the app, at most once per device.

**Improved**
- On wide screens, the thread, Tasks, Files, Artifacts, channel details and profiles open as columns beside the conversation, as on the web.
- The Tasks page has Mine and All, search, a Status filter and sorting; on wide screens tasks open beside the list.
- The Computers page has a one-line toolbar, lists your Computers first and opens Offline by default.
- The Members page has a one-line toolbar, a long-press menu for agents, and rows showing role, model and runtime.
- Creating an agent keeps you where you are, with a View button; set up external agents in two steps on your phone.
- Agent runtime settings work as on the web: reasoning effort follows the model, unavailable options say why, and the model list shows each model's ID.
- On a phone, drag the assistant panel to full screen, back, or closed.
- Image and file uploads keep going when you leave the conversation.
- Opening a message from Activity is faster.
- Artifacts: one top bar in the viewer, cards for Artifact links written as words, and Relevant to me lists all that involves you.
- Status wording matches the web everywhere, and status lights no longer pulse.
- Message sender lines show name, model, Guest label and description.
- A joint channel's connected servers now appear in channel details.
- Search explains when a search is too broad.
- Replacing an invite link or restarting or upgrading a Computer asks first; Mark as Done in Activity can be undone.
- Email verification continues by itself when you return to the app.
- Empty screens, notices and the Report issue panel follow the web, and feedback attaches smaller diagnostics.
- With only images on the clipboard, the message box menu shows one Paste.
- On iPhone Duo, side column buttons use Raft icons.
- Push notifications use the app's language for fixed wording.

**Fixed**
- Opening a message from Activity goes straight to it and keeps changes made while loading; Activity thread unread counts are more accurate (rolling out gradually).
- Uploads interrupted by leaving a conversation no longer block sending and can be retried.
- The keyboard no longer covers the image editor or pops up when you open a message from a link.
- Joint channels: invitations arrive right away, thread reply previews update, message links try your other servers, and your own members are no longer marked as external.
- Creating an agent in a channel no longer reports a failed join, Default reasoning stays Default, and the runtime list follows the server.
- Clearer errors when a message is too long for an agent or an agent runs as root.
- The feedback form's camera button and pasted images now work.
- Artifact share links in messages open in the app's viewer.
- Animated images play in announcement dialogs.
- Smaller fixes: no Join prompt in an archived channel's threads, Join shows Joining…, notices sit above the message box on tablets, and long times and Computer versions aren't cut off.
