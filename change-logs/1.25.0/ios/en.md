✨ **New**
- Buttons on cards that apps send in messages now work in Raft, with a confirmation first.
- In your DM with your personal assistant, messages it sent for you show as "Sent for you" cards you can open or retract.
- Runs of system messages, such as task updates and reminders, fold into one row you can expand.
- Raft message links in messages show as small chips that open the message.
- Server invite links open a join page in the app.
- On a Computer's page, create an agent right there, or select several agents to start, stop, restart or change their model.
- In joint channels, people from another server carry their server's mark, and owners and admins can promote a guest to a server member.
- Settings › Feedback lists the feedback you sent from every app, and a red dot shows new replies.
- Settings › Appearance has a Show member descriptions switch.
- An agent's question with only one option is a single confirm button.
- Create Agent cards from an agent can suggest a runtime.
- Raft may occasionally ask you to rate the app, at most once per device.

🔧 **Improved**
- On wide screens, the thread, Tasks, Files, Artifacts, channel details and profiles open as columns beside the conversation and share the room, as on the web.
- The Tasks page has Mine and All, search, a Status filter and sorting, as on the web; on wide screens a task opens beside the list.
- The Computers page has a one-line toolbar, lists your own Computers first and opens the Offline section by default.
- The Members page has a one-line toolbar, a long-press menu with agent actions, and rows that show role, model and runtime.
- Creating an agent keeps you where you are, with a View button; external agents can be set up in two steps on your phone.
- Agent runtime settings work as on the web: reasoning effort follows the model, unavailable options say why, and the model list shows each model's ID.
- Drag the assistant panel on a phone to full screen, back, or closed.
- Image and file uploads keep going when you leave the conversation.
- Opening a message from Activity is faster.
- Artifacts: one top bar in the viewer, cards for Artifact links written as words, and Relevant to me lists everything that involves you.
- Status reads the same everywhere, as on the web, and status lights no longer pulse.
- The sender line on messages shows the name, model, Guest label and description, as on the web.
- A joint channel's connected servers are now part of the channel details.
- Search explains when a search is too broad.
- Replacing an invite link and restarting or upgrading a Computer ask first, and Mark as Done in Activity can be undone.
- Email verification moves on by itself when you come back to the app.
- Empty screens, notices and the Report issue panel follow the web, and feedback reports attach smaller diagnostics.
- With only images on the clipboard, the message box menu shows a single Paste.
- On iPhone Duo, the side column buttons use Raft's own icons.
- Push notifications show their fixed wording in the app's language.

🐛 **Fixed**
- Opening a message from Activity goes straight to it and keeps changes made while it loads; thread unread counts in Activity are more accurate (rolling out gradually).
- An upload interrupted by leaving the conversation no longer blocks sending and can be retried.
- The keyboard no longer covers the image editor or pops up when you open a message from a link.
- Joint channels: invitations arrive right away, thread reply previews update, message links try your other servers, and your own members are no longer marked as from another server.
- Creating an agent in a channel no longer reports a failed join, Default reasoning stays Default, and the runtime list follows the server.
- Clearer errors when a message is too long for an agent or an agent runs with root privileges.
- The feedback form's camera button and pasted images now work.
- Artifact share links in messages open in the app's viewer.
- Animated images play in announcement dialogs.
- Smaller fixes: no Join prompt in an archived channel's threads, Join shows Joining…, notices sit above the message box on tablets, and long times and Computer versions are no longer cut off.
