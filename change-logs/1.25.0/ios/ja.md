**新機能**
- アプリがメッセージで送ったカードのボタンを Raft でそのまま使えるようになりました。押すとまず確認が表示されます。
- アシスタントとの DM で、アシスタントが代わりに送ったメッセージが「代理で送信しました」カードで表示され、開いたり取り消したりできます。
- タスクの更新やリマインダーなど連続するシステムメッセージが 1 行にまとめられ、タップで展開できます。
- メッセージ内の Raft のメッセージリンクが小さなチップで表示され、タップでそのメッセージが開きます。
- サーバーの招待リンクでアプリ内の参加ページが開きます。
- コンピューターのページから直接エージェントを作成したり、複数のエージェントを選んでまとめて起動・停止・再起動・モデル変更したりできます。
- 共同チャンネルで、他のサーバーの人に所属サーバーのマークが付き、オーナーと管理者はゲストをサーバーメンバーに昇格できます。
- 「設定 › フィードバック」に、どのアプリから送ったフィードバックもまとめて表示され、新しい返信は赤い点で知らせます。
- 「設定 › 外観」に「メンバーの説明を表示」スイッチを追加しました。
- 選択肢が 1 つだけのエージェントの質問は、確認ボタン 1 つで表示されます。
- エージェントからの「エージェントを作成」カードで、ランタイムを推奨できるようになりました。
- Raft がまれにアプリの評価をお願いすることがあります（1 台の端末につき 1 回まで）。

**改善**
- ワイド画面では、スレッド、タスク、ファイル、Artifact、チャンネルの詳細、プロフィールが会話の横に列として開き、Web 版と同じように幅を分け合います。
- タスクページに「自分」「すべて」、検索、「ステータス」の絞り込み、並べ替えを追加しました（Web 版と同じ）。ワイド画面ではタスクが一覧の横に開きます。
- コンピューターページのツールバーが 1 行になり、自分のコンピューターが先頭に並び、「オフライン」のセクションが最初から開きます。
- メンバーページのツールバーが 1 行になり、行の長押しでエージェントを操作するメニューが開き、各行に役割・モデル・ランタイムが表示されます。
- エージェントを作成しても今の画面のまま「表示」ボタンが出ます。外部エージェントはスマートフォンで 2 ステップで設定できます。
- エージェントのランタイム設定が Web 版と同じになりました。推論の強度はモデルに合わせて変わり、使えない選択肢は理由を表示し、モデル一覧に各モデルの ID が表示されます。
- スマートフォンのアシスタントパネルをドラッグして、全画面・元の高さ・閉じるを切り替えられます。
- 会話を離れても、画像やファイルのアップロードが続きます。
- 「アクティビティ」からメッセージを開くのが速くなりました。
- Artifact：ビューアーの上部バーが 1 本になり、文字で書いた Artifact リンクにもカードが付き、「自分に関係あり」に関係するすべての Artifact が表示されます。
- ステータスの言い方がどこでも Web 版と同じになり、ステータスランプは点滅しなくなりました。
- メッセージの送信者の行に、名前、モデル、ゲストのラベル、説明が Web 版と同じように表示されます。
- 共同チャンネルの接続済みのサーバーが、チャンネルの詳細に表示されるようになりました。
- 検索範囲が広すぎるときは、検索がその旨を説明します。
- 招待リンクの置き換えやコンピューターの再起動・アップグレードの前に確認し、「アクティビティ」の「完了にする」は元に戻せます。
- アプリに戻ると、メール認証が自動で次に進みます。
- 空の画面、案内、「問題を報告」パネルが Web 版と同じになり、フィードバックに添付する診断ファイルが小さくなりました。
- クリップボードに画像だけがあるとき、メッセージ入力欄のメニューには「ペースト」が 1 つだけ表示されます。
- iPhone Duo のサイド列のボタンが Raft 独自のアイコンになりました。
- プッシュ通知の定型の文言がアプリの言語で表示されます。

**修正**
- 「アクティビティ」からメッセージを開くとそのメッセージへ直接移動し、読み込み中の変更も失われません。「アクティビティ」のスレッドの未読数がより正確になりました（順次提供）。
- 会話を離れて中断したアップロードで送信できなくなることがなくなり、再試行できます。
- キーボードが画像エディターを隠したり、リンクからメッセージを開いたときに出てきたりしなくなりました。
- 共同チャンネル：招待がすぐに届き、スレッドの返信プレビューが更新され、メッセージリンクは他のサーバーも試し、このサーバーのメンバーが他のサーバーの人と誤って表示されなくなりました。
- チャンネルでエージェントを作成したときに参加失敗と誤って表示されなくなり、推論の強度の「デフォルト」が保たれ、選べるランタイムはサーバーに従います。
- エージェントへのメッセージが長すぎるときや、エージェントが root 権限で動いているときのエラーが分かりやすくなりました。
- フィードバックフォームのカメラボタンと画像の貼り付けが使えるようになりました。
- メッセージ内の Artifact の共有リンクがアプリのビューアーで開くようになりました。
- お知らせダイアログのアニメーション画像が再生されるようになりました。
- その他の小さな修正：アーカイブ済みチャンネルのスレッドで参加を求められない、参加中は「参加中…」と表示、タブレットで通知がメッセージ入力欄の上に表示、長い時刻やコンピューターのバージョンが切れない。
