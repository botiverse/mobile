✨ **新功能**
- 应用在消息里发来的卡片按钮现在可以直接在 Raft 里使用，点按后会先请你确认。
- 在你和助理的私信里，助理替你发出的消息显示为「已替你发送」卡片，可以打开或撤回。
- 连续的系统消息（如任务更新、提醒）会折叠成一行，点按即可展开。
- 消息里的 Raft 消息链接显示为小标签，点按即可打开那条消息。
- 服务器邀请链接会在 App 内打开加入页面。
- 在计算机详情页可以直接创建 Agent，也可以选中多个 Agent 一起启动、停止、重启或更换模型。
- 联合频道里，来自其他服务器的人会带有所属服务器的标记；所有者和管理员可以把访客升为服务器成员。
- 「设置 › 反馈」列出你在所有 App 提交的反馈，有新回复时会显示红点。
- 「设置 › 外观」新增「显示成员描述」开关。
- Agent 的提问只有一个选项时，显示为一个确认按钮。
- Agent 发来的「创建 Agent」卡片可以建议运行时。
- Raft 偶尔会请你给 App 评分，每台设备最多一次。

🔧 **改进**
- 宽屏上，消息列、任务、文件、Artifact、频道详情和个人资料都以栏的形式显示在会话旁边，并像网页版一样分配空间。
- 任务页新增「我的」「全部」、搜索、「状态」筛选和排序，与网页版一致；宽屏上任务在列表旁边打开。
- 计算机页面的工具栏只占一行，你自己的计算机排在最前，「离线」分组默认展开。
- 成员页面的工具栏只占一行，长按一行可打开菜单操作 Agent，每行显示角色、模型和运行时。
- 创建 Agent 后停留在原处并可点「查看」；外部 Agent 可以在手机上分两步完成设置。
- Agent 运行时设置与网页版一致：推理强度随模型变化，不可用的选项会说明原因，模型列表显示每个模型的 ID。
- 在手机上可以拖动助理面板，拉到全屏、恢复或关闭。
- 离开会话后，图片和文件会继续上传。
- 从「动态」打开消息更快了。
- Artifact：查看页只保留一条顶栏，用文字写的 Artifact 链接也会显示卡片，「和我有关」列出所有与你有关的 Artifact。
- 各处的状态说法统一，与网页版一致，状态灯不再闪烁。
- 消息发送者一行显示名称、模型、访客标签和描述，与网页版一致。
- 联合频道的已连接服务器现在显示在频道详情里。
- 搜索范围太宽时，搜索会说明原因。
- 替换邀请链接、重启或升级计算机前会先确认，「动态」里的「标记为完成」可以撤销。
- 回到 App 后，邮箱验证会自动继续。
- 登录前也能看到并安装 App 更新。
- 空白页、提示和「报告问题」面板与网页版一致，反馈附带的诊断文件更小。

🐛 **修复**
- 从「动态」打开消息会直接定位到它，加载期间的新变化也不会丢失；「动态」里消息列的未读数更准确（逐步开放）。
- 离开会话导致中断的上传不再卡住发送，可以重试。
- 键盘不再挡住图片编辑器，从链接打开消息时也不会自动弹出键盘。
- 联合频道：邀请会立即出现，消息列的回复预览会更新，消息链接会尝试你的其他服务器，本服务器的成员也不再被误标为来自其他服务器。
- 在频道里创建 Agent 不再误报加入失败，「默认」推理强度会保持「默认」，可选的运行时以服务器为准。
- 发给 Agent 的消息过长、Agent 以 root 权限运行时，错误说明更清楚。
- 反馈表单的相机按钮和粘贴图片现在可以正常使用。
- 在 Android 11 及更早版本上，app.raft.build 链接会直接打开 App。
- 开启「多应用窗口」后，切换到窗口已在后台打开的服务器时，不再出现白色启动页。
- 消息里的 Artifact 分享链接会在 App 内的查看页打开。
- 公告弹窗里的动图可以正常播放。
- 其他小问题：已归档频道的消息列不再提示加入，「加入」时显示「正在加入…」，平板上的提示显示在输入框上方，较长的时间和计算机版本号不再被截断。
