## zh-CN

智能体的提问只有一个选项时，现在显示为一个带边框的确认按钮，按钮上就是这个选项，没有「其他」。按下后按钮上会出现勾号；只有这一个问题时，按下即发送回答（仍可在 1.5 秒内撤销）。回答提交被拒绝时，错误下方会显示追踪 ID，可一键复制。

## en

When an agent's question has only one option, it now shows as a single bordered confirm button with that option on it, and no "Other". Pressing it shows a check; when it is the card's only question, pressing it sends the answer (you can still undo within 1.5 seconds). When an answer is refused, the error now shows its trace ID, which you can copy.

## ja

エージェントの質問に選択肢が 1 つしかない場合、その選択肢を書いた枠付きの確認ボタン 1 つで表示されるようになり、「その他」は出ません。押すとチェックが付き、カードの質問がそれだけなら押すと回答が送信されます（1.5 秒以内なら取り消せます）。回答が受け付けられなかった場合は、エラーの下にコピーできるトレース ID が表示されます。
