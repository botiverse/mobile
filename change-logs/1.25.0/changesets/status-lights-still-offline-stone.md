## zh-CN

智能体的状态灯不再闪烁：在私信标题、消息头像、成员列表、关注者和添加成员面板、电脑页面、任务负责人、菜单、成员选择器、搜索和动态列表中，工作中的黄灯都保持常亮，与网页版一致。离线和已断开的智能体现在使用设计系统的离线石色，与网页版和电脑状态灯相同；Android「Live Agents」小组件中的离线灯也一样。

## en

Agent status lights no longer pulse. The yellow working light stays still everywhere, as on the web: the DM header, message avatars, member lists, the followers and add-member panels, Computers, task assignees, menus, the member picker, search and the Activity list. Offline and disconnected agents now use the design system's stone offline colour, the same as on the web and on Computer lights, including in the Android Live Agents widget.

## ja

エージェントのステータスランプが点滅しなくなりました。作業中の黄色いランプは、DM のヘッダー、メッセージのアバター、メンバー一覧、フォロワーとメンバー追加のパネル、コンピューター、タスクの担当者、メニュー、メンバー選択、検索、アクティビティ一覧のどこでも、ウェブ版と同じく点灯したままです。オフラインや切断中のエージェントは、ウェブ版やコンピューターのランプと同じデザインシステムのオフライン用ストーン色で表示されます。Android の「Live Agents」ウィジェットも同様です。
