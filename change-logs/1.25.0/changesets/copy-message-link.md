## zh-CN

长按消息中的链接打开菜单时，顶部的链接区已经有「复制链接」，消息本身的复制链接操作现在显示为「复制消息链接」，不再出现两个同名操作。直接长按消息时仍显示「复制链接」。

## en

When you long-press a link in a message, the menu's link section already has Copy link, so the message's own action now reads Copy Message Link instead of a second Copy Link. A plain long press on the message still shows Copy Link.

## ja

メッセージ内のリンクを長押ししてメニューを開くと、上部のリンク欄に「リンクをコピー」があるため、メッセージ自体の操作は「メッセージのリンクをコピー」と表示されるようになりました。同じ名前の項目が 2 つ並ぶことはありません。メッセージを普通に長押ししたときは、これまでどおり「リンクをコピー」と表示されます。
