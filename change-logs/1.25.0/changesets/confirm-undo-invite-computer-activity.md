## zh-CN

几个难以撤回的操作现在会先确认，或者给你撤销的机会，和网页版一致：已有邀请链接时点「更新链接」会先询问，因为旧链接会失效；重启或升级 Computer 前会先确认，并说明它上面有多少个 Agent 会断开连接；在「动态」里用行上的「标记为完成」按钮或长按菜单的「完成」时，也会像滑动操作一样显示 8 秒的「撤销」提示。

## en

A few actions that are hard to take back now ask first or let you undo them, as on the web: Update Link on an invite link that already exists asks before replacing it, since the old link stops working; restarting or upgrading a Computer asks first and says how many agents on it will disconnect; and in Activity, the row's Mark as Done button and the menu's Done now show the same 8-second Undo toast as the swipe.

## ja

取り消しにくい操作で、先に確認するか、元に戻せるようになりました（Web 版と同じ動作です）。既存の招待リンクで「リンクを更新」を押すと、古いリンクが使えなくなるため先に確認します。Computer の再起動やアップグレードの前にも確認し、接続が切れるエージェントの数を表示します。また「アクティビティ」で行の「完了にする」ボタンやメニューの「完了」を使ったときも、スワイプと同じく 8 秒間の「元に戻す」が表示されます。
