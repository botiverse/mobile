## zh-CN

从消息链接、「动态」或搜索结果打开某条消息时，输入框不会再自动获得焦点，键盘也不会自己弹出把这条消息挤出屏幕。连接了实体键盘时，正常打开对话仍会像以前一样聚焦输入框。

## en

When you open a message from a message link, Activity or a search result, the message box no longer takes focus by itself, so the keyboard doesn't pop up and push that message off the screen. With a hardware keyboard connected, opening a conversation normally still focuses the message box as before.

## ja

メッセージリンク、「アクティビティ」、検索結果からメッセージを開いたとき、入力欄に自動でフォーカスが入らなくなりました。キーボードが勝手に表示されて、そのメッセージが画面の外へ押し出されることはありません。ハードウェアキーボード接続時に会話を通常どおり開いた場合は、これまでどおり入力欄にフォーカスが入ります。
