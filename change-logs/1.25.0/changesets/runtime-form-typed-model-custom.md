## zh-CN

创建或编辑智能体时，如果模型字段允许直接填写，你填写的模型 ID 不在列表里时，会作为当前选中项显示在列表顶部并标注「自定义」，与网页版一致。模型字段下方的提示也会说明：可以从列表中选择，提供方支持时也可以直接填写模型 ID。

## en

When you create or edit an agent and the model field accepts a typed value, a model ID you typed that isn't in the list now shows as the current selection at the top of the list, marked Custom, as on the web. The hint under the model field now says to pick a model from the list, or type a model ID where the provider allows it.

## ja

エージェントの作成・編集時、モデル欄に直接入力できる場合、入力したモデル ID がリストにないときは、現在の選択としてリストの先頭に「カスタム」と表示されるようになりました（ウェブ版と同じ）。モデル欄の下のヒントでは、リストから選ぶか、プロバイダーが対応していればモデル ID を直接入力できることを案内します。
