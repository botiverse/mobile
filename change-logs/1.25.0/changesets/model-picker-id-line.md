## zh-CN

创建或编辑智能体时，模型选择列表中每个模型的名称下方会以灰色小字显示它的模型 ID（例如内置 Pi 的「provider/modelId」），与网页版一致；搜索时也可以按模型 ID 查找。

## en

When you create or edit an agent, the model picker now shows each model's ID in grey under its name (for the built-in Pi, "provider/modelId"), as on the web, and you can search the list by model ID.

## ja

エージェントの作成時や編集時、モデルの選択リストでは各モデル名の下にモデル ID（内蔵 Pi では「provider/modelId」）がグレーで表示されるようになりました。Web 版と同じ表示で、モデル ID で検索することもできます。
