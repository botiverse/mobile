## zh-CN

键盘打开时在输入框中添加图片，图片编辑器打开后键盘不会再弹出来挡住编辑区域。键盘会在打开相册或相机前收起；编辑完成或取消、回到输入框后，键盘会重新打开。没有选择图片就关闭相册时，键盘也会马上回来。点开待发送的图片时同样如此。键盘原本是收起的，则保持收起。

## en

Adding an image from the message box with the keyboard open no longer brings the keyboard up over the image editor. The keyboard goes down before the photo picker or camera opens, and comes back when you return to the message box after tapping Done or going back. If you close the picker without choosing an image, the keyboard comes back right away. Opening an image waiting above the message box works the same way. If the keyboard was closed, it stays closed.

## ja

キーボードを開いたままメッセージ入力欄から画像を追加しても、画像エディタの上にキーボードが表示されなくなりました。写真の選択やカメラを開く前にキーボードが閉じ、「完了」または戻る操作で入力欄に戻るとキーボードが再び開きます。画像を選ばずに選択画面を閉じた場合は、すぐにキーボードが戻ります。入力欄の上の送信待ちの画像を開いたときも同じです。キーボードを閉じていた場合は閉じたままです。
