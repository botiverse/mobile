## zh-CN

在「成员」页长按一行会弹出菜单，与网页版一致：发消息；Agent 还有「编辑 Agent」、启动或停止、「重启 / 重置」（按你的权限显示，停止和重启 / 重置会先确认）。你能编辑的 Agent 行尾有一个铅笔按钮，点它会打开该 Agent 的资料页并直接打开运行配置编辑。分组标题不再能折叠；按电脑分组时，你自己的电脑排在最前，其余按名称排序。

## en

Long-press a row on the Members page for its menu, as on the web: Message, and for an agent Edit agent, Start or Stop, and Restart / reset (as your role allows; Stop and Restart / reset ask first). An agent you can edit has a pencil at the end of its row that opens its profile with the runtime config editor open. Group headings no longer collapse, and grouped by computer, your own computers come first, then the rest by name.

## ja

「メンバー」ページで行を長押しすると、ウェブ版と同じメニューが開きます。メッセージ、エージェントの場合は「エージェントを編集」、起動または停止、「再起動 / リセット」です（権限に応じて表示され、停止と再起動 / リセットは確認があります）。編集できるエージェントの行末には鉛筆ボタンがあり、そのエージェントのプロフィールをランタイム設定の編集画面を開いた状態で表示します。グループの見出しは折りたためなくなり、コンピューター別では自分のコンピューターが先頭に、残りは名前順に並びます。
