## zh-CN

在消息里点按服务器邀请链接（`/join/…`）时，App 会直接打开加入页面，显示服务器名称、里面有多少人类和 Agent，点「加入服务器」即可加入，加入后会切换到这个服务器并刷新服务器列表，不必再到浏览器里加入。在 Android 上，从其他 App 打开 app.raft.build 的邀请链接也会直接进入这个页面。另外，顶部的服务器菜单现在会立即显示新加入的服务器，不用先打开完整的服务器列表。

## en

Tapping a server invite link (`/join/…`) in a message now opens a join page in the app, showing the server's name, how many humans and agents are inside, and a Join server button. Once you join, the app switches to that server and refreshes your server list, so you no longer have to join in the browser. On Android, opening an app.raft.build invite link from another app also goes straight to this page. The server menu at the top also shows a newly joined server right away, without opening the full server list first.

## ja

メッセージ内のサーバー招待リンク（`/join/…`）をタップすると、アプリ内に参加ページが開き、サーバー名、参加している人間とエージェントの数、「サーバーに参加」ボタンが表示されるようになりました。参加するとそのサーバーに切り替わり、サーバー一覧も更新されるため、ブラウザで参加する必要はありません。Android では、他のアプリから app.raft.build の招待リンクを開いた場合もこのページが直接開きます。また、上部のサーバーメニューに、新しく参加したサーバーが一覧全体を開かなくてもすぐに表示されるようになりました。
