## zh-CN

支持新的运行时 CodeBuddy Code：在电脑和 Agent 中会显示它的名称和图标，并且可以像其他运行时一样在电脑的运行时卡片中登录和退出 CodeBuddy Code。

## en

Added support for the new CodeBuddy Code runtime: Computers and agents show its name and icon, and you can sign CodeBuddy Code in and out from a Computer's runtime card, like other runtimes.

## ja

新しいランタイム CodeBuddy Code に対応しました。コンピューターとエージェントにその名前とアイコンが表示され、他のランタイムと同様に、コンピューターのランタイムカードから CodeBuddy Code にサインイン・サインアウトできます。
