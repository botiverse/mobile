## zh-CN

计算机详情页「此计算机上的 Agent」标题旁新增「创建 Agent」按钮（有管理计算机权限时显示，即使这台计算机上还没有 Agent）。点开就是创建 Agent 表单，并已选好这台计算机，和网页版一致。

## en

The Computer detail page now has a **Create agent** button next to "Agents on this computer" (for people who can manage computers, even when the computer has no agents yet). It opens the create-agent form with this computer already selected, as on the web.

## ja

コンピューターの詳細画面で、「このコンピューターのエージェント」の横に「エージェントを作成」ボタンを追加しました（コンピューターを管理できる場合に表示され、エージェントがまだいなくても表示されます）。タップすると、このコンピューターが選択済みの状態でエージェント作成フォームが開きます。ウェブ版と同じ動作です。
