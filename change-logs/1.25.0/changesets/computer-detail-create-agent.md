## zh-CN

计算机详情页和网页版对齐：「这台 Computer 上的 Agent」标题旁新增「创建 Agent」按钮（有管理计算机权限时显示，即使还没有 Agent），点开就是已选好这台计算机的创建 Agent 表单。「检测到的运行时」只列出已安装的运行时，其余的点「显示所有支持的运行时」再展开。创建时间、创建者和所有者并排显示，所有者旁直接放「转移所有者」「设为我的」。Agent 行在线/离线只显示状态色块，其他状态在模型下方用文字说明；「Agent 工作区」标题带文件夹图标，空状态文案和网页版一致。

## en

The Computer page now matches the web. "Agents on this computer" has a **Create agent** button (for people who can manage computers, even with no agents yet) that opens the create-agent form with this computer already selected. Detected runtimes lists only the installed ones, with **Show all supported** to reveal the rest. Created, Creator and Owner sit side by side, with Transfer owner and Make it mine right next to the owner. Agent rows show a plain online/offline as the status light alone, and any other status as words under the runtime and model. "Agent workspaces" has a folder icon, and the empty states use the web's wording.

## ja

コンピューターの詳細画面をウェブ版に合わせました。「このコンピューターのエージェント」の横に「エージェントを作成」ボタンを追加しました（コンピューターを管理できる場合に表示され、エージェントがまだいなくても表示されます）。タップすると、このコンピューターが選択済みのエージェント作成フォームが開きます。「検出されたランタイム」にはインストール済みのものだけを表示し、残りは「対応しているものをすべて表示」で表示できます。作成日・作成者・オーナーを横に並べ、オーナーのすぐ横に「オーナーを移す」「自分のものにする」を置きました。エージェントの行では、オンライン/オフラインはステータスの色だけで示し、それ以外の状態はランタイムとモデルの下に文字で表示します。「エージェントのワークスペース」にはフォルダーアイコンが付き、空の状態の文言もウェブ版と同じになりました。
