## zh-CN

在联合频道里只能断开连接的其他服务器管理员，不再在频道信息中看到“编辑”；频道名称和描述由主服务器编辑。

## en

In a joint channel, an admin from another server who can only disconnect the channel no longer sees Edit on the channel info; the channel's name and description are edited by the host server.

## ja

共同チャンネルで接続解除のみ可能な別サーバーの管理者には、チャンネル情報の「編集」が表示されなくなりました。チャンネル名と説明はホストサーバーが編集します。
