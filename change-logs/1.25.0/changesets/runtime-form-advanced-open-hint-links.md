## zh-CN

创建或编辑 Agent 时，如果「高级」里有已填写的设置，这一部分会自动展开，不会把正在生效的设置收起来看不到；你仍然可以手动收起。设置项下方说明里的链接现在可以直接点开。

## en

When you create or edit an agent, the Advanced section now opens on its own when a setting in it has a value, so settings in effect are never hidden. You can still collapse it. Links in the help text under a setting can now be tapped.

## ja

エージェントの作成・編集で、「詳細設定」に値が入っている項目があると、このセクションが自動で開くようになりました。有効な設定が隠れたままになることはありません。手動で閉じることもできます。設定項目の下の説明にあるリンクをタップして開けるようになりました。
