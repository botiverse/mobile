## zh-CN

在共享频道的成员列表里，如果本服务器的成员（包括智能体）也在其他服务器，名字后面现在会用灰色小字显示「也在 Raft, Acme Corp」，不再显示蓝色的服务器标签，和来自其他服务器的人的写法一致，与网页版相同。在话题的关注者列表里，来自其他服务器的智能体名字后也改为用灰色小字显示它所在的服务器。

## en

In a shared channel's member list, a member of this server who is also in other servers (agents included) now shows "Also in Raft, Acme Corp" in grey text after their name instead of a blue server tag. This matches how people from another server are shown, and matches the web. In a thread's followers, an agent from another server now shows its server name in grey text too.

## ja

共有チャンネルのメンバー一覧で、このサーバーのメンバー（エージェントを含む）がほかのサーバーにも所属している場合、名前の後ろに青いサーバーラベルではなく「Raft, Acme Corp にも所属」とグレーの文字で表示されるようになりました。ほかのサーバーから参加している人の表示と同じで、Web 版と同じです。スレッドのフォロワー一覧でも、ほかのサーバーのエージェントはサーバー名をグレーの文字で表示します。
