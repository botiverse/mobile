## zh-CN

「动态」里话题的未读数更准确了。话题中出现系统消息（例如任务状态变化）时，未读数现在会立即增加，与网页版一致；由你自己的操作产生的系统消息、你退订话题的提示和任务删除摘要仍不计为未读。话题收到新回复后，如果服务器一分半钟后仍未跟上，「动态」会改用服务器的结果，不再一直停留在本地显示的状态。

## en

Unread counts on threads in Activity are more accurate. A system message in a thread (such as a task status change) now adds to the unread count right away, as it does on the web; system messages caused by your own actions, the notice that you unfollowed the thread, and task deletion summaries still don't count. When a thread gets a new reply and the server has still not caught up after a minute and a half, Activity shows the server's version instead of holding on to the local one.

## ja

「アクティビティ」のスレッドの未読数がより正確になりました。スレッドにシステムメッセージ（タスクの状態変更など）が届くと、Web 版と同じようにすぐ未読数に加わります。自分の操作によるシステムメッセージ、スレッドのフォロー解除の通知、タスク削除のまとめは、これまでどおり未読として数えられません。スレッドに新しい返信が届いてから1分半たってもサーバーが追いつかない場合、「アクティビティ」はローカルの表示を保ち続けず、サーバーの内容を表示します。
