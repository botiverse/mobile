## zh-CN

在宽屏上，从任务页打开的任务改为显示在列表右侧的一栏，和网页版一样，不再是盖住列表的居中弹窗。列表可以继续滚动、筛选和点选，点另一个任务就会在这一栏里换成它，当前打开的任务在列表里会高亮显示。拖动这一栏的左边缘可以调整宽度（默认 400，最窄 320），宽度会被记住。栏顶的「展开」让任务占满整行，再点「恢复」回到原来的布局；「关闭任务」关闭这一栏。按返回键时，先退出展开，再关闭这一栏。窗口太窄、列表旁边放不下这一栏时，任务会占满整行，关闭后回到列表。手机上仍然以单独页面打开任务。

## en

On a wide screen, a task you open from the Tasks page now shows in a column beside the list, as on the web, instead of a centered window over the list. The list stays in use: you can scroll, filter and pick another task, which replaces the one in the column, and the open task is highlighted in the list. Drag the column's left edge to resize it (400 by default, 320 at the narrowest); the width is remembered. Expand in the column's header makes the task fill the row, and Restore brings the list back; Close task closes the column. Back first leaves Expand, then closes the column. When the window is too narrow for the list and the column side by side, the task fills the row and closing it returns to the list. On a phone a task still opens as its own page.

## ja

ワイド画面では、タスクページから開いたタスクが、リストを覆う中央のウィンドウではなく、ウェブ版と同じくリストの右側の列に表示されるようになりました。リストはそのまま使えます。スクロールや絞り込みができ、別のタスクを選ぶと列の中身がそのタスクに替わり、開いているタスクはリストで強調表示されます。列の左端をドラッグすると幅を変えられ（標準は 400、最小は 320）、幅は記憶されます。列のヘッダーの「拡大」でタスクが行いっぱいに広がり、「元に戻す」で元の配置に戻ります。「タスクを閉じる」で列を閉じます。「戻る」では、まず拡大を解除し、次に列を閉じます。ウィンドウが狭くリストの横に列を置けないときは、タスクが行いっぱいに表示され、閉じるとリストに戻ります。スマートフォンでは、これまでどおりタスクを単独のページで開きます。
