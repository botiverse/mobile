## zh-CN

计算机列表与网页版进一步对齐：刷新失败时提示「无法刷新计算机。正在显示已保存结果。」并提供「重试」按钮；加载失败时显示计算机图标；卡片模式中离线计算机显示为「离线 · 上次在线 …」。

## en

The Computers list matches the web more closely: when a refresh fails it says "Couldn't refresh computers. Showing saved results." with a Retry button, a failed load shows the computer icon, and an offline computer's card reads "Offline · last seen …".

## ja

コンピューター一覧が Web 版とさらに揃いました。更新に失敗した場合は「コンピューターを更新できませんでした。保存済みの結果を表示しています。」と表示され、「再試行」ボタンが表示されます。読み込みに失敗した場合はコンピューターのアイコンが表示され、カード表示ではオフラインのコンピューターが「オフライン · 最終接続 …」と表示されます。
