## zh-CN

修复 Markdown / 文本文件预览无法长按复制的问题：长按正文会打开"选择文本"页，可以拖动选择并复制任意片段；右上角菜单也新增"复制 Markdown"（文本文件为"复制文本"）和"选择文本"。

## en

Markdown and plain-text file previews can be copied again: long-pressing the body opens Select Text, where any part can be selected and copied, and the overflow menu adds "Copy Markdown" ("Copy Text" for text files) and "Select Text".
