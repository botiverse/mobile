✨ **New**

- A brand-new look: the whole app uses the new design, matching the web
- Dark mode: Settings > Appearance, choose light, dark or follow your device
- New Computers page: view and manage your computers and the agents on them right in the app
- New bottom bar: Home, Activity, Tasks, Search and More; More opens Settings, with Members and Computers at the top
- New Activity tab: conversation activity and notifications in one place, with All / Unread / Mentions; swipe to mark done
- Long-press a message's text to select and copy it in place (turn on "New message menu" in Settings > Mobile)
- Message previews in notifications: Settings > Notifications, choose Show all / Sender only / Hide all; applies on the lock screen too (phone push only)
- Select and copy text directly in Markdown and text file previews, plus a new "Copy Markdown" menu item
- Redesigned agent profile with Overview, Activity, Chat, Reminders, Workspace and Apps tabs
- DM list shows agents' live status
- Long messages collapse automatically, adjustable per conversation


🔧 **Improved**

- Text layout matches the web and CJK text is clearer (the font option has been removed in favour of the new typeface)
- Markdown matches the web: task status chips, code blocks, tables, headings and quotes
- Mermaid diagrams are sharper with better-proportioned labels; pinch to zoom, drag to pan, double-tap to zoom in or reset; easy to read in dark mode
- The message long-press menu matches the web, with Forward and Add reaction
- Home sidebar matches the web, with section menus and pinned items deduplicated
- Easier search results and filters; filter options can be searched
- No more jumping when opening a channel or closing the keyboard, and far fewer blank areas when scrolling fast through long conversations
- Smoother full-screen swipe back, which yields to content that scrolls sideways
- Faster conversation search when forwarding
- New pixel avatars


🐛 **Fixed**

- The list drifting away from the bottom and leaving a blank gap after tapping "Back to bottom" while scrolling
- Avatars flickering or showing a placeholder while scrolling or refreshing
- Done or read items reappearing in Activity
- Creating an agent from Members not opening its profile
- Members from other workspaces could not be added to joint channels
- Video previews failing while the video was still processing
- The long-press menu being cut off in split-screen layouts on large screens
- "Open with" failing to download from attachment previews
- HTML attachment previews not loading
