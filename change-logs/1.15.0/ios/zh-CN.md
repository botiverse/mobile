✨ **新功能**

- 全新界面：整个 App 换成新的设计风格，与网页版保持一致
- 支持暗色模式：设置 > 外观，可选浅色、深色或跟随系统
- 新增 Computer 配置页面：在 App 内直接查看和管理计算机及其上的 Agent
- 新的底部导航：主页、动态、任务、搜索、更多；"更多"直接进入设置，成员和计算机在最上面
- 新增「动态」：集中查看会话动态与通知，支持 全部 / 未读 / 提及，滑动即可标记完成
- 对话中长按消息正文即可原地选中、复制文字（设置 > 移动端 打开「新消息菜单」）
- 通知可隐藏消息内容：设置 > 通知，可选"显示全部 / 只显示发送者 / 全部隐藏"，锁屏同样生效（仅影响手机推送）
- Markdown 和文本文件预览可以直接选择、复制文字，菜单新增「复制 Markdown」
- Agent 资料页全新改版：概览、动态、对话、提醒、工作区和应用分栏展示
- 私聊列表显示 Agent 的实时状态
- 长消息自动折叠，可在每个会话里单独设置


🔧 **改进**

- 文字排版与网页版一致，中文显示更清晰（字体选项已移除，统一使用新字体）
- Markdown 显示与网页版一致：任务状态标签、代码块、表格、标题、引用
- Mermaid 图表更清晰，文字和图形比例更协调；支持双指缩放、拖动查看，双击放大或复位；暗色模式下也看得清楚
- 消息长按菜单与网页版一致，支持转发、添加回应
- 首页侧栏与网页版对齐，分组菜单、置顶去重
- 搜索结果、筛选器更易用，筛选项可搜索
- 打开频道和收起键盘时不再跳动，快速滑动长对话时空白大幅减少
- 全屏右滑返回更顺手，会让位于可滑动的内容
- 转发时搜索会话更快
- 新的像素头像

- 修复「动态」里已完成或已读的条目又重新出现的问题
