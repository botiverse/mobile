✨ **新機能**

- 新しいデザイン：アプリ全体を Web 版と同じ新しいデザインに刷新
- ダークモードに対応：設定 > 外観 で、ライト・ダーク・デバイスに合わせるから選択
- コンピューター画面を新設：アプリ内でコンピューターとその上のエージェントを確認・管理できます
- 新しい下部バー：ホーム、アクティビティ、タスク、検索、その他。「その他」から設定が開き、メンバーとコンピューターが一番上にあります
- 新しい「アクティビティ」：会話の動きと通知をまとめて表示。すべて / 未読 / メンション、スワイプで完了にできます
- 会話でメッセージ本文を長押しすると、その場でテキストを選択・コピーできます（設定 > モバイル で「新しいメッセージメニュー」をオン）
- 通知に表示するメッセージ内容を選べます：設定 > 通知 で「すべて表示 / 送信者のみ / すべて非表示」。ロック画面にも適用されます（スマートフォンのプッシュ通知のみ）
- Markdown とテキストファイルのプレビューでテキストを直接選択・コピーでき、メニューに「Markdown をコピー」を追加
- エージェントのプロフィールを刷新：概要、アクティビティ、チャット、リマインダー、ワークスペース、アプリのタブ
- DM 一覧にエージェントの状態をリアルタイム表示
- 長いメッセージを自動で折りたたみ、会話ごとに設定できます
- Google Play 開発者サービスのない端末に「バックグラウンドで接続を維持」を追加。オンにすると新着メッセージの通知を受け取れます


🔧 **改善**

- 文字組みを Web 版に合わせ、日本語・中国語の表示がより鮮明に（フォント設定は廃止し、新しい書体に統一）
- Markdown の表示を Web 版に統一：タスクのステータス、コードブロック、表、見出し、引用
- Mermaid 図がより鮮明になり、文字と図形のバランスも改善。ピンチで拡大、ドラッグで移動、ダブルタップで拡大・リセット。ダークモードでも見やすく
- メッセージの長押しメニューを Web 版に統一（転送、リアクションの追加）
- ホームのサイドバーを Web 版に合わせました（セクションメニュー、ピン留めの重複排除）
- 検索結果とフィルターが使いやすくなり、フィルター項目を検索できます
- チャンネルを開いたときやキーボードを閉じたときに画面が跳ねなくなり、長い会話を素早くスクロールしたときの空白も大幅に減りました
- 転送時の会話検索が速くなりました
- 新しいピクセルアバター


🐛 **修正**

- スクロール中に「一番下へ」をタップすると、リストが下から離れて空白ができる問題
- スクロールや更新時にアバターがちらつく、またはプレースホルダーになる問題
- アクティビティで完了・既読にした項目が再表示される問題
- メンバー画面からエージェントを作成してもプロフィールが開かない問題
- 共有チャンネルに他のワークスペースのメンバーを追加できない問題
- 動画の処理中にプレビューが失敗する問題
- 大画面の分割表示で長押しメニューが切れて表示される問題
- Google Play 開発者サービスのない端末でプッシュ登録の状態が正しく表示されない問題
- ホーム画面ウィジェットのピクセルアバターが正しく表示されない問題
