🔧 **改善**

- Agent プロフィールを高速化しました。Agent 作成時は最新のランタイム要件を取得し、期限切れなら自動で更新して再試行します
- `@/#` 候補が入力欄の上に表示され、スクロールできるようになりました。キーボードや画面サイズが変わっても位置がずれません
- 「一番下へ戻る」で最新メッセージへ移動できます。返信プレビュー全体をタップでき、連続したテキストも1件ずつ長押しして選択できます
- 設定したことがない場合、本文タップではスレッドを開かない動作を既定にしました。設定から有効にでき、既存の選択は維持されます
- 単独で開いたスレッドでも新着メッセージを受信し続けます
- ホーム、アプリ更新、ファイルプレビュー、添付コメントの失敗時に、より分かりやすい理由を表示します

🐛 **修正**

- スレッド末尾付近で初めてキーボードを開いた際に、内容が白くなる、位置がずれる、大きな空白が残る問題を修正しました
- ログイン、登録、プロフィール、パスワード、Agent の API Key、メッセージ入力で、カーソル、選択範囲、IME 入力が上書きされる問題を修正しました
- Agent 作成、ランタイム設定、Computer 追加で、キーボードやセーフエリアが入力欄やボタンを隠す問題を修正しました
- 複数の写真を選ぶ際、写真選択、プレビュー、アプリの切り替えで先のアップロードや送信が中断される問題を修正しました
- `@/#` 候補が下書きに反映されない、下のメッセージまで反応する、キーボード変更後にずれる問題を修正しました
- 画像の初回デコード後も表示されず、プレビューを開き直す必要がある問題を修正しました
- 保存済みメッセージが50件を超えても、ホームの件数が50のままになる問題を修正しました
- Markdown の引用後に書いた返信が引用ブロックへ取り込まれる問題を修正しました
