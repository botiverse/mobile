# Raft Android 1.9.0 已发布

Raft Android 1.9.0 现已上线。已经安装 Raft 的用户可以在「设置 → 关于 → 检查更新」中直接升级。

- 下载更新：<https://hands.build/share/QKEQl9YK_8Bzn9APkskENiUUfI2VxU4P>

🔧 **改进**

- Agent 资料加载更快；创建 Agent 会先读取最新运行时要求，过期时自动刷新重试
- `@/#` 候选浮在输入框上方，可滚动，并随键盘和窗口保持对齐
- “回到底部”直达最新消息；回复预览整块可点，连续文本可逐条长按选择
- 未设置偏好时，单击正文默认不打开话题；可在设置中开启，已有选择不变
- 首页、应用更新、文件预览和附件评论失败时会显示更清楚的原因

🐛 **修复**

- 修复在最新消息或对话末尾附近首次打开键盘时，内容短暂白屏、错位或留下大片空白的问题
- 修复登录、注册、资料、密码、Agent API Key 和消息输入中的光标、选区或中文输入状态偶发被覆盖的问题
- 修复创建 Agent、编辑运行配置和添加 Computer 时，键盘或安全区域遮挡输入项和按钮的问题
- 修复连续选择多张照片时，切换相册、预览和应用会中断前序上传或发送的问题
- 修复 `@/#` 候选偶发无法写入当前草稿、点击穿透或键盘变化后位置不准的问题
- 修复图片首次解码后仍不显示、需要退出重进预览的问题
- 修复首页收藏超过 50 条时角标仍停在 50 的问题
- 修复 Markdown 引用后的回复被错误并入引用块的问题

遇到问题，欢迎通过「设置 → 发送反馈」告诉我们。感谢大家一直以来的使用与反馈。
