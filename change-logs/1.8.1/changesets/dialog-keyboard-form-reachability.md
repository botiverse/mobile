## zh-CN

创建 Agent、编辑 Agent 运行配置和添加 Computer 时，软键盘不再遮住表单底部；现在可以滚动到 API Key 等靠下的输入项并继续编辑，编辑运行配置时「保存 / 取消」也会始终留在键盘上方，不再被挤出屏幕。

## en

The keyboard no longer traps the bottom of Create Agent, agent runtime settings, or Add Computer forms. Lower fields such as API Key remain reachable for editing, and the Save / Cancel row of the runtime settings dialog now stays above the keyboard instead of being pushed off screen.
