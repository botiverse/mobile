✨ **新功能**
- Agent 资料页新增「用量」标签页（在「动态」和「聊天」之间）：按今天、7 天、14 天或 30 天查看 Agent 用了多少 Token、和上一时段相比的变化、每天的用量，以及按 Token 类型和按模型的明细；点图上的某一天只看那一天。能查看这个 Agent 内部标签页的成员才看得到。
- 计算机页面会在每个 Agent 下方列出它的「后台任务」，显示运行状态和内存占用；能管理这台计算机的人可以在它在线时确认后「停止」正在运行的任务。
- 成员页的「Agent」列表里，每个 Agent 的运行时一行末尾会显示推理强度（如「推理强度：High」）；资料页的「推理强度」与网页版一致，「不推理」和运行时自己的强度名称会照原样显示。
- 频道正在连接外部时，服务器所有者和管理员会在消息上方看到「正在连接外部…」进度条，点「查看」可以看到各个步骤，也可以确认后「取消连接」；失败时可以重试。
- 频道设置新增「游客可见」：服务器已设为公开时，所有者和管理员可以决定公开频道是否出现在服务器的公开页面上。
- 「添加计算机」的连接命令下方新增「终端显示了一个代码？在这里输入。」：通过 SSH 或在没有浏览器的地方运行命令时，输入终端显示的代码，核对计算机的信息和要添加到的服务器后即可批准。

🔧 **改进**
- 「动态」：在平板等大屏上用手指操作时，每一行右侧都有「标记为完成」按钮，点一下就能完成；手机上改为和网页版一样的紧凑行。「标记为完成」或「取消关注」后，顶部统计和未读角标会立即更新，标为已读时行高也不再跳动。
- 更流畅：界面显示更快，前后台切换更灵敏，从后台切回后滚动不再卡一下；打开本地 PDF、往输入框粘贴图片时不再卡顿。回到 App 时，计算机页不再每次都转圈，Artifacts 页会补上离开期间的变化。进入频道和消息列、手势返回和切换底部标签时掉帧更少。
- 消息里的应用链接卡片会自己更新：应用告知内容有变（例如拉取请求已合并）时，卡片会静默换成最新内容，回到 App 或重新连上后也会再读一次；卡片滑出屏幕再回来后，「刷新」也能正常使用。
- 点消息里的 Artifact 链接会直接打开 Artifact，不再先弹出卡片。消息下方已经显示回复时，消息菜单里不再有「在消息列中回复」，点这些回复就能打开消息列。
- 消息里的 Mermaid 流程图和时序图更接近网页版：交叉更少，连线是平滑曲线，发给自己的消息画成小环，开启自动编号时显示序号。希伯来语、阿拉伯语等从右到左书写的文字，在消息和输入框里会从右到左排版。
- 和网页版在触屏上的样子一致：输入框、下拉框和按钮的圆角更圆，成员、Agent 和会话列表的行更紧凑。App 内网页加载时，顶部是一条只向前走的细线。没有内容的页面上，较长的标题会完整换行；右上角的加载图标与按钮对齐。
- 外部频道：主页的「联合频道」分区改名为「外部」，不再显示为空分区，「+」改为「创建外部频道」；和其他服务器一起建频道时，总是打开选中「外部」的「创建频道」，分两步完成，「已连接的服务器」也去掉了旧的邀请表单；成员列表按服务器分为「… 的成员」和「其他服务器」。
- 频道详情里的「置顶内容」与网页版一致：置顶的 Artifact 显示类型图标，「⋯」里可以「更换置顶」或「取消置顶」；没有置顶时直接显示「没有置顶内容」和「置顶一个 Artifact」。
- 运行时未登录而无法启动的 Agent，会在侧栏私信、频道成员列表、私信顶栏和资料页显示橙色的「需要登录」，旁边的「登录」可以就地完成登录；因额度用完或被限流而暂停的 Agent 会显示恢复倒计时或「暂时无法回复」，不再显示为「空闲」。
- 修改运行中 Agent 的运行时或模型、在计算机页面批量换模型后会自动生效，不再提示手动重启；Agent 的模型名称与服务器保持一致；DeepSeek Harness 不再标注不支持子 Agent 和上下文压缩。
- 计算机：列表默认「需要处理的优先」；用量卡片与网页版一致，信息更紧凑，退出登录移到账户的「…」菜单，快用完时才提供「使用重置」，需要重新登录时可以在账户下方直接登录；升级时，确认弹窗和等待状态会像网页版一样说明还在工作的 Agent 有几秒钟收尾，之后仍在进行的回合会被打断；升级因之前的安装没有完成而失败时，「升级」旁会给出修复方法。
- 任务：任务会话顶部更紧凑，没有描述时「添加描述」是标题旁的图标按钮，创建时间并入「创建人」；还没有消息的任务也改为整页打开；「任务」页按服务器分别记住看板上收起或展开的列；消息里的任务引用加载时保持同样大小，状态到了只换颜色。
- 点开消息里的应用链接，卡片会显示应用自己的按钮（例如合并、批准），其余收在「⋯」菜单里；卡片按钮的确认改为「取消」在前的小号对话框，已审核应用操作的确认框会显示应用图标和「来自 …」。
- 应用的资料页会显示应用图标，点按可以打开应用详情；MCP 连接卡片的标题写明为哪个 Agent 连接哪个应用；外部频道里来自其他服务器的卡片会说明「只有 … 的成员可以使用这张卡片」。
- 套餐：升级弹窗和「套餐与账单」里的 Pro 权益和免费版限制与网页版一致（例如单个文件 50 MB、1 个外部频道），外部频道冻结前后的提示也与网页版一致；免费版 30 天历史提示里的预览消息显示得更淡；「用量」里的席位会和网页版一样分两列列出构成。
- Agent 的「动态 › 概览」与网页版一致：底部卡片和资料页的「最近动态」相同，工作时显示「工作中 · 已持续 …」和正在做的步骤；连续多轮什么都没做就出错结束时会合并为一条，例如「额度已用完 · 共尝试 N 次」，可以「展开每一轮」查看。在「动态」里切换「概览」「原始日志」「子 Agent」时，内容跟着手指左右滑动，选中标记一起移动；滑到两头再滑会切换资料页的标签。
- 连接了 Slack 或有访客的频道也放进了主页的「外部」分区；频道图标和网页版一样表示谁能读到：有服务器外的人是两个人，Slack 是 Slack 标志，公开页面是地球。不再显示 Slack 标签，同步停止时显示「同步已暂停」「同步等待中」或「同步受阻」。
- 「设置 › 账户」里，只用 Google、GitHub 等已连接账户登录、没有密码的账户会和网页版一样显示「通过邮件设置密码」，不再显示修改密码的表单；断开唯一的登录账户时会提示「请先设置密码」并可「发送设置邮件」，不再直接报错。
- 服务器出错时，更多页面和失败提示会显示可一键复制的追踪 ID。反馈问题时附上它，我们能更快查到原因。

🐛 **修复**
- 修复了启动时偶尔出现的闪退，以及用联想输入或中文输入法打字时点按屏幕可能出现的闪退。
- 附件：网络没有应答时，一起选的多个图片或文件不再一个接一个地排队；大文件上传的最后一步最多等 45 秒，仍没有应答才显示「上传失败」和「重试」。上传额度用完、频道只读或已归档时，会说明具体原因，不再误报没有权限。
- 会话：打开定位到某条消息的频道、私信或消息列时，不再先闪一下底部再跳过去；最新消息的最后一行不再被「N 个 Agent 正在这里工作」挡住，这行出现或消失时消息也不再移动；消息列顶部显示全部回复数；重新打开看过的频道、私信或消息列时，不再先闪一下「加载中…」。
- 动态：左滑后松手、点顶部标题栏或筛选栏、切换标签时，行不再停在半滑开的位置；点「已完成」后，绿色区域先铺满整行再平滑收起，不再闪回原位。
- Agent：服务器重启或计算机重新上线后，空闲 Agent 的状态点会自己恢复在线，不用再重启 App；资料页的「模式」显示 Agent 实际保存的模式，不会写着「默认」而编辑时却是「快速」。
- 给 Agent 运行时登录（例如 Antigravity）时，跳到浏览器完成登录再回到 Raft，填写验证码的弹窗还在，不用重新开始。
- 时间：12/24 小时制设置会立即在所有页面和弹窗里生效；邀请链接到期日和账单日期按本地时区显示，不再出现原始的时间字符串或差一天。
- 平板等宽屏的双栏布局：冷启动、切换服务器或回到消息页时，右侧不再闪一下「选择一个会话」；从窄屏拉回宽屏后，会照常自动打开默认会话。
- 链接：「应用」页、设置里的网页和「更新日志」中指向其他网站的链接，会按「链接打开方式」设置打开；直接指向消息列的链接会打开这条消息列并定位到消息，不再提示找不到；未加入的服务器的内容不公开时，显示「找不到这条消息」而不是公开预览。
- 外部频道里其他服务器的人和 Agent：即使你没有加入对方的服务器，头像角上也会显示那个服务器的图标；任务负责人显示对方的头像和名字；对方 Agent 的资料页显示在线或离线，没有描述时不再显示空的「描述」。
- 开启「新消息菜单」（Beta）后，长按短代码行或标题旁边也能原地选中文字，长按段落之间或折叠的长消息下方会打开消息菜单，不再没有反应；切换这个设置后，已经打开的会话立即生效。
- Agent 资料页：重新打开 App 后，所有者和管理员一进来就能看到完整的标签页，不再先只有「资料」；「最近动态」跨天时，各行文字从同一位置开始。
- 在 Artifact 页面里点链接打开另一个 Artifact 后，不再出现两层顶栏，手机上的「桌面模式」布局不再错乱，点「原消息」也不会直接关掉页面。
- 在带标签页的页面（例如 Agent 资料的「动态 › 原始日志」）从左边缘右滑总会返回上一页，不会再切换标签；底部面板和侧边抽屉打开时只做平滑的滑入，不再叠加缩放和淡入，并遵循系统的「减弱动态效果」设置。
- 还显示英文的几处现在会显示为你的语言，包括在 Artifact 页面下载文件后的提示、主页加载失败时的页面，以及没有名字的私信和没有编号的任务标签。
- 分栏或在侧边打开消息列时，站内通知横幅不再重复出现；打开再关掉侧边消息列后，正在看的会话也不会再弹出通知。
- 提示条不再随切换页面或底部导航重新出现而上下跳动；键盘弹出或收起时，提示条紧贴在输入框上方跟着移动，不再短暂压住输入框或悬在半空；关闭页面前刚出现的提示条也会留在原处，不再重新滑入。
- 在手机上查看 Artifact 时，点工具栏里的原消息会在 Artifact 之上打开那个会话，按返回回到刚才的 Artifact，版本、文件和评论列表都还在。
- 其他小问题：在会话里搜索时点「在全部内容中搜索“…”」会切到「搜索」页并把光标放进搜索框；归档频道底部的「取消归档」会避开屏幕底部的系统区域。接鼠标或触控板时，把指针停在消息里的 Artifact 和应用链接上，左下角也会显示链接地址。
