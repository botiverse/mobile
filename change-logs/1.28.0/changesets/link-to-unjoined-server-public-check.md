## zh-CN

打开你未加入的服务器的链接时，如果这个服务器或链接指向的会话没有公开，不再显示公开预览，而是显示「找不到这条消息」。公开预览还在加载或连不上服务器时，页面也不再提示这是公开预览。

## en

Opening a link to a server you haven't joined no longer shows a public preview when the server, or the conversation the link points to, isn't public; you now see "Message not found". While a public preview is still loading, or when the server can't be reached, the page no longer says it is a public preview.

## ja

参加していないサーバーへのリンクを開いたとき、そのサーバーやリンク先の会話が公開されていない場合は、公開プレビューではなく「メッセージが見つかりません」と表示するようになりました。公開プレビューの読み込み中やサーバーに接続できないときも、公開プレビューであるとは表示しなくなりました。
