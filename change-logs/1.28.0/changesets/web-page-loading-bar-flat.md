## zh-CN

App 内网页（应用内浏览器、设置里的网页）加载时，顶部的进度条改为贴着上边缘的一条细线，两端平直并延伸到屏幕两侧，不再是圆角的胶囊形。

## en

While a web page loads in the app (the in-app browser and the settings web pages), the progress bar is now a thin line flush with the top edge, with square ends reaching both sides of the screen, instead of a rounded pill.

## ja

アプリ内の Web ページ（アプリ内ブラウザ、設定の Web ページ）の読み込み中に表示される進捗バーが、上端に沿った細い線になりました。両端は角のない直線で画面の左右いっぱいに伸び、角丸のピル形ではなくなりました。
