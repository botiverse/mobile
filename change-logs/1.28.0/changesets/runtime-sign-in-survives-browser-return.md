## zh-CN

给 Agent 运行时登录（例如 Antigravity）时，跳到浏览器完成登录再回到 Raft，填写验证码的弹窗还在，不用重新开始。

## en

Signing in to an agent runtime (for example Antigravity) no longer loses the code dialog when you come back from the browser: finish the sign-in where you left it.

## ja

エージェントのランタイム（Antigravity など）にサインインするとき、ブラウザから Raft に戻ってもコード入力のダイアログが残り、最初からやり直す必要がなくなりました。
