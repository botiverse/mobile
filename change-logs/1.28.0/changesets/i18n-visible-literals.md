## zh-CN

几处还显示英文的地方现在会显示为你的语言：
- Android 上页面无法显示时出现的错误页：“出了点问题”、下面的说明（仍带有错误代码），以及“重新加载”“关闭”按钮。这一页使用手机的系统语言。
- 在 Artifact 页面里下载文件后的提示，例如“已保存到系统下载”；文件之前已经下载过时，提示“已经下载过”。
- 主页加载失败时页面的标题、副标题和“重试”按钮，以及频道成员页打不开时的标题。某个标签页因内部错误无法显示时，会显示通用的出错提示，不再显示开发用的英文说明。
- 消息下方没有编号的任务标签显示“任务”；长按应用图标出现的快捷菜单里，没有名字的私信显示为“私信”；选中的图片没有文件名时，图片预览的标题显示“图片预览”。

## en

A few places that still showed English now appear in your language:
- On Android, the error screen shown when a page can't be displayed: "Something went wrong", the explanation under it (which still includes the error code), and the Reload and Close buttons. This screen uses your phone's system language.
- The message after you download a file from an Artifact page, such as "Saved to Downloads", or "Already downloaded" when the file was downloaded before.
- When Home can't load, the page's title, subtitle and Retry button, and the title of a channel's members page when it can't open. When a tab can't be shown because of an internal error, it shows the app's usual error message instead of developer text.
- A task tag under a message with no task number reads "Task". In the shortcut menu you get by long-pressing the app icon, a direct message without a name reads "Direct Message". The image preview title reads "Image preview" when the picked image has no file name.

## ja

英語のまま表示されていたいくつかの箇所が、表示言語で表示されるようになりました：
- Android でページを表示できなかったときのエラー画面：「問題が発生しました」、その下の説明（エラーコードは引き続き表示されます）、「再読み込み」「閉じる」ボタン。この画面は端末のシステム言語で表示されます。
- Artifact のページからファイルをダウンロードしたあとのメッセージ（「ダウンロードに保存しました」など）。以前にダウンロードしたファイルでは「すでにダウンロードされています」と表示します。
- ホームを読み込めなかったときのページのタイトル、サブタイトル、「再試行」ボタンと、チャンネルのメンバーページを開けなかったときのタイトル。内部エラーでタブを表示できないときは、開発者向けの英語ではなく、通常のエラーメッセージを表示します。
- メッセージの下に表示される番号のないタスクのタグは「タスク」と表示します。アプリアイコンを長押ししたときのショートカットメニューでは、名前のないダイレクトメッセージを「ダイレクトメッセージ」と表示します。選んだ画像にファイル名がないとき、画像プレビューのタイトルは「画像プレビュー」と表示します。
