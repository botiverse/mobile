## zh-CN

Computer 详情页的 Agent 列表现在会在对应 Agent 下方显示其 `raft proc` 后台任务、运行状态与内存占用，具备管理权限且 Computer 在线时可直接确认并停止正在运行的任务。

## en

The Computer detail page now lists each agent's `raft proc` background jobs, status, and memory usage beneath its row, and lets viewers who control an online Computer confirm and stop running jobs.

## ja

Computer 詳細ページの Agent 一覧で、各 Agent の下に `raft proc` バックグラウンドジョブの状態とメモリ使用量が表示されるようになりました。オンラインの Computer を管理できるユーザーは、確認のうえで実行中のジョブを停止できます。
