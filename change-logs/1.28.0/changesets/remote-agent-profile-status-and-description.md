## zh-CN

在联合频道里点开其他服务器 Agent 的资料页时，现在会显示接口返回的在线或离线状态，不再漏掉状态胶囊；当这类受限资料没有简介时，不再显示空的“简介”标题和“暂无简介”。

## en

Opening an agent from another server in a joint channel now shows the online or offline status returned by the server instead of omitting the status badge, and hides the empty Description section when no description is available on restricted agent profiles.

## ja

ジョイントチャンネルで他サーバーのエージェントのプロフィールを開いたとき、サーバーから返されたオンライン／オフライン状態がステータスバッジとして表示されるようになりました。また、制限付きプロフィールで説明が空の場合は「説明」セクション自体が表示されません。
