## zh-CN

成员页的「Agent」标签下，每个 Agent 的运行时一行末尾现在会显示它的推理强度，例如「推理强度：High」，与它资料页上的「推理强度」一致：没有设置时显示「默认」，不支持推理强度的运行时和应用机器人不显示。资料页的「推理强度」也改为与网页版相同：Pi 的「不推理」、Kimi Code 等运行时自己的强度名称会照原样显示，不再显示为「默认」；Kimi Code 的 Agent 也总会显示这一行。

## en

On the Members page's Agents tab, each agent's runtime line now ends with its reasoning effort, such as "Reasoning: High", the same value as the Reasoning row on its profile: "Default" when none is set, and nothing for a runtime that takes no reasoning effort or an App Bot. The profile's Reasoning row now reads as on the web too: Pi's "No reasoning" and a level a runtime names itself, such as Kimi Code's, show as they are instead of "Default", and a Kimi Code agent always has the row.

## ja

メンバーページの「エージェント」タブで、各エージェントのランタイムの行の末尾に推論の強度（「推論の強度：High」など）が表示されるようになりました。プロフィールの「推論の強度」と同じ値で、未設定なら「デフォルト」、推論の強度がないランタイムやアプリボットでは表示されません。プロフィールの「推論の強度」も Web 版と同じになり、Pi の「推論なし」や Kimi Code などのランタイム独自の強度は「デフォルト」ではなくそのまま表示され、Kimi Code のエージェントにはこの行が常に表示されます。
