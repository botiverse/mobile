## zh-CN

- 与其他服务器一起创建频道时，现在总是使用外部频道流程：会打开“创建频道”并选中“外部”。旧的“创建联合频道”对话框（可能会创建失败）已移除。
- “创建频道”始终分两步（先为频道命名，再添加成员）；“已连接的服务器”不再显示旧的服务器邀请表单、“重新发送邀请”以及免费版/付费版标记，与网页端一致。

## en

- Creating a channel with another server now always uses the external channel flow: Create Channel opens with External chosen. The old Create Joint Channel dialog, which could fail, is gone.
- Create Channel always takes two steps (name the channel, then add people), and Connected servers no longer shows the old server invite form, Resend Invite, or the Free/Paid badges, matching the web app.

## ja

- 他のサーバーと一緒にチャンネルを作成するときは、常に外部チャンネルのフローを使うようになりました。「チャンネルを作成」が「外部」を選んだ状態で開きます。失敗することがあった従来の「共同チャンネルを作成」ダイアログは削除しました。
- 「チャンネルを作成」は常に 2 ステップ（チャンネル名を決めてからメンバーを追加）になり、「接続済みのサーバー」には従来のサーバー招待フォーム、「招待を再送」、無料プラン/有料プランのバッジが表示されなくなりました（Web 版と同じ）。
