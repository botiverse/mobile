## zh-CN

当计算机从网页升级因先前未完成的安装而失败时，升级按钮旁会显示修复建议与安装命令，提示在那台计算机上执行一次安装命令完成修复，并在版本变化或有新的升级请求后自动清除。

## en

When a remote Computer upgrade fails because an earlier installation on that computer was not finished, the repair advice and install command now appear beside Upgrade and clear once the computer's version changes or a newer upgrade request replaces it.

## ja

コンピューターのリモートアップグレードが以前の未完了インストールにより失敗したとき、アップグレードの横に修復の案内とインストールコマンドが表示されるようになりました。バージョンが変わるか新しいアップグレード要求に置き換わると自動的に消えます。
