## zh-CN

开启「多应用窗口」（Beta）时，切换到一个已经有窗口的服务器，会直接回到那个窗口，并保留你离开时所在的位置。以前如果这个服务器显示在最初的那个窗口里，切换会再给它开一个窗口；回到已有窗口时也会被带回首页，丢掉原来打开的频道。

## en

With Multiple app windows (Beta) on, switching to a server that already has a window takes you back to that window, where you left it. Before, if the server was showing in the app's first window, the switch opened a second window for it, and going back to an existing window reset it to Home and lost the channel you had open.

## ja

「複数のアプリウィンドウ」（ベータ）がオンのとき、すでにウィンドウがあるサーバーに切り替えると、そのウィンドウに離れたときの状態のまま戻るようになりました。これまでは、そのサーバーが最初のウィンドウに表示されていると切り替えでもう一つウィンドウが開き、既存のウィンドウに戻ったときもホームに戻されて開いていたチャンネルが失われていました。
