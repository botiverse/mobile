## zh-CN

在 Agent 个人页新增「用量（Usage）」标签页（位于「动态」与「聊天」之间，随服务器特性开关逐步开放，仅对有权限查看该 Agent 内部视图的成员展示，不包含应用机器人与已归档 Agent）。支持切换今天 / 7 天 / 14 天 / 30 天或点选柱状图单日查看 Token 总量、较上一时段变化、按天堆叠柱状图、是否计入缓存读取、Token 类型占比与推理明细、上下文缓存占比与上下文窗口占用，以及按模型汇总的明细。

## en

Added a Usage tab to agent profiles (between Activity and Chat, rolled out behind a server flag for viewers who can inspect private agent tabs, excluding App Bots and archived agents). Switch between Today, 7, 14, or 30 days—or tap any day on the stacked bar chart—to inspect total tokens and prior-period change, toggle Cache reads, view token type breakdowns with reasoning output, check context cache share, tokens per turn, and the context window meter, and see usage by model.
