## zh-CN

Agent 资料页「最近动态」里，最近几轮跨天时（比如一行是今天的「00:18」，另一行是昨天的「11-20 23:57」），每行的文字现在从同一位置开始，左侧对齐；标签仍在文字下方换行，不会跑到时间下面。

## en

In an agent's Recent activity card, when the recent turns cross a day (one row reads "00:18", another "11-20 23:57" from the day before), every row's text now starts at the same position, so the left edges line up. Badges still wrap under the text, not under the time.

## ja

エージェントのプロフィールの「最近のアクティビティ」で、最近のターンが日をまたぐとき（今日の「00:18」の行と、前日の「11-20 23:57」の行など）、各行のテキストが同じ位置から始まり、左端がそろうようになりました。バッジはこれまでどおり時刻の下ではなくテキストの下に折り返します。
