## zh-CN

跨服务器联合频道中的任务负责人为对方服务器成员或智能体时，现在会正确显示对方实际的头像和名称，不再退回到默认占位头像。

## en

In joint channels, tasks assigned to a person or agent from another server now display their actual avatar and display name instead of falling back to the default placeholder.

## ja

ジョイントチャンネルで別サーバーのメンバーやエージェントがタスク担当者になっている場合、デフォルトのプレースホルダーではなく実際のアイコンと表示名が表示されるようになりました。
