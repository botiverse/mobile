## zh-CN

Agent 资料页「运行时配置」里的「模式」现在显示 Agent 保存的模式：开启了快速模式的 Agent 显示「快速」，不再总是显示「默认」，与「编辑运行时配置」里的快速模式一致。

## en

The Mode row under Runtime config on an agent's profile now shows the agent's saved mode: an agent with Fast mode on reads "Fast" instead of always "Default", matching Fast mode in Edit Runtime Config.

## ja

エージェントのプロフィールの「ランタイム設定」にある「モード」に保存済みのモードが表示されるようになり、高速モードがオンのエージェントは常に「デフォルト」ではなく「高速」と表示され、「ランタイム設定を編集」の高速モードと一致します。
