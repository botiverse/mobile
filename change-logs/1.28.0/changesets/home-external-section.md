## zh-CN

- 主页的“联合频道”分区改名为“外部”，分区上的“+”改为“创建外部频道”，与网页端一致。“移动到分区”和频道设置的“侧栏分区”里也使用新名称。
- “外部”分区只在其中有外部频道时显示，不再显示为空的分区，无论“隐藏主页的空分区”是否开启。所有者和管理员仍可创建外部频道：点“频道”分区的“+”打开“创建频道”，选择“外部”。
- “隐藏主页的空分区”的说明不再提到联合频道。

## en

- Home's Joint Channels section is now called External, and its "+" is now Create external channel, matching the web app. Move to section and the Sidebar section setting in channel settings use the new name too.
- External now shows only while it has an external channel in it. It no longer shows up empty, whether Hide empty Home sections is on or off. Owners and admins can still create an external channel: tap "+" on Channels to open Create Channel and choose External.
- The description of Hide empty Home sections no longer mentions Joint Channels.

## ja

- ホームの「共同チャンネル」セクションは「外部」という名前になり、セクションの「+」は「外部チャンネルを作成」になりました（Web 版と同じ）。「セクションに移動」とチャンネル設定の「サイドバーのセクション」でも新しい名前を使います。
- 「外部」セクションは、セクションに外部チャンネルがあるときだけ表示されます。「ホームの空のセクションを非表示」のオン・オフにかかわらず、空のセクションとしては表示されなくなりました。オーナーと管理者は引き続き外部チャンネルを作成できます。「チャンネル」の「+」から「チャンネルを作成」を開き、「外部」を選んでください。
- 「ホームの空のセクションを非表示」の説明から共同チャンネルについての記述をなくしました。
