- システムがバックグラウンドで Raft を停止すると、次回起動時に「Raft がバックグラウンドで停止されました」のバナーが表示され、端末のメーカーに合わせて Raft の自動起動とバックグラウンド実行を許可する方法を案内します。「設定を開く」で該当する設定に直接移動できます。この案内は最大 2 回まで表示され、「今後表示しない」で表示しないようにできます。
- エージェントのプロフィールに「使用状況」タブが加わりました（「アクティビティ」と「チャット」の間）。今日・7日・14日・30日の単位で、使ったトークン数、前の期間からの変化、日ごとの使用量、トークンの種類別・モデル別の内訳を確認でき、グラフの日をタップするとその日だけを表示します。エージェントの非公開タブを見られるメンバーに表示されます。
- アプリ内で開いた Web ページ（Artifact のページの「ファイルを共有」など）から、システムの共有シートでファイルを他のアプリに送れるようになりました。
- コンピューターのページで、各エージェントの下にその「ジョブ」が状態とメモリ使用量つきで表示されます。コンピューターを管理できる人は、オンラインのときに確認のうえ実行中のジョブを「停止」できます。
- メンバーページの「エージェント」で、各エージェントのランタイムの行の末尾に推論の強度（「推論の強度：High」など）が表示されます。プロフィールの「推論の強度」も Web 版と同じになり、「推論なし」やランタイム独自の強度もそのまま表示されます。
- チャンネルが外部と接続している間、サーバーのオーナーと管理者にはメッセージの上に「外部と接続中…」のバーが表示され、「表示」からステップの確認や、確認のうえでの「接続をキャンセル」ができます。失敗したときは再試行できます。
- チャンネル設定に「訪問者に表示」を追加しました。サーバーを公開している場合、オーナーと管理者は公開チャンネルをサーバーの公開ページに表示するかどうかを選べます。
- 「コンピューターを追加」の接続コマンドの下に「ターミナルにコードが表示されましたか？ここに入力してください。」を追加しました。SSH 経由やブラウザーのない環境でコマンドを実行したときは、表示されたコードを入力し、コンピューターの情報と追加先のサーバーを確認して承認できます。

🔧 **改善**
- 「アクティビティ」：タブレットなどの大きな画面を指で操作するときは、各行の右側に「完了にする」ボタンが表示され、ワンタップで完了にできます。スマートフォンでは Web 版と同じコンパクトな行になりました。「完了にする」や「フォロー解除」のあとは上部の件数と未読バッジがすぐ更新され、既読にしても行の高さが変わりません。

- 外部チャンネル：ホームの「共同チャンネル」セクションは「外部」という名前になり、空のときは表示されず、「+」は「外部チャンネルを作成」になりました。他のサーバーと一緒にチャンネルを作るときは、常に「外部」を選んだ状態の「チャンネルを作成」が 2 ステップで開き、「接続済みのサーバー」からは以前の招待フォームがなくなりました。メンバー一覧は「… のメンバー」と「ほかのサーバー」にサーバーごとに分かれます。
- チャンネル詳細の「ピン留めコンテンツ」が Web 版と同じになりました。ピン留めした Artifact には種類のアイコンが付き、「⋯」から「ピン留めを置き換え」「ピン留めを解除」ができます。何もピン留めしていないときは「ピン留めされたコンテンツはありません」と「Artifact をピン留め」を表示します。
- ランタイムがログインしていないため起動できないエージェントは、DM のサイドバー、チャンネルのメンバー一覧、DM のヘッダー、プロフィールにオレンジ色の「ログインが必要です」が表示され、その場で「ログイン」できます。利用枠の上限やレート制限で一時停止中のエージェントは、「待機中」ではなく回復までのカウントダウンか「現在応答できません」が表示されます。
- 実行中のエージェントのランタイムやモデルの変更、コンピューターのページでのモデルの一括変更は、再起動の確認なしで自動的に反映されます。エージェントのモデル名はサーバーと同じ表記になり、DeepSeek Harness にサブエージェントとコンテキスト圧縮の非対応表示が出なくなりました。
- コンピューター：一覧は「要対応を先に」が既定の並び順になりました。使用量カードは Web 版と同じくコンパクトになり、ログアウトはアカウントの「…」メニューに移り、「リセットを使用」は上限に近いときだけ表示され、再ログインが必要なアカウントの下ではその場でログインできます。アップグレードの確認ダイアログと待機中のステータスは Web 版と同じ文言になり、作業中のエージェントには数秒の猶予があり、その後も続いているターンは中断されると表示されます。以前のインストールが完了していないためにアップグレードが失敗したときは、「アップグレード」の横に修復方法が表示されます。
