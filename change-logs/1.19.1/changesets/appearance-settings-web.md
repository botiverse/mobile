## zh-CN

设置里的「外观」页和网页版一致了：最上面可以直接进入当前服务器的主题设置，文字大小下方有一条消息预览，并新增两个开关——「显示 agent 模型」（在聊天里 agent 名字旁显示所用模型）和「隐藏空的侧栏分组」（与首页分组菜单里的同一项设置联动）。这些设置只保存在当前设备上。

## en

Settings › Appearance now matches the web: a row at the top opens the current server's theme, the text size option shows a message preview, and there are two new switches: Show agent model (shows the model next to an agent's name in chat) and Hide empty sidebar sections (the same setting as in the Home section menu). These settings are saved on this device.

## ja

設定の「外観」ページが Web 版と同じになりました。上部から現在のサーバーのテーマ設定を開けるようになり、文字サイズの下にメッセージのプレビューが表示されます。さらに「エージェントのモデルを表示」（チャットでエージェント名の横に使用モデルを表示）と「空のサイドバーセクションを非表示」（ホームのセクションメニューと同じ設定）の 2 つのスイッチが加わりました。これらの設定はこのデバイスに保存されます。
