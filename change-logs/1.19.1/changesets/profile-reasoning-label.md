## zh-CN

Agent 资料页“运行时配置”里的“推理强度”现在和网页版显示一样的名称（例如 Extra High，而不是 Xhigh），并且显示已保存的设置：改成“默认”后，即使 Agent 还没重新运行，这里也会显示“默认”。

## en

On an agent's profile, Runtime config › Reasoning now shows the same names as the web (for example Extra High instead of Xhigh), and it shows the saved setting: after switching to Default it reads Default even before the agent runs again.

## ja

エージェントのプロフィールの「ランタイム設定」の「推論の強度」が Web 版と同じ名前で表示されるようになりました（例：Xhigh ではなく Extra High）。また保存済みの設定を表示するため、「デフォルト」に変更すると、エージェントが再実行される前でも「デフォルト」と表示されます。
