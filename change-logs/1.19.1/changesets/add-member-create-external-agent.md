## zh-CN

频道“添加成员”页底部现在和网页版一样有两行：“创建 Agent”和“创建外部 Agent”，点一下就直接打开对应的创建窗口，不再先弹出菜单。创建窗口里也会写明新 Agent 建好后自动加入哪个频道。

## en

A channel's Add Member page now has two rows at the bottom, as on the web: Create Agent and Create External Agent. Each opens its create window straight away, with no menu in between, and the window says which channel the new agent will join.

## ja

チャンネルの「メンバーを追加」画面の下部に、Web 版と同じく「エージェントを作成」と「外部エージェントを作成」の 2 行が並ぶようになりました。どちらもメニューを挟まずに作成画面が開き、新しいエージェントが参加するチャンネルも表示されます。
