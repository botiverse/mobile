## zh-CN

消息里的 Raft 桌面版链接（`raft://…/s/…`）现在会显示为可点击的链接，点开后直接在应用内打开对应的频道、私信、话题或消息，和网页版消息链接一样；代码块里的链接仍按原文显示。

## en

Raft Desktop links in messages (`raft://…/s/…`) are now tappable and open the channel, DM, thread or message right in the app, like a web message link. Links inside code still show as plain text.

## ja

メッセージ内の Raft デスクトップ版リンク（`raft://…/s/…`）がタップできるようになり、Web 版のメッセージリンクと同じく、チャンネル・DM・スレッド・メッセージをアプリ内で直接開きます。コード内のリンクはこれまでどおり文字のまま表示されます。
