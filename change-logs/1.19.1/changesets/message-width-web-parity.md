## zh-CN

在平板、iPad 和 Compose 版等宽窗口里，消息发送者的名字不再在固定宽度处被截断：有空间时显示完整名字，和网页版一致；窗口窄时名字照常截断，时间始终留在这一行上。消息下方的任务标记也不再有固定宽度上限。

## en

On wide windows (tablets, iPad and the Compose desktop app), a message sender's name is no longer cut off at a fixed width: the full name shows when there is room, as on the web. On narrow windows the name still truncates and the time stays on the line. The task chip under a message no longer has a fixed width limit either.

## ja

タブレット、iPad、Compose 版などの広いウィンドウでは、メッセージ送信者の名前が固定幅で切れなくなりました。スペースがあれば Web 版と同じく名前全体が表示されます。狭いウィンドウでは従来どおり名前が省略され、時刻は同じ行に残ります。メッセージ下のタスクチップにも固定の幅上限はなくなりました。
