## zh-CN

智能体运行时设置里，推理强度等选项选的是“默认”时，选择框又会显示“默认”并勾选这一项，而不是只显示占位文字。

## en

In an agent's runtime settings, a choice such as reasoning strength that is set to Default shows “Default” again, with that row checked, instead of only the placeholder.

## ja

エージェントのランタイム設定で、推論の強さなどが「デフォルト」のときに、選択欄に再び「デフォルト」と表示され、その項目にチェックが付くようになりました（プレースホルダーだけが表示されることはありません）。
