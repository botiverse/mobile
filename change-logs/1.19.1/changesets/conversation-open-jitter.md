## zh-CN

打开频道、讨论串或任务对话时，消息出现后不再上下抖动：输入框的位置从第一帧就留好，不会在消息显示后才出现、把消息往上推；也不会先闪一下旧的「聊天 / 任务 / 文件」标签栏。助理小水獭现在直接盖在消息列表底部，出现或离开时列表不再移动；如果挡住了内容，滚动一下即可。

## en

Opening a channel, thread or task conversation no longer makes the messages jump after they appear: the composer's space is there from the first frame instead of the composer showing up afterwards and pushing the messages up, and the old Chat / Tasks / Files tab row no longer flashes for a moment. The assistant's otter now sits over the bottom of the message list, so the list no longer moves when it comes or goes; scroll if it covers something.

## ja

チャンネル、スレッド、タスクの会話を開いたとき、メッセージが表示された後に上下に揺れなくなりました。入力欄の場所は最初のフレームから確保され、表示後に入力欄が現れてメッセージを押し上げることはありません。また、古い「チャット / タスク / ファイル」タブ行が一瞬表示されることもなくなりました。アシスタントのカワウソはメッセージ一覧の下端に重ねて表示されるようになり、現れたり消えたりしても一覧は動きません。内容が隠れる場合はスクロールしてください。
