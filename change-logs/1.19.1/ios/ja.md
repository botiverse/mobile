✨ 新機能
- iPad で、左側のナビゲーションのタブ（チャット、アクティビティ、タスク、メンバー、コンピューター、アプリなど）をドラッグして並べ替えられます。順序はアカウントに保存され、Web 版と共通です
- iPad で、サイドバーやアクティビティ一覧の右端をドラッグして幅を変えられます。最小幅を超えてドラッグすると「サイドバーを折りたたむ」と同じように折りたたまれます
- ホームの「通知」で、管理しているコンピューターに期限までのアップグレードまたは再インストールが必要なときにお知らせします。期限を過ぎるとそのコンピューター上のエージェントは停止します。「表示」でそのコンピューターを開きます
- メッセージ内の raft:// リンクをタップすると、チャンネル・DM・スレッド・メッセージをアプリ内で直接開きます
- iPad のワイド表示では、上部バーの検索欄をタップする（キーボード接続時は ⌘K / Ctrl+K）と、Web 版と同じく今のページの上に検索パネルが開きます。最近の会話が並び、入力すると一致するチャンネル・メンバー・メッセージを先に確認できます
- 会話の画像を編集できます。画像ビューアーで、iPhone では右下の ⋯ から「編集」を、iPad のワイド表示では右上の「編集」をタップします。「ペン」「テキスト」「モザイク」「切り抜き」「回転」で編集でき、編集した画像は新しい画像として入力欄に入ります。元のメッセージは変わりません

🔧 改善
- サーバーへのリクエストが失敗したとき、エラーにトレース ID を表示します。トーストの「コピー」でコピーして送っていただければ、そのリクエストを特定できます。アプリ内の理由でスレッドを開けないときは、理由と対処を表示します
- iPad で、一覧・会話・スレッド・「タスクとファイル」が Web 版と同じく 1 行に並び、ウインドウが狭くなっても会話は十分な幅を保ちます
- ハードウェアキーボード接続時は、チャンネル・DM・スレッドを開くとすぐに入力できます
- iPad でマウスやトラックパッドを使うとき、メッセージ内のリンクにポインタを置くとウィンドウ左下に行き先が表示されます
- アプリリンクのカードが Web 版と同じ表示になりました。タイトルは最大 2 行で、作成者や所要時間などの詳細とリンクの短い名前を表示します（サーバーごとに順次提供）
- 長いメッセージのあるチャットのスクロールがなめらかになりました
- 設定の「外観」が Web 版と同じになりました。上部から現在のサーバーのテーマを開け、「メッセージの文字サイズ」の下にプレビューを表示し、「エージェントのモデルを表示」と「空のサイドバーセクションを非表示」の 2 つのスイッチが加わりました

🐛 修正
- 送信に時間がかかっていたメッセージの送信完了と同時に入力を続けると、アプリが終了することがある問題を修正しました
- チャンネル・スレッド・タスクの会話を開いたときにメッセージが上下に揺れる問題を修正しました。@メンションと #チャンネル も最初からチップで表示されます
- ピンインなどの入力方式で候補が未確定のとき、メンションの挿入・引用の追加・下書きの復元で未確定の文字が入力される問題を修正しました
- Web 版や別のデバイスで完了にした会話が、手動で更新しないとアクティビティから消えない問題を修正しました
- Markdown の表が狭い列で折り返される問題を修正し、内容に合わせた幅で表示します。広い画面では送信者名をスペースがあれば省略せずに表示します
- iPhone Duo の Split View で、サイドの列がウインドウのある側に追従して幅もそろい、内容に重なったり余白が残ったりしなくなりました（@pleiades-xl さんの貢献に感謝します）
- キーボードが表示されている状態でメッセージを長押ししても、キーボードが閉じなくなりました。メニューを閉じたあとそのまま入力を続けられます
- タスクの会話でメッセージをタップしても「スレッドを開けません」が表示されなくなりました。Web 版と同じく、その中のメッセージには「スレッドで返信」が表示されません
- iPad の画像ビューアーで、上部の時刻がローカル時刻で表示されるようになりました（長い日付コードのままにはなりません）
- タスクページ上部のステータスと担当者が Web 版と同じ動作になりました。ステータスをタップすると任意のステータスに変更でき、担当者をタップすると別の人に変えたり割り当てを外したりできます。完了済みや閲覧のみのタスクではドロップダウンの矢印なしで表示だけになります
