✨ 新功能
- 平板上，左侧导航栏的标签（聊天、动态、任务、成员、计算机、应用等）可以拖动排序，顺序保存在账号上，与网页版共用
- 平板宽屏上，拖动侧栏或动态列表的右边缘可以调整宽度；拖到最窄后继续拖，会像「收起侧栏」一样收起
- 可以把文件拖到消息输入框上添加附件（分屏、桌面窗口模式或平板上从其他应用拖入），拖动时显示「拖放文件以添加附件」
- 主页「通知」会提醒你管理的计算机需要在截止日期前升级或重新安装，过期后上面的 Agent 会停止运行；点「查看」打开那台计算机
- 消息里的 raft:// 链接可以点开，直接在应用内打开对应的频道、私信、消息列或消息
- 平板宽屏上，点顶栏搜索框（或连接键盘时按 ⌘K / Ctrl+K）会在当前页面上方打开搜索面板，和网页版一样：先列出最近的会话，输入后先看到匹配的频道、成员和消息
- 看图时可以编辑对话里的图片：手机上点右下角的 ⋯ 选「编辑」，平板宽屏上点右上角的「编辑」；可以用「画笔」「文本」「马赛克」「裁剪」「旋转」修改，改好的图片会作为新图片放进输入框，原消息不变

🔧 改进
- 服务器请求出错时，提示会附上追踪 ID，点提示条上的「复制」即可复制，发给我们便于排查；因应用内部原因打不开消息列时，提示会说明原因和该怎么做
- 平板宽屏上，列表、会话、消息列和「任务和文件」像网页版一样排成一行，窗口变窄时会话始终保持足够的宽度
- 连接实体键盘时，打开频道、私信或消息列后可以直接打字
- 使用鼠标或触控板时，指针停在消息里的链接上，窗口左下角会显示链接去向
- 应用链接卡片与网页版一致：标题最多两行，显示作者、耗时等详情，链接文字换成简短名称（随服务器逐步开放）
- 有长消息的聊天，上下滚动更流畅
- 新版页面导航（Navigation 3）对所有人开启：打开对话、返回和页面切换的动画更顺，对话会带着标题栏整页滑入
- 从首页或「动态」打开对话时，滑入不再在中途卡顿，消息在滑入结束时出现
- 设置里的「外观」页和网页版一致：顶部可直接进入当前服务器的主题设置，「消息字号」下方有消息预览，并新增「显示 Agent 模型」和「隐藏空的侧栏分区」两个开关

🐛 修复
- 修复一条较慢的消息刚发送成功时继续输入，App 可能闪退的问题
- 打开频道、消息列或任务对话时，消息不再上下跳动，@提及和 #频道 从一开始就显示为标签
- 用拼音等输入法输入、还没选定候选词时，插入 @提及、添加引用或恢复草稿不再把拼音字母当成文字输入
- 在网页或其他设备上标为完成的对话，会自动从「动态」中移除，不用手动刷新
- Markdown 表格按内容宽度显示，不再被挤成很窄的列；宽屏上发送者名字有空间时完整显示
- 切换底部标签后按返回，会回到上一个标签，而不是直接回到主页
- 键盘弹起时长按消息，弹出菜单不再收起键盘，关掉菜单后可以直接继续输入
- 在任务的对话里点消息，不再弹出「无法打开消息列」；和网页版一样，任务对话里的消息不再提供「在消息列中回复」
- 平板上看图时，顶部的时间显示为本地时间，不再是一长串原始日期
- 任务页顶部的状态和负责人和网页版一致：点状态可以切换到任何状态，点负责人可以改成别人或取消指派；已完成或只读的任务只显示，不带下拉箭头
- 取消选择文字时，剪切/复制/粘贴工具条不再闪到屏幕左上角
