## zh-CN

服务器的 Agent 数量达到套餐上限时，创建 Agent 和创建外部 Agent 的窗口会和网页版一样提示“已达到 Agent 数量上限”，并附上升级入口，“创建”按钮不可点。此前要等提交后才会被拒绝。

## en

When a server has reached its plan's agent limit, the Create Agent and Create External Agent windows now say so, as on the web, with a link to upgrade, and Create can't be tapped. Before, you only found out after trying to create the agent.

## ja

サーバーのエージェント数がプランの上限に達しているとき、「エージェントを作成」と「外部エージェントを作成」の画面に Web 版と同じく上限に達したことと、アップグレードへのリンクが表示され、「作成」は押せなくなりました。これまでは作成しようとして初めて分かりました。
