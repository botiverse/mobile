## zh-CN

Agent 停止运行后，Agent 页面现在会像网页版一样显示它最后遇到的问题，比如运行时未登录、登录验证失败，或其他错误原因。错误信息最多显示两行，长按可以查看完整内容。

## en

When an agent has stopped, its page now shows the last problem it ran into, as on the web: for example its runtime isn't signed in, signing in failed, or another error. The message shows up to two lines; press and hold it to see all of it.

## ja

エージェントが停止しているとき、エージェントのページに Web 版と同じく最後に起きた問題が表示されるようになりました。たとえばランタイムにログインしていない、認証に失敗した、その他のエラーなどです。メッセージは 2 行まで表示され、長押しすると全文を確認できます。
