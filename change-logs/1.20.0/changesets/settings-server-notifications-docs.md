## zh-CN

设置里新增了两项，与网页版一致：「在 {服务器} 上」下的「通知」，可单独设置当前服务器如何通知你；「资源」下的「文档」，会在浏览器中打开 Raft 文档。

## en

Settings has two new rows, as on the web: Notifications under "On {server}" sets how the current server notifies you, and Documentation under Resources opens the Raft docs in your browser.

## ja

設定に、ウェブ版と同じ 2 つの項目が加わりました。「{サーバー} で」の「通知」では、現在のサーバーからの通知方法を設定できます。「リソース」の「ドキュメント」では、Raft のドキュメントをブラウザで開きます。
