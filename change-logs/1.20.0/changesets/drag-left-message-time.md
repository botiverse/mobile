## zh-CN

在消息列、任务讨论和助理面板里，手指按住消息往左拖，右边会露出每条消息的时间，松手弹回，和网页版一致。从屏幕边缘开始拖仍然是系统返回；代码块和宽表格里的横向滑动不受影响。打开「减少动态效果」时，消息不移动，时间直接在连发消息左侧淡入。

## en

In the message list, task discussions and the assistant panel, drag messages to the left to see each message's time; let go and they spring back, as on the web. Dragging from the screen edge still goes back, and sideways scrolling in code blocks and wide tables is unchanged. With Reduce Motion on, messages stay put and the times fade in beside grouped messages.

## ja

メッセージ一覧、タスクのディスカッション、アシスタントパネルで、メッセージを左にドラッグすると各メッセージの時刻が右側に表示され、指を離すと元に戻ります（ウェブ版と同じ）。画面の端からのドラッグは引き続き「戻る」操作になり、コードブロックや幅の広い表の横スクロールも変わりません。「視差効果を減らす」がオンのときは、メッセージは動かず、連続したメッセージの横に時刻がフェードインします。
