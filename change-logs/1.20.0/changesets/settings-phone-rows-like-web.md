## zh-CN

手机上的设置页现在和网页版一致：「电脑」和「应用」不再是设置里的条目，而是和「成员」「设置」一起放在服务器标签弹出的菜单里；「应用」条目只对访客保留在设置中。手机专属的「移动端」和「存储」照旧。设置里各分组标题和下面第一项之间的空白也收紧了，与网页版相同。

## en

On phones, Settings now lists the same rows as the web: Computers and Apps are no longer Settings rows but sit with Members and Settings in the server tab's menu, and the Applications row stays in Settings only for guests. The app's own Mobile and Storage rows remain. Each Settings group heading also sits closer to its first row, as on the web.

## ja

スマートフォンの設定画面が Web 版と同じ項目になりました。「コンピューター」と「アプリ」は設定の項目ではなくなり、「メンバー」「設定」と一緒にサーバータブのメニューに並びます。「アプリケーション」の項目はゲストの場合のみ設定に残ります。アプリ独自の「モバイル」と「ストレージ」はそのままです。設定の各グループ見出しと最初の項目の間隔も、Web 版と同じように詰めました。
