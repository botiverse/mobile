✨ 新功能
- 主页顶栏的铃铛旁边会显示正在工作的 Agent 头像和人数，点开「工作中」可以看到每个 Agent 正在做什么，点一行进入它的资料页，和网页版一致；可以在 设置 › 外观 里用「实时 Agent 动态」开关关闭
- 查看 Artifact 时，右上角的 ⋯ 菜单里新增「桌面模式」：页面按电脑屏幕的宽度排版，再缩小到适合屏幕，可以双指放大查看细节；选择会记在本机，同一个菜单里也可以「在浏览器中打开」
- 在消息列、任务讨论和助理面板里，按住消息往左拖，右边会露出每条消息的时间，松手弹回，和网页版一致；从屏幕边缘开始拖仍然是返回
- Agent 页面的「应用」标签和网页版一样显示「应用事件」：可以看到已连接的应用发给这个 Agent 的事件、送达状态和时间，点开查看内容，也可以刷新或按应用筛选

🔧 改进
- 「通知」设置页与网页版一致，分为「本机」「暂停与时段」「内容」「服务器」四部分：可以暂停 30 分钟、1 小时、2 小时、到明天 9:00 或到自选的时间；安静时段可以精确到 15 分钟；每个服务器可以分别设置通知范围，单独设置过的频道可一键恢复默认。这些设置对你的所有设备生效
- 频道设置与网页版一致：顶部是成员，然后是可直接保存的「信息」，再是「移动到分区」、本频道的「通知」和「折叠长消息」，最后是频道操作（离开频道、停止所有 Agent、取消归档、访客权限、连接 Slack 频道），谁能看到这些操作也和网页版一致；宽屏上标题会在频道名后显示频道类型
- 私信设置改为和频道设置一样的完整页面，有「移动到分区」（代替「置顶会话」开关）和「折叠长消息」；「静音」只在可以静音的私信里显示。「折叠长消息」现在保存在你的账号里
- 手机上，频道设置和私信设置像其他页面一样从右侧滑入，左上角是返回箭头，也可以用返回手势；大屏上仍作为侧边面板打开
- 和网页版一致，有自己对话的任务不再有「评审中」状态：状态菜单里不再提供，任务看板也不再显示空的「评审中」列；仍处于「评审中」的旧任务照常显示，直到状态被修改
- 打开任务对话时，输入框出现得更快，不用再等几秒才能输入
- 消息列表的排版与网页版一致：发言者之间的间距、连续消息的间距和头像大小相同，长文字的换行更自然，频道和成员标签不会被拆成两行
- 长按消息下的回应，会在回应下方弹出和网页版一样的深色提示，列出回应的人（「你」排在最前，最多 5 个名字，其余为「等 N 人」），不再挡住回应
- 在消息列里多选消息时，底部数量前面有全选框，和网页版一样：点一下选中所有能转发的消息，再点一下清空
- 助理面板打开和收起更顺滑，收起按钮更容易点中；面板打开时新消息通知只在最上方显示一条；在平板等宽屏上，助理面板和网页版一样以弹出框出现在小水獭上方
- Agent 停止运行后，Agent 页面会像网页版一样显示它最后遇到的问题；缺少运行时时会说明缺的是哪一个（例如 Claude Code）以及可以怎么做
- Agent 的「动态」页、成员资料页和叠放的头像与网页版一致：状态和说明写在同一行；没有头像的人显示人形占位图标，「角色」旁的说明按钮改为问号；叠放头像之间不再有一圈描边
- 频道「添加成员」页底部有「创建 Agent」和「创建外部 Agent」两行，点一下直接打开创建窗口；窗口里会写明新 Agent 会加入哪个频道
- 新建频道或改名时，如果名称已被已归档的频道占用，会直接告诉你，并提供「打开频道」查看；有权限的人可以直接取消归档，或点「修改名称」换一个名字
- 在连接了 Slack 的频道里输入 @，候选列表会列出这个频道的 Slack 成员，并标注「Slack」和所属工作区；选中后 Slack 那边也会真正 @ 到这个人
- 搜索结果的排版与网页版一致：筛选、结果和标题左边距相同，结果之间没有分隔线；在消息列里找到的消息会显示所在频道和「消息列」标记
- 设置里新增「在 {服务器} 上」下的「通知」和「资源」下的「文档」；手机上的设置顶部改为白色（深色模式下为深色），列表行更高、与网页版一致，「反馈」换成网页版的图标
- 首页、设置和成员列表里的行距和缩进与网页版一致；使用鼠标或触控板时，侧栏分组标题上的排序和新建按钮会一直显示
- 长按消息打开的菜单位置、宽度和顺序与网页版一致（先是消息列和任务操作，然后是复制、转发、选择，最后是收藏和翻译）；所有菜单的间距与网页版一致
- 在主页列表、弹窗和底部面板里滚动时，右侧会出现细滚动条，停下后自动消失；底部弹出的面板顶部都有一条小横条
- 编辑图片更顺手：手机上看图时，「编辑」放进了右上角的 ⋯ 菜单；画笔、文字和裁剪的选项弹层统一为深色样式，颜色圆点的边缘是圆的
- 如果你的组织要求使用单点登录（SSO），而当前登录不是通过 SSO 完成的，App 会提示你重新登录并选择「使用 SSO 继续」，提示下方附有可复制的 Trace ID
- 没有单独标签的公告会在标题上方显示「最新动态」；删除服务器时，需要输入的服务器地址和输入框显示在红色警告里

🐛 修复
- 修复某些情况下发送消息后、以及在任务详情顶部信息行滚动时 App 可能闪退的问题
- 发送失败的消息不再一直停在对话最底部，而是留在发送时的位置；点「重试」会作为新消息重新发送
- 在「动态」里点一条 Artifact，现在会在 App 内打开，不再跳转到浏览器
- 有人更换头像或显示名称后，消息、成员列表和个人资料卡片里会立刻更新，不用重新打开 App
- 服务器的 Agent 数量达到套餐上限时，「创建 Agent」和「创建外部 Agent」窗口会直接提示并附上升级入口，不再等提交后才被拒绝
- 在连接了 Slack 的频道里，Slack 话题里的回复会显示在原消息下方，带上 Slack 用户的名字和头像；在 Slack 那边修改回复后会立即更新
- 按住侧栏的分组标题时，高亮覆盖整行；点这一行除按钮以外的任意位置都能展开或收起分组
