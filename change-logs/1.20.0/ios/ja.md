✨ 新機能
- ホームのトップバーのベルの横に、いま作業中のエージェントのアイコンと人数が表示されます。タップすると「作業中」が開き、各エージェントが何をしているかを確認でき、行をタップするとプロフィールが開きます（Web 版と同じ）。設定 › 外観 の「エージェントのライブアクティビティ」でオフにできます
- Artifact を表示するとき、右上の ⋯ メニューに「デスクトップ表示」が追加されました。ページをパソコンの画面幅でレイアウトしてから画面に合わせて縮小し、ピンチで拡大できます。選択はこの端末に保存され、同じメニューから「ブラウザで開く」こともできます
- メッセージ一覧、タスクのディスカッション、アシスタントパネルで、メッセージを左にドラッグすると各メッセージの時刻が表示され、指を離すと元に戻ります（Web 版と同じ）。画面の端からのドラッグは引き続き「戻る」操作です
- エージェントの「アプリ」タブに、Web 版と同じく「アプリのイベント」が表示されます。連携アプリがこのエージェントに送ったイベント、配信状況、時刻を確認でき、開いて内容を見たり、更新やアプリごとの絞り込みもできます

🔧 改善
- 「通知」設定ページが Web 版と同じく「このデバイス」「一時停止とスケジュール」「内容」「サーバー」の 4 つに分かれました。30 分間・1 時間・2 時間・明日の 9:00 まで、または選んだ日時まで一時停止でき、通知オフの時間帯は 15 分単位で設定できます。サーバーごとに通知の範囲を設定でき、個別に設定したチャンネルはデフォルトに戻せます。これらの設定はすべてのデバイスに適用されます
- チャンネル設定が Web 版と同じになりました：最初にメンバー、次にその場で保存できる「情報」、続いて「セクションに移動」、このチャンネルの「通知」と「長いメッセージを折りたたむ」、最後にチャンネルの操作（チャンネルから退出、すべてのエージェントを停止、アーカイブ解除、ゲストのアクセス、Slack チャンネルとの接続）が並び、それぞれ Web 版と同じ人にだけ表示されます。iPad の広い画面では見出しにチャンネルの種類が表示されます
- ダイレクトメッセージの設定がチャンネル設定と同じ専用ページになり、「セクションに移動」（「会話をピン留め」スイッチの代わり）と「長いメッセージを折りたたむ」を設定できます。「ミュート」はミュートできる会話でのみ表示されます。「長いメッセージを折りたたむ」はアカウントに保存されるようになりました
- iPhone では、チャンネル設定と DM 設定がほかのページと同じく右からスライドして開き、戻る矢印や戻るジェスチャーで会話に戻れます。iPad ではこれまでどおりサイドパネルとして開きます
- Web 版と同様に、専用の会話を持つタスクには「レビュー中」ステータスがなくなりました。ステータスメニューに表示されず、タスクボードにも空の「レビュー中」列は表示されません。まだ「レビュー中」の古いタスクは、ステータスが変わるまでそのまま表示されます
- タスクの会話を開いたとき、入力欄がすぐに表示され、数秒待たずに入力できます
- メッセージ一覧のレイアウトが Web 版と同じになりました。発言者の間や連続したメッセージの間隔、アイコンの大きさがそろい、長い文章の改行も自然になり、チャンネルやメンバーのタグが 2 行に分かれなくなりました
- リアクションを長押しすると、Web 版と同じ濃い色のツールチップがリアクションの下に表示され、リアクションした人がわかります（「あなた」が先頭、最大 5 人、それ以降は「ほか N 人」）。リアクションを隠さなくなりました
- スレッドでメッセージを複数選択するとき、ツールバーの件数の前に Web 版と同じ全選択チェックボックスが表示されます。タップすると転送できるメッセージをすべて選択し、もう一度タップすると選択を解除します
- アシスタントパネルの開閉がなめらかになり、折りたたみボタンも押しやすくなりました。パネルを開いている間、新着メッセージの通知は一番上に 1 つだけ表示されます。iPad の広い画面では、Web 版と同じくカワウソの上にポップオーバーとして表示されます
- エージェントが停止しているとき、エージェントのページに Web 版と同じく最後に起きた問題が表示され、足りないランタイム（例：Claude Code）とその対処方法も示されます
- エージェントの「アクティビティ」ページ、メンバーのプロフィール、重なったアイコンが Web 版と同じになりました。ステータスと説明が 1 行にまとまり、写真のない人には人型のアイコンが表示され、「役割」の横のヘルプボタンは疑問符になりました。重なったアイコンの周りの縁取りもなくなりました
- チャンネルの「メンバーを追加」画面の下部に「エージェントを作成」と「外部エージェントを作成」の 2 行が並び、すぐに作成画面が開きます。新しいエージェントが参加するチャンネルも表示されます
- チャンネルの作成や名前の変更で、その名前がアーカイブ済みのチャンネルで使われている場合はそのことが表示され、「チャンネルを開く」で確認できます。権限があればその場でアーカイブを解除するか、「名前を変更」で別の名前にできます
- Slack と連携したチャンネルで @ を入力すると、このチャンネルの Slack メンバーが「Slack」とワークスペース名付きで候補に表示され、選ぶと Slack 側でもその人へのメンションになります
- 検索結果のレイアウトが Web 版と同じになりました。フィルター、結果、見出しの余白がそろい、結果の間の区切り線はなくなり、スレッド内で見つかったメッセージにはチャンネルとスレッドの表示が付きます
- 設定に「{サーバー} で」の「通知」と「リソース」の「ドキュメント」が加わりました。iPhone の設定は上部が白（ダークモードでは暗い色）になり、一覧は Web 版と同じく行が高くなり、「フィードバック」は Web 版と同じアイコンになりました
- ホーム、設定、メンバー一覧の行の間隔とインデントが Web 版と同じになりました。マウスやトラックパッドでも、サイドバーのセクション見出しの並べ替えと作成のボタンが常に表示されます
- メッセージを長押しして開くメニューの位置・幅・順番が Web 版と同じになりました（スレッドとタスクの操作、次にコピー・転送・選択、最後に保存と翻訳）。すべてのメニューの余白も Web 版と同じです
- ホームのリスト、ダイアログ、下から開くパネルをスクロールすると細いスクロールバーが表示され、止めると消えます。下から開くパネルの上端にはハンドルが付きました
- 画像の編集が使いやすくなりました。iPhone で画像を表示しているとき、「編集」は右上の ⋯ メニューにあります。ペン、テキスト、切り抜きのオプションは濃い色のスタイルにそろい、色の丸の縁も丸くなりました
- 組織でシングルサインオン（SSO）が必須なのに SSO 以外でログインしている場合、アプリはもう一度ログインして「SSO で続行」を選ぶよう案内し、その下にコピーできる Trace ID を表示します
- 独自のラベルがないお知らせのタイトルの上に「最新情報」と表示されます。サーバーを削除するとき、入力するアドレスと入力欄が赤い警告の中に表示されます

🐛 修正
- 場合によってはメッセージ送信の直後に、またタスク詳細上部の情報の行をスクロールしたときに、アプリが終了することがある問題を修正しました
- 送信に失敗したメッセージが会話の一番下に残り続けることはなくなり、送信した位置にとどまります。「再試行」で新しいメッセージとして送り直されます
- 「アクティビティ」で Artifact をタップすると、ブラウザではなくアプリ内で開きます
- HTML 添付ファイルのプレビューで「デスクトップ表示」をオンにすると、ページがパソコンの画面幅でレイアウトされて画面に合わせて表示され、小さく縮まなくなりました
- 誰かがアイコンや表示名を変えると、メッセージ、メンバー一覧、プロフィールカードにすぐ反映され、アプリを開き直す必要はありません
- サーバーのエージェント数がプランの上限に達しているとき、「エージェントを作成」と「外部エージェントを作成」の画面に最初からそのこととアップグレードへのリンクが表示され、作成しようとして初めて分かることはなくなりました
- Slack と連携したチャンネルで、Slack のスレッドに投稿された返信が元のメッセージの下に Slack ユーザーの名前とアイコン付きで表示され、Slack 側での編集もすぐに反映されます
- サイドバーのセクション見出しを押したとき、ハイライトが行全体を覆い、ボタン以外なら行のどこをタップしてもセクションを開閉できます
