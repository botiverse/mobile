## zh-CN

外部频道的邀请链接可以在 App 里打开，与网页版一致：Android 上点邀请邮件里的链接直接进入 App（未登录时，登录后自动打开）。页面列出服务器提供的加入方式：作为访客加入、连接你所在的服务器（可多选，需要批准的服务器可以选择请哪位管理员批准），或创建新服务器并连接。加入后直接打开频道；连接需要时间或等待批准时，页面会显示进度，可以取消申请。邀请链接无效时会说明；如果邀请是发给另一个邮箱的，会显示脱敏后的邮箱，并提供「切换账号」。出错时显示原因和追踪 ID。该功能正在逐步开放。

## en

External channel invite links open in the app, as on the web: on Android the link in the invite email opens the app directly (signed out, it opens once you sign in). The page lists the ways in the server offers: join as a guest, connect servers you're in (several at once; for one that needs approval, choose which admin to ask), or create a new server and connect it. Joining opens the channel; while a server connects or a request waits for approval, the page shows where it stands and the request can be canceled. An invalid link says so, and an invite sent to another address shows that address masked with Switch account. Errors show the reason and the trace ID. This is rolling out gradually.

## ja

外部チャンネルの招待リンクを、Web 版と同じくアプリで開けるようになりました。Android では招待メールのリンクからアプリが直接開きます（未ログインの場合はログイン後に開きます）。ページには、サーバーが提示する参加方法が表示されます。ゲストとして参加する、所属しているサーバーを接続する（複数選択でき、承認が必要なサーバーは承認を依頼する管理者を選べます）、または新しいサーバーを作成して接続する、のいずれかです。参加するとチャンネルが開きます。接続中や承認待ちの間は進捗が表示され、依頼を取り消すこともできます。無効なリンクの場合はその旨が表示され、別のメールアドレス宛ての招待の場合は、伏せ字のアドレスと「アカウントを切り替え」が表示されます。エラー時は理由とトレース ID が表示されます。この機能は段階的に公開されています。
