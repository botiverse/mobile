## zh-CN

「计算机」页面的卡片和列表更接近网页版：按某个运行时余量、磁盘用量或内存用量排序时，每张卡片会把这一项放在最上面并加粗显示。用量已用完时，会显示多久后恢复，例如「3h 后重置」，不知道重置时间时仍显示「已用完」。卡片上的 Agent 排成一行，放不下时可以左右滑动，边缘渐隐提示还有更多，不再显示「+N」。列表视图改为网页版的手机列表：顶部固定显示各运行时的列标题，每台计算机一块，显示名称、Agent 数、版本、所有者、Agent、各运行时的用量（与列标题对齐），离线时显示上次在线时间，以及下一步操作。

## en

The Computers page's cards and list follow the web more closely. Sorted by what a runtime has left, or by disk or memory used, each card puts that line first, in bold. A used-up allowance says when it is back ("Back in 3h"), or "Used up" when that isn't known. A card's agents stay on one line that scrolls sideways and fades at the edge when there are more, instead of ending in "+N". The List view is the web's phone list: a runtime header that stays at the top, and a block per computer with its name, agent count, version, owner, agents, each runtime's usage under its column, when it was last seen if it is offline, and its next step.

## ja

「コンピューター」ページのカードと一覧が Web 版により近くなりました。ランタイムの残量、ディスク使用量、メモリ使用量で並べ替えると、各カードでその行がいちばん上に太字で表示されます。上限に達した使用量は回復までの時間（「3h で回復」）を表示し、リセット時刻がわからないときは「上限到達」のままです。カードのエージェントは 1 行に並び、収まらないときは横にスクロールでき、端がフェードして続きがあることを示します（「+N」は表示されなくなりました）。リスト表示は Web 版のスマートフォン向け一覧になり、上部に固定されるランタイムの見出しと、コンピューターごとのブロック（名前、エージェント数、バージョン、オーナー、エージェント、見出しにそろえた各ランタイムの使用量、オフライン時の最終オンライン、次の操作）が表示されます。
