## zh-CN

设置 › 开发者中新增「每个窗口都实时更新」开关（默认关闭）。在开启「多应用窗口」时打开它，每个窗口里的工作空间会各自保持实时连接（最多 3 个），放在后面的窗口也能及时收到新消息和回复；关闭时仍只有最前面的工作空间保持连接。

## en

Settings › Developer has a new Live updates in every window switch (off by default). With Multiple app windows on, turning it on keeps a realtime connection for the workspace in each window (up to 3), so a window in the back still gets new messages and replies right away. While it is off, only the workspace in front stays connected.

## ja

設定 › 開発者に「すべてのウィンドウでリアルタイム更新」スイッチを追加しました（既定はオフ）。「複数のアプリウィンドウ」がオンのときにこれをオンにすると、各ウィンドウのワークスペースがそれぞれリアルタイム接続を保ち（最大 3 つ）、後ろにあるウィンドウにも新しいメッセージや返信がすぐに届きます。オフの間は、最前面のワークスペースだけが接続されます。
