## zh-CN

创建或编辑使用 Built-in Pi + OpenRouter 的 Agent 时，模型既可以从列表中选择，也可以直接输入任意 OpenRouter 模型 ID；还可以选填上下文窗口和最大输出长度。需要将计算机更新到新版本。

## en

When creating or editing an agent with Built-in Pi and OpenRouter, you can pick a model from the list or type any OpenRouter model ID, and optionally set the context window and max output. Requires an updated Computer.

## ja

Built-in Pi と OpenRouter を使うエージェントを作成・編集するとき、モデルを一覧から選ぶことも、任意の OpenRouter モデル ID を直接入力することもできるようになりました。コンテキストウィンドウと最大出力も任意で設定できます。コンピューターを新しいバージョンに更新する必要があります。
