## zh-CN

支持显示用户在网页版中搭建的像素头像，与网页版一致：在消息、私信、成员列表、个人资料、搜索、动态、附件评论和 Android 桌面小组件等所有显示用户头像的地方，都会按原样显示完整的像素形象，放大缩小时保持像素清晰。由服务器自动分配的像素头像也同样显示。无法识别的头像仍显示默认的人物占位图标。头像搭建目前只能在网页版中进行，并且由服务器逐步开放。

## en

People's built pixel avatars from the web now show in the app, as on the web: wherever a person's avatar appears (messages, DMs, the member list, profiles, search, Activity, attachment comments and Android home-screen widgets), the whole pixel character is drawn with crisp pixels at every size. Avatars the server picked for a new account show the same way. An avatar the app can't read still shows the usual person placeholder. Building an avatar is on the web only for now, and the server is rolling it out gradually.

## ja

Web 版で作成したピクセルアバターがアプリにも表示されるようになりました（Web 版と同じ表示）。メッセージ、DM、メンバー一覧、プロフィール、検索、アクティビティ、添付ファイルのコメント、Android のホーム画面ウィジェットなど、人のアバターが表示されるすべての場所で、ピクセルキャラクター全体がどのサイズでもくっきり表示されます。新しいアカウントにサーバーが割り当てたアバターも同様に表示されます。アプリが読み取れないアバターは、これまでどおり人物のプレースホルダーで表示されます。アバターの作成は現在 Web 版のみで、サーバー側で段階的に公開されています。
