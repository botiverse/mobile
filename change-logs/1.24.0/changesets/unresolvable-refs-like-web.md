## zh-CN

消息里的 `#4442` 这类编号，如果不是当前会话中已知的任务，现在和网页端一样显示为普通文字，不再显示成可点按的标签，点按后也不会再提示“无法打开”。`#7` 只会打开当前会话中的任务 7，不再到其他频道中查找同号任务或让你从中选择。

## en

A number like `#4442` in a message that isn't a known task of the conversation now shows as plain text, as on the web, instead of a tappable tag that only said it couldn't be opened. `#7` opens task 7 of the current conversation only; the app no longer searches other channels for a task with that number or asks you to pick one.

## ja

メッセージ内の `#4442` のような番号は、この会話の既知のタスクでなければ、Web と同じく通常のテキストとして表示されるようになりました。タップできるタグとして表示されて「開けません」と表示されることはなくなります。`#7` は現在の会話のタスク 7 だけを開き、ほかのチャンネルから同じ番号のタスクを探したり選ばせたりしなくなりました。
