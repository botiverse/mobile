## zh-CN

长按消息里的链接现在会打开这条消息的菜单（之前没有任何反应），菜单顶部多出这个链接的一栏：一行显示链接地址，下面是「打开」「复制链接」「分享」；不是 Raft 的链接还有「在浏览器中打开」。Raft 链接点「打开」会直接在 App 内打开。长按 @提及、频道或任务标签也会打开消息菜单。轻点链接仍然直接打开。

## en

Long-pressing a link in a message now opens that message's menu (it did nothing before), with a section for the link on top: the link's address on one line, then Open, Copy link and Share, plus Open in browser for links outside Raft. Open takes a Raft link straight to it in the app. Long-pressing an @mention, channel or task chip opens the message menu too. Tapping a link still opens it.

## ja

メッセージ内のリンクを長押しすると、そのメッセージのメニューが開くようになりました（以前は何も起きませんでした）。メニューの上部にはそのリンクの欄があり、リンクのアドレスを 1 行で表示し、「開く」「リンクをコピー」「共有」を選べます。Raft 以外のリンクでは「ブラウザーで開く」も表示されます。Raft のリンクは「開く」でアプリ内で開きます。@メンション、チャンネル、タスクのチップを長押ししてもメッセージのメニューが開きます。リンクをタップした場合はこれまでどおり開きます。
