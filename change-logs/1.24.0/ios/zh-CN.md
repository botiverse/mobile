✨ 新功能
- 「设置 › 账号」新增「登录与安全」分组，显示两步验证是否已开启，以及账号有几个通行密钥。点按其中一行会在系统浏览器中打开网页版对应的设置（通行密钥需要在浏览器中使用）；回到 App 后数字会自动刷新。公告里指向两步验证或通行密钥设置的链接，现在也会打开这个分组。无法加载时会显示错误、重试按钮和追踪 ID。
- Agent 的「动态」页新增「子 Agent」视图：Agent 启动过子 Agent 后，切换栏里会出现「子 Agent」及其数量，列出运行中和已结束的子 Agent（任务、类型、步数、用时和状态）。点按一个子 Agent 可查看它自己的动态；有权限停止当前回合的人，还能单独停止一个正在运行的子 Agent，其他子 Agent 和 Agent 本身继续运行。原始日志中启动子 Agent 的那一行和子 Agent 的「Subagent」标签都可以直接打开它。工具调用的名称也与网页版一致（如「Running command」「Reading file」），各运行时读起来相同。
- Agent 因登录失效、套餐不包含所用模型或服务商余额用完而无法运行时（包括同一登录下另一个 Agent 遇到这个问题、它因此被暂停的情况），Agent 资料页的状态不再显示「在线」，而是显示原因，例如「需要重新登录 Codex CLI」，旁边有「重试」按钮。只有可以重启这个 Agent 的人才会看到「重试」；不能查看 Agent 详情的成员只会看到「错误」。
- 迁移 Agent 时，如果原计算机正在等 Agent 结束当前回合、后台任务或排队的消息，迁移卡片现在会写明在等什么、最晚几点停下。Agent 自己精简工作区并重新发起迁移时，卡片会说明它代谁重试，并列出失败的那次和本次的大小（以 GiB 计）；这次重试也失败时，会提示下一次迁移需要由人发起。操作卡片上的计算机现在显示为你的计算机列表里的名字，而不是一串 ID。
- 在你的个人助理的资料页里，新增了「助理」一栏，可以编辑「补充指令」：告诉助理你希望它怎么替你做事。只有你能看到这些内容，最多 4000 个字符，快到上限时会显示字数。如果服务器所有者或管理员暂停了你的助理，它的资料页顶部会显示是谁、什么时候暂停的，并提供「启动」按钮，让你重新启动它。该功能正在逐步开放。
- 频道可以有一条公告了，和网页版一致：把频道里的一个 Artifact 设为公告后，它会以一行横条显示在消息列表上方，所有人都能看到，不能隐藏。公告有新版本而你还没看过时，标题会加粗并显示提醒点，同时显示是谁更新的（有更新说明时显示说明）；看过之后显示正文的第一行。点横条即可在应用内的 Artifact 查看器中打开；「⋯」里可以复制链接，有权限的人还能进入「公告设置」。在频道详情里，频道所有者和服务器所有者、管理员可以设置、替换或移除公告；设置、替换、移除都会在频道里留下一条记录。该功能正在逐步开放。
- 计算机页面的运行时卡片现在可以像网页版一样登录和退出该计算机上的运行时：Claude Code、Codex CLI、Kimi Code（先选择账号所在地区）、Qoder、Grok Build，以及服务器开放时的 Antigravity。登录在计算机上进行：卡片会显示要在浏览器中打开的登录页面（Claude Code 和 Antigravity 还需粘贴页面给出的代码），或一个可复制的设备码。Pi 和 OpenCode 2 可以按模型提供方逐个登录账号（OpenCode 可选择登录方式）或保存 API Key，也可以逐个退出或移除。未登录的运行时标签会变成橙色并注明“（未登录）”；计算机上缺少或版本过旧的命令行工具会说明原因，并给出可复制的安装命令。只有连接这台计算机的人或服务器所有者、管理员可以操作。出错时会显示追踪 ID。
- 「计算机」页面新增了工具栏，和网页版一致：可以按名称、主机名或所有者搜索计算机，按状态（在线、离线、需要处理）和运行时筛选，按名称前缀或提供方分组，并按名称、各运行时余量、磁盘用量或内存用量排序。列表默认按名称从 A 到 Z 排列；离线的计算机收在列表末尾的「离线」分区里，点一下即可展开，没有在线的计算机时默认展开。分组可以单独收起。没有匹配结果时，可以一键「清除筛选」。分组、排序和卡片/列表视图会保存在这台设备上；搜索和筛选只在本次使用期间保留，切换服务器后会清空。卡片/列表切换按钮现在卡片在前。
- 在开启外部频道的服务器上，服务器所有者和管理员可以通过邮件邀请服务器以外的人加入频道，与网页版一致：在频道成员的「添加成员」里选择「邀请 {服务器} 以外的人」，粘贴最多 20 个邮箱，先查看每个地址会怎样处理（会被邀请、作为服务器成员直接加入、已邀请、已在频道里、在其他频道当访客、地址无效），再发送。公开频道在发出第一个邀请时会变为私有，发送前会提示。频道成员页的「已邀请」里列出待接受的邀请和剩余天数，可以重新发送或撤回。免费版服务器已有一个外部频道时，会说明原因并提供「升级」。出错时显示原因和追踪 ID。
- 在 Raft 里点外部频道的邀请链接，会在 App 里打开邀请页面，与网页版一致。页面列出服务器提供的加入方式：作为访客加入、连接你所在的服务器（可多选，需要批准的服务器可以选择请哪位管理员批准），或创建新服务器并连接。加入后直接打开频道；连接需要时间或等待批准时，页面会显示进度，可以取消申请。邀请链接无效时会说明；如果邀请是发给另一个邮箱的，会显示脱敏后的邮箱，并提供「切换账号」。出错时显示原因和追踪 ID。该功能正在逐步开放。
- 设置 › 反馈的列表顶部多了一条提示：任意一个 Agent 都能帮你起草反馈，跟它说一声就行，发出前你会先确认。你在这台设备上发出过一份 Agent 起草的反馈后，这条提示就不再显示。
- 在「设置 › 反馈」中打开一个工单后，标题栏新增「复制链接」按钮。复制的链接可在网页版打开同一工单，并注明当前平台（Android 或 iOS），把它粘贴给 Agent，Agent 就能找到这个工单及其诊断日志。
- 支持显示用户在网页版中搭建的像素头像，与网页版一致：在消息、私信、成员列表、个人资料、搜索、动态和附件评论等所有显示用户头像的地方，都会按原样显示完整的像素形象，放大缩小时保持像素清晰。由服务器自动分配的像素头像也同样显示。无法识别的头像仍显示默认的人物占位图标。头像搭建目前只能在网页版中进行，并且由服务器逐步开放。
- 应用图标现在会跟随 iOS 主屏幕的深色和着色样式显示。
- 在 iPhone 和 iPad 上，剪贴板里只有图片、没有文字时（比如截图后点「拷贝并删除」），可以直接粘贴到输入框：输入框菜单里的「粘贴」或 ⌘V 会打开图片编辑器，和选取照片时一样，可以先标注再点「完成」放进待发送附件。一次最多粘贴 9 张，不会自动发送，也不会往消息里打出任何文字。剪贴板里同时有文字时，照常粘贴文字。
- 在开启外部频道的服务器上，频道成员可以把自己的服务器连接到频道，与网页版一致：「已连接的服务器」标题旁的「⋯」里有「连接你的服务器」，列出你的服务器，你是所有者或管理员、还没连接的可以多选，已连接的和你不是管理员的会说明原因。不需要托管方同意，每个服务器的结果分别显示，被拒绝的会说明原因并附上追踪 ID。你连接的服务器在列表里标为「由你连接」。私有频道也可以这样连接，这个服务器作为托管方；连接前会提示频道会变成与其他服务器共享的频道，你连入的服务器能看到它之前的消息。
- 在频道或私信里长按一条消息，菜单中新增「将频道标为未读」（私信里为「将私信标为未读」），与侧栏里的「标为未读」相同；留在这个会话里时，它会一直保持未读。如果你关注了这条消息的消息列，菜单里还会出现「将消息列标为未读」。
- 创建或编辑使用 Built-in Pi + OpenRouter 的 Agent 时，模型既可以从列表中选择，也可以直接输入任意 OpenRouter 模型 ID；还可以选填上下文窗口和最大输出长度。需要将计算机更新到新版本。
- 任务页面的「更多」菜单末尾新增「删除任务」，任务的创建者和服务器所有者、管理员可以使用。删除前会先确认，并说明此操作无法撤销、任务中的讨论会一并删除。删除后页面会关闭；删除失败时确认框保持打开，显示原因和追踪 ID。
- 现在可以在任务页面里修改任务的标题和描述：点按标题或描述旁的铅笔图标，没有描述时点按「添加描述」。改完点按「保存」（标题也可以用键盘上的完成键保存），点按「取消」或返回键会放弃修改。描述留空即删除描述。如果你编辑时有人改了同一处，会先提示你，再次保存才会用你的版本替换。保存失败时你输入的内容会保留，并显示原因和追踪 ID。修改会立刻出现在任务列表和其他打开这个任务的地方。
- 任务带着原因交给别人时，任务对话里现在显示为一张卡片：「[头像] @交出者 → [头像] @接手者」、时间，以及交接原因；任务之后回到交出者手里时，卡片会写明「已接回」或「交回给了」谁，并变淡。请求迁移 Agent 的卡片现在也显示它当前所在的计算机，以及由其他 Agent 发起时是谁发起的。
- 链接卡片的按钮现在也可以来自本服务器自己创建、未经 Raft 审核的应用。点按这类应用的任何操作按钮时，都会先弹出 Raft 的确认框，写明由哪个应用执行、它未经 Raft 审核、会收到你的名字并用自己的权限执行；确认后才会执行。

🔧 改进
- 按钮和菜单项不再以「…」结尾，与网页版一致，比如「新建分区」「编辑分区」「自定义」「打开方式」。「加载中…」这类进度文字和输入框提示保持不变。
- 带操作按钮的公告现在只显示该操作按钮，不再在旁边多显示一个「我知道了」；要关闭公告，点右上角的 ×。没有操作的公告仍然显示「我知道了」。
- 在别的 App 里点 Artifact 的分享链接（`app.raft.build/artifacts/…`），现在会直接在 Raft App 的 Artifact 查看器里打开，不再进浏览器。
- Artifact 查看页中，网页自己工具栏左侧的「返回」现在可以直接关闭查看页，回到打开它的地方。
- 频道和私聊的输入框重新有了「作为任务」：勾上后发出去仍是一条普通消息，并从这条消息创建任务，和网页一致。话题和任务对话里没有这个选项。
- 频道设置改为和网页版一样的「详情」：在手机上是一个带「返回」的页面，在宽屏上是会话右侧的一栏，不再盖住会话，可以一边看详情一边继续聊天。点频道名称或标题栏里的设置按钮即可打开，设置按钮在详情打开时保持按下状态，再点一次就关闭。详情从上到下依次是：频道图标、名称、公开或私密标签和描述（较长的描述折叠为三行，可点「展开全文」），能编辑的人点「编辑」后在原处修改名称和描述；成员卡片（点它在同一处打开成员列表）；公告；已连接的服务器；「频道设置」（公开或私密，以及行末的「设为私密」或「设为公开」、「游客可见」、Slack 的连接或更换）；「我的偏好」（通知、侧栏分区、折叠长消息）；最后是归档、离开、停止所有 Agent（橙色）和删除或断开（红色）。
- 「计算机」卡片的 ⋯ 菜单新增「删除计算机」，和网页版一样会先确认（计算机上还有 Agent 时提示先移除），删除失败时显示原因和追踪 ID。卡片的下一步也补齐了：不能从 App 升级的计算机会显示带终端图标的升级按钮，点开即可复制在那台机器上运行的安装命令；之前的安装没有完成或上次从网页升级失败时，升级按钮旁会出现 ⚠，说明原因和处理步骤；由 Raft Desktop 管理的计算机会注明「Raft Desktop 会自动更新这台计算机。」从首页的计算机提醒点「查看」时，只涉及一台计算机会直接打开它，涉及多台会打开只显示「需要处理」的列表。
- 「计算机」页面的卡片和列表更接近网页版：按某个运行时余量、磁盘用量或内存用量排序时，每张卡片会把这一项放在最上面并加粗显示。用量已用完时，会显示多久后恢复，例如「3h 后重置」，不知道重置时间时仍显示「已用完」。卡片上的 Agent 排成一行，放不下时可以左右滑动，边缘渐隐提示还有更多，不再显示「+N」。列表视图改为网页版的手机列表：顶部固定显示各运行时的列标题，每台计算机一块，显示名称、Agent 数、版本、所有者、Agent、各运行时的用量（与列标题对齐），离线时显示上次在线时间，以及下一步操作。
- 「计算机」页面在第一次加载、还没有保存的列表时，不再只显示转圈：工具栏会先出现，下面是和卡片形状一致的占位，和网页版一样，加载完成后内容直接落在原位。
- 外部频道（有访客、有其他服务器加入或有待接受的外部邀请）在侧边栏、频道顶部、动态、草稿、搜索、转发和输入框的频道建议里都显示同一个外部频道图标，与网页版一致；其他频道的图标不变。从频道里打开某个人的资料时，「来自」会列出这个人在该频道所属的服务器。
- 应用内网页（如设置中的网页、更新日志和应用内浏览器）打开得更快：页面内容到达即开始显示，不再先显示一块空白，加载期间顶部会显示一条细进度条。页面加载失败或长时间无响应时，仍会显示错误提示和“重试”按钮。应用会提前准备好网页视图，首次打开网页时也更快。
- 在聊天中点按 Agent 准备好的反馈卡片，现在会打开 App 自己的反馈表单，内容已按卡片填好，可以修改后发送；发送后直接打开新的反馈工单。如果卡片已经发送过或无法读取，会打开「设置 › 反馈」中的工单列表。工单列表无法加载时，会显示错误、重试按钮和追踪 ID。
- 在「设置 › 反馈 › 新建反馈」中添加图片后，会直接打开图片编辑器，可以先标注再返回表单。点「完成」后，表单中附带的是编辑后的图片；点返回取消编辑，则保留原图。
- 在 iPhone Duo 上，屏幕侧边竖栏里的按钮（返回、搜索、设置、时间线、更多等）改由系统绘制，和系统标签栏一样是玻璃样式的按钮，每个页面都一样，包括回复串页面。「更多」里的操作以系统菜单显示。
- 在开启外部频道的服务器上，联合频道的「已连接的服务器」与网页版一致：托管方排在最前并标有「托管方」，不再显示免费/付费标签和「已连接」标记，只有待接受的服务器仍会标注；邀请服务器的表单和「重新发送邀请」不再提供。托管方的所有者和管理员可以在其他服务器那一行断开它，确认后该服务器的成员和 Agent 会离开频道。托管方自己的频道设置里不再有「断开频道」，只能归档，归档确认会说明其他所有服务器上的这个频道也会一并归档。断开自己服务器的连接后，会提示「{服务器} 已断开与 #{频道} 的连接」。

- Agent 出现常见运行错误（用量达到上限、余额不足、模型不可用、需要登录、无法连接模型服务、输入过长）时，状态会显示简短的原因，Agent 页面会用你的语言说明原因和下一步。可以管理该 Agent 的人还会在下方看到错误详情；其他成员看到的是说明，而不是错误原文。
- 搜索结果中，已归档的频道现在排在仍在使用的频道之后，你已加入的频道排在未加入的之前，与网页版一致。名称完全匹配的频道仍然排在最前。
- 消息列顶部的副标题和网页版一致：先是这条消息列所在的频道或私信，后面跟着回复数，比如“@Lagoon · 12 条回复”。点频道或私信的名字，会回到那里并定位到原消息；在原生导航栏里也可以点。回复数在原消息的统计还没更新时，也会按已经看到的回复算，没有回复时显示“0 条回复”。
- 反馈附带的诊断日志会记录页面多久显示出内容；超过一秒仍是空白时会注明在等待什么，方便排查白屏。

🐛 修复
- 修复动态列表顺序错乱的问题：有新回复的讨论串在服务器更新后可能一直停留在顶部，压在之后有更新动态的行之上，较早的行（如「25 分钟」「1 小时」）显示在「刚刚」的行上方。现在动态始终按最新活动时间排列，最新的在最上面。
- 修复列表中 Agent 状态不刷新的问题：首页私信、成员列表里的 Agent 不会再在它正在工作时一直显示“在线”，而要点进去才看到“工作中”。切换到另一个服务器后，Agent 状态也会立即刷新。
- 没有头像的 Agent 在所有地方都显示默认的像素机器人，不再显示名字首字母或人形图标；头像图片加载失败时也一样。没有头像（或头像加载失败）的人在所有地方都显示人形占位图标，不再显示名字首字母，与网页版一致。Agent 私信列表中的对方现在按 Agent 显示；搜索结果中没有头像的人不再显示随机生成的像素头像；没有头像的外部（如 Slack）发送者显示其名字首字母，与网页版一致。
- 输入框上方待发送附件的上传状态不再溢出：图片缩略图上的「正在完成上传…」「正在检查文件…」「上传失败」等文字始终留在缩略图内，放不下时换行或以省略号结尾，不再被屏幕边缘截断或盖住旁边的内容。完成上传时进度条改为来回滑动，表示正在等待服务器确认。
- 计算机详情页「此计算机上的 Agent」里，没有设置头像的 Agent 现在显示默认的像素头像（与网页版一致），不再显示名字首字母。
- 长按消息里的链接现在会打开这条消息的菜单（之前没有任何反应），菜单顶部多出这个链接的一栏：一行显示链接地址，下面是「打开」「复制链接」「分享」；不是 Raft 的链接还有「在浏览器中打开」。Raft 链接点「打开」会直接在 App 内打开。长按 @提及、频道或任务标签也会打开消息菜单。轻点链接仍然直接打开。
- 在 Agent 会客厅的讨论串里回复时，输入框不再一直显示「正在确认权限，暂时无法发送」：和网页版一样，会客厅里的讨论串可以直接回复（只读或已归档的会客厅除外）。如果某个讨论串的发送权限几秒内仍无法确认，App 会直接向服务器查询，不再无限等待。
- 引用块（以 `>` 开头）里的 @某人 现在显示为普通文字，不再显示为提及标签；回复时引用别人的消息，也不会再次提及其中被 @ 的人。引用之后你自己写的 @ 仍然是提及。
- 当你在打开某个频道时被他人移出该频道，App 现在会关闭这个频道、提示「你已不在这个频道中」，并从「动态」中移除它的条目，而不是一直停留在频道里反复尝试加载新消息。
- Agent 的「报告问题」表单现在说明报告会发送给 Raft 团队，不再错误地写成工作区所有成员都能查看；「包含」下方多余的说明也已删去，表单更简短。
- 修复消息下方的「已收藏」标记点不动的问题。现在和网页一样，点一下就会取消收藏。
- 在任务会话中，如果你还没有加入该任务所在的频道，输入框位置会显示「加入频道」。此前点这个按钮总会提示「无法加入频道」，现在会加入任务所在的频道，加入后直接出现输入框，可以回复。
- 消息列顶部“对话开始”下面的回复数不再在已经有回复时显示“0 条回复”。它和消息列标题里的回复数用同一个算法：原消息的统计还没更新时，也会按已经看到的回复算；还在加载时先不显示。
- 消息中以 `_` 结尾的链接（例如分享链接）现在会完整打开，不再丢掉末尾的 `_`；单独的 `_` 也不会再显示成 `*`。
- 消息里的 `#4442` 这类编号，如果不是当前会话中已知的任务，现在和网页端一样显示为普通文字，不再显示成可点按的标签，点按后也不会再提示“无法打开”。`#7` 只会打开当前会话中的任务 7，不再到其他频道中查找同号任务或让你从中选择。在任务的对话里，`#7` 指的是该任务所在频道的任务 7；只读查看时同样显示这些任务标签。
