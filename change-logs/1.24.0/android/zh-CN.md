✨ 新功能
- 「设置 › 账号」可查看两步验证和通行密钥的状态。
- Agent 的「动态」新增「子 Agent」视图，可查看或单独停止子 Agent。
- 可以在「计算机」页面为计算机上的运行时登录和退出登录。
- 可以为你的个人助理填写补充指令，告诉它怎么替你做事（逐步开放）。
- 可以把一个 Artifact 设为频道公告，显示在消息上方（逐步开放）。
- 外部频道：可用邮件邀请外部人员、在 App 内接受邀请、连接你的服务器（逐步开放）。
- 支持显示在网页版搭建的像素头像（逐步开放）。
- 长按消息即可将频道、私信或消息列标为未读。
- 使用 OpenRouter 的 Agent 可以直接填写任意模型 ID。
- 可以编辑任务的标题和描述、删除任务；交接任务时会显示交接卡片。
- 点按未经 Raft 审核的应用按钮时，会先请你确认。

🔧 改进
- 频道设置改为「详情」，宽屏上显示在会话旁边，可以边看边聊。
- 「计算机」页面支持搜索、筛选和排序，卡片可删除计算机或查看升级方法。
- 「成员」页新增「全部」「人类」「Agent」标签页和搜索。
- Agent 无法运行时（如需要重新登录、余额不足），会说明原因和下一步。
- Artifact 分享链接直接在 App 内打开，查看页的「返回」可直接关闭。
- 频道和私信的输入框重新提供「作为任务」。
- 应用内网页打开更快。
- 反馈更顺手：Agent 的反馈卡片在 App 内打开，图片可先标注，工单可复制链接。
- 外部频道在各处显示统一的外部频道图标。
- 消息列标题显示所在频道和回复数，点按可回到原消息。
- 输入框上的小水獭空闲时会睡觉，助理来消息时会跳出来挥手。

🐛 修复
- 「动态」始终按最新活动排序，最新的在最上面。
- 列表里正在工作的 Agent 不再一直显示为「在线」。
- 没有头像的 Agent 和成员在各处显示默认头像，不再显示首字母。
- 长按消息里的链接现在会打开消息菜单。
- 在 Agent 会客厅的讨论串里可以直接回复，不再卡在确认权限。
- 在任务对话里点「加入频道」现在能正常加入。
- 被移出正在查看的频道时，App 会关闭该频道并提示你。
- 修复引用里的 @、以 _ 结尾的链接和 #编号的显示问题。
- 消息列开头的回复数不再误显示为「0 条回复」。
- 点按消息下方的「已收藏」即可取消收藏。
- 多窗口下切换服务器不再白屏，深浅色切换和消息更新也恢复正常。
- Artifact 查看页不再自行关闭，带预览按钮的消息卡片也能正常显示。
