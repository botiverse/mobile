- エージェントの「アクティビティ」タブに「サブエージェント」ビューを追加しました。エージェントがサブエージェントを起動すると、切り替えに「サブエージェント」と件数が表示され、実行中と終了済みのサブエージェント（依頼内容、種類、ステップ数、時間、状態）が一覧になります。タップするとそのサブエージェント自身のアクティビティを確認できます。ターンを停止できる人は、実行中のサブエージェントを個別に停止でき、エージェント本体と他のサブエージェントは動き続けます。生ログでは、サブエージェントを起動した行とサブエージェントのバッジから直接開けます。ツール呼び出しの名前も Web 版と同じ表記（「Running command」「Reading file」など）になり、どのランタイムでも同じように表示されます。

- 移行元のコンピューターがエージェントの現在のターン、バックグラウンドタスク、キューにあるメッセージの完了を待っている間、移行カードに何を待っているか、遅くともいつ停止するかが表示されるようになりました。エージェントが自分でワークスペースを整理して移行を再試行すると、誰に代わって再試行したか、失敗した試行と今回の試行のサイズ（GiB 単位）が表示されます。その再試行も失敗した場合は、次の移行を人が開始する必要があることが表示されます。操作カード上のコンピューターは、ID ではなくコンピューター一覧の名前で表示されるようになりました。

- コンピューターページのランタイムカードから、Web 版と同じようにコンピューター上のランタイムへのログインとログアウトができるようになりました：Claude Code、Codex CLI、Kimi Code（先にアカウントの地域を選択）、Qoder、Grok Build、そしてサーバーが提供している場合は Antigravity。ログインはコンピューター上で行われます。カードにはブラウザーで開くログインページ（Claude Code と Antigravity は表示されたコードを貼り付け）か、コピーできるデバイスコードが表示されます。Pi と OpenCode 2 はモデルプロバイダーごとにアカウントでログイン（OpenCode はログイン方法を選択可能）するか API キーを保存でき、プロバイダーごとにログアウトや削除もできます。未ログインのランタイムのバッジはオレンジになり「（未ログイン）」と表示されます。コンピューターにコマンドラインツールがない、または古い場合は理由とコピーできるインストールコマンドが表示されます。操作できるのは、このコンピューターを接続した人、またはサーバーのオーナーか管理者だけです。エラーにはトレース ID が表示されます。
- 「コンピューター」ページに、Web 版と同じツールバーが追加されました。名前、ホスト名、オーナーでコンピューターを検索し、状態（オンライン、オフライン、要対応）とランタイムで絞り込み、名前の接頭辞またはプロバイダーでグループ化し、名前、各ランタイムの残量、ディスク使用量、メモリ使用量で並べ替えられます。一覧は既定で名前の A から Z の順です。オフラインのコンピューターは一覧の最後の「オフライン」セクションに折りたたまれ、タップで開けます（オンラインのコンピューターがないときは最初から開いています）。各グループも折りたためます。一致するものがないときは「すべてクリア」で元に戻せます。グループ、並べ替え、カード／リスト表示はこの端末に保存されます。検索と絞り込みはアプリの使用中のみ保持され、別のサーバーに切り替えるとクリアされます。カード／リストの切り替えは、カードが先になりました。
- 外部チャンネルが有効なサーバーでは、Web 版と同じく、サーバーのオーナーと管理者がサーバー外部の人をメールでチャンネルに招待できるようになりました。チャンネルメンバーの「メンバーを追加」から「{サーバー} の外部の人を招待」を選び、最大 20 件のメールアドレスを貼り付けて、各アドレスの扱い（招待、サーバーのメンバーとして直接追加、招待済み、参加済み、別のチャンネルのゲスト、無効なアドレス）を確認してから送信します。公開チャンネルは最初の招待で非公開になり、送信前に案内されます。メンバーページの「招待済み」に保留中の招待と残り日数が表示され、再送や取り消しができます。無料プランのサーバーですでに外部チャンネルがある場合は、その旨と「アップグレード」が表示されます。エラー時は理由とトレース ID が表示されます。
- 外部チャンネルの招待リンクを、Web 版と同じくアプリで開けるようになりました。招待メールのリンクからアプリが直接開きます（未ログインの場合はログイン後に開きます）。ページには、サーバーが提示する参加方法が表示されます。ゲストとして参加する、所属しているサーバーを接続する（複数選択でき、承認が必要なサーバーは承認を依頼する管理者を選べます）、または新しいサーバーを作成して接続する、のいずれかです。参加するとチャンネルが開きます。接続中や承認待ちの間は進捗が表示され、依頼を取り消すこともできます。無効なリンクの場合はその旨が表示され、別のメールアドレス宛ての招待の場合は、伏せ字のアドレスと「アカウントを切り替え」が表示されます。エラー時は理由とトレース ID が表示されます。この機能は段階的に公開されています。
- 設定 › フィードバックの一覧の上部に、どのエージェントでもフィードバックを下書きでき、頼むだけで送信前に確認できるというヒントが表示されるようになりました。このデバイスでエージェントが下書きしたフィードバックを一度送信すると、ヒントは表示されなくなります。
- 「設定 › フィードバック」で開いたチケットのヘッダーに「リンクをコピー」が追加されました。コピーしたリンクはウェブ版で同じチケットを開き、使用中のプラットフォーム（Android または iOS）も含まれるため、エージェントに貼り付ければ、そのチケットと診断ログを見つけられます。
- Web 版で作成したピクセルアバターがアプリにも表示されるようになりました（Web 版と同じ表示）。メッセージ、DM、メンバー一覧、プロフィール、検索、アクティビティ、添付ファイルのコメント、ホーム画面ウィジェットなど、人のアバターが表示されるすべての場所で、ピクセルキャラクター全体がどのサイズでもくっきり表示されます。新しいアカウントにサーバーが割り当てたアバターも同様に表示されます。アプリが読み取れないアバターは、これまでどおり人物のプレースホルダーで表示されます。アバターの作成は現在 Web 版のみで、サーバー側で段階的に公開されています。
- 外部チャンネルが有効なサーバーでは、Web 版と同じく、チャンネルのメンバーが自分のサーバーをチャンネルに接続できるようになりました。「接続済みのサーバー」の横の「⋯」から「所属しているサーバーを接続」を選ぶと、あなたのサーバーが一覧表示されます。オーナーまたは管理者で、まだ接続されていないサーバーは複数選択でき、それ以外のサーバーには選べない理由が表示されます。ホストの承認は不要です。結果はサーバーごとに表示され、拒否された場合は理由とトレース ID が表示されます。あなたが接続したサーバーには一覧で「あなたが接続」と表示されます。非公開チャンネルにも、このサーバーをホストとして接続できます。接続前に、チャンネルが他のサーバーと共有され、接続したサーバーでは過去のメッセージが表示されることが案内されます。
- チャンネルや DM でメッセージを長押しすると、メニューに「チャンネルを未読にする」（DM では「DM を未読にする」）が追加されました。サイドバーの「未読にする」と同じ操作で、その会話にいる間は未読のままです。メッセージのスレッドをフォローしている場合は、「スレッドを未読にする」も表示されます。
- Built-in Pi と OpenRouter を使うエージェントを作成・編集するとき、モデルを一覧から選ぶことも、任意の OpenRouter モデル ID を直接入力することもできるようになりました。コンテキストウィンドウと最大出力も任意で設定できます。コンピューターを新しいバージョンに更新する必要があります。
- タスクのページの「その他」メニューの最後に「タスクを削除」を追加しました。タスクを作成した人と、サーバーのオーナー・管理者が使えます。削除の前に、元に戻せないこととタスク内の議論も一緒に削除されることを確認します。削除するとページが閉じます。削除に失敗した場合は確認画面が開いたまま、理由とトレース ID が表示されます。
- タスクのページで、タイトルと説明を編集できるようになりました。タイトルや説明の横の鉛筆アイコンをタップするか、説明がない場合は「説明を追加」をタップします。編集が終わったら「保存」をタップします（タイトルはキーボードの完了キーでも保存できます）。「キャンセル」または戻るで元の内容に戻ります。説明を空にすると説明は削除されます。編集中に他の人が同じ箇所を変更した場合は先にお知らせし、もう一度保存するとあなたの内容で置き換えます。保存に失敗しても入力内容は残り、理由とトレース ID が表示されます。変更はタスク一覧やこのタスクを開いている画面にすぐ反映されます。
- 理由を添えてタスクを誰かに渡すと、タスクの会話にカードとして表示されるようになりました。「[アバター] @渡した人 → [アバター] @受け取った人」、時刻、理由が表示されます。あとでタスクが渡した人に戻ると、誰が引き取ったか・戻したかが表示され、カードは薄く表示されます。エージェントを別のコンピューターへ移すよう求めるカードには、現在のコンピューターと、別のエージェントが依頼した場合は依頼したエージェントも表示されるようになりました。
- リンクカードに、サーバーが独自に作成した Raft の審査を受けていないアプリの操作ボタンが表示されるようになりました。こうしたアプリの操作ボタンを押すと、まず Raft の確認ダイアログが開き、実行するアプリ、Raft の審査を受けていないこと、あなたの名前を受け取り自身の権限で実行することが表示されます。確認するまで何も実行されません。
