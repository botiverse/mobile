## zh-CN

Computer 卡片右上角新增 ⋯ 菜单。能管理这台 Computer 的人可以在菜单里点「创建 Agent」，打开创建 Agent 的表单，并已选好这台 Computer（需要时仍可换成别的）；Computer 离线时不显示这一项。Computer 在线、且没有在升级或重启时，菜单里还有「重启」。

## en

Computer cards now have a ⋯ menu. If you can manage the Computer, choose "Create Agent" there to open the create form with that Computer already selected (you can still pick another); it isn't shown while the Computer is offline. While the Computer is online and not upgrading or restarting, the menu also has "Restart".

## ja

コンピューターのカードに ⋯ メニューが追加されました。そのコンピューターを管理できるユーザーは、メニューの「エージェントを作成」から、このコンピューターが選択された状態で作成フォームを開けます（別のコンピューターに変更することもできます）。コンピューターがオフラインのときはこの項目は表示されません。コンピューターがオンラインで、アップグレード中や再起動中でないときは、メニューに「再起動」もあります。
