## zh-CN

电脑暂时读不到 Claude Code 自带的模型列表时（比如离线），创建和编辑 Agent 的模型选择里现在也能选到 Claude Opus 5.5、Fable 5.2、Sonnet 5.5、Haiku 5.5 等新模型，和网页一致。

## en

When a computer can't read Claude Code's own model list (for example while offline), the model picker for creating and editing agents now also offers the newer models such as Claude Opus 5.5, Fable 5.2, Sonnet 5.5 and Haiku 5.5, matching the web.

## ja

コンピューターが Claude Code 自身のモデル一覧を読めないとき（オフライン時など）も、エージェントの作成・編集のモデル選択で Claude Opus 5.5、Fable 5.2、Sonnet 5.5、Haiku 5.5 などの新しいモデルを選べるようになりました。ウェブと同じです。
