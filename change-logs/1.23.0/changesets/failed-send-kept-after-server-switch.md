## zh-CN

如果消息还在发送中时你切换到了另一个服务器，而这条消息随后发送失败，它现在会保留下来：回到原来的服务器后，它会显示为发送失败，并带有「重试」按钮，重启 App 后也还在。之前这条消息会直接丢失。

## en

If you switch to another server while a message is still sending and that send then fails, the message is now kept. When you go back to the first server it shows as failed with Retry, and it's still there after you restart the app. Before, the message was lost.

## ja

メッセージの送信中に別のサーバーに切り替え、その後送信に失敗した場合でも、メッセージが残るようになりました。元のサーバーに戻ると送信失敗として「再試行」付きで表示され、アプリを再起動しても残ります。これまではメッセージが失われていました。
