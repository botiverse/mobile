## zh-CN

在 iPad 等支持多窗口的设备上开启“多个应用窗口”后，切换到另一个工作区会在新窗口中打开它（已有该工作区的窗口时直接切到那个窗口），当前窗口保持原来的工作区，并保留你所在的标签页；之前会在当前窗口里打开，仍显示原来的工作区。系统无法再打开窗口时会改为在当前窗口切换。重新打开 App 后，各窗口仍显示各自的工作区。

## en

With Multiple app windows on, on an iPad or another device that supports multiple windows, switching to another workspace now opens it in a new window (or brings up the window already showing it) on the tab you were on, and the current window keeps its workspace. It used to open in the current window, which kept showing the old workspace. When the system can't show another window, the current window switches instead. Each window shows its own workspace again after the app is reopened.

## ja

iPad など複数ウインドウに対応したデバイスで「複数のアプリウインドウ」をオンにしていると、別のワークスペースに切り替えたときに新しいウインドウで開くようになりました（そのワークスペースのウインドウがすでにある場合はそのウインドウに切り替わります）。開いていたタブはそのままで、今のウインドウは元のワークスペースのままです。これまでは今のウインドウで開かれ、元のワークスペースが表示されたままでした。システムがウインドウを追加で開けない場合は、今のウインドウで切り替わります。アプリを開き直しても、各ウインドウはそれぞれのワークスペースを表示します。
