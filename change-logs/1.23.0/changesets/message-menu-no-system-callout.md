## zh-CN

开启「新消息菜单」（Beta）后，长按消息正文不再先弹出「全选 | 复制选中 | 回复」的文本选择小菜单、再叠上新菜单。现在长按消息任意位置都只会打开新的两行菜单，也不会选中文字；需要挑选部分文字时，可使用菜单里的「选择文本」。关闭该设置时行为不变。

## en

With "New message menu (Beta)" turned on, pressing and holding a message's text no longer shows the small "Select All | Copy selection | Reply" text-selection menu first, with the new menu then opening on top of it. Holding anywhere on a message now opens only the new two-row menu, without selecting any text. To pick part of the text, use "Select Text" in the menu. Nothing changes with the setting off.

## ja

「新しいメッセージメニュー」（ベータ）をオンにしているとき、メッセージ本文を長押しすると「すべて選択 | 選択部分をコピー | 返信」というテキスト選択用の小さなメニューが先に表示され、その上に新しいメニューが重なってしまう問題を修正しました。メッセージのどこを長押ししても新しい 2 行メニューだけが開き、テキストは選択されません。テキストの一部を選びたいときは、メニューの「テキストを選択」を使ってください。設定がオフのときの動作は変わりません。
