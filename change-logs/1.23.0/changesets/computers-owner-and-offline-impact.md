## zh-CN

Computer 现在会显示所有者：Computers 页面的每台 Computer 下方写着「所有者：某人」或「公共（无所有者）」，Computer 详情页多了「所有者」一行。所有者本人和服务器的所有者或管理员可以「转移所有者」，把它交给服务器里的另一位成员或设为公共；接入公共 Computer 的人可以点「设为我的」。从网页发起升级后，如果 Computer 要先等本服务器上的 Agent 完成手头的工作，会显示「正在等待本服务器上的 N 个 Agent…」。移除成员和离开服务器前会先确认，并说明哪些 Computer 会因此离线、上面有多少个其他人的 Agent，以及之后怎么恢复。

## en

Computers now show their owner: each Computer on the Computers page reads "Owner: <name>" or "Public (no owner)", and a Computer's page has an Owner row. The owner, and the server's owners and admins, can Transfer owner to another person in the server or make it Public; whoever connected a Public Computer can tap Make it mine. After an upgrade is started from the web, a Computer that first waits for this server's agents to finish their work says "Waiting for N agents on this server…". Removing a member and leaving a server now ask first, and say which Computers go offline as a result, how many agents on them belong to other people, and how to bring them back.

## ja

コンピューターにオーナーが表示されるようになりました。コンピューターページの各コンピューターに「オーナー：名前」または「公開（オーナーなし）」と表示され、コンピューターの詳細ページに「オーナー」の行が追加されました。オーナー本人とサーバーのオーナー・管理者は「オーナーを移す」で、サーバーの別のメンバーに移すか公開にできます。公開のコンピューターを接続した人は「自分のものにする」を選べます。Web からアップグレードを始めたあと、コンピューターがまずこのサーバーのエージェントの作業完了を待つ間は「このサーバーのエージェント N 件を待機中…」と表示されます。メンバーの削除とサーバーからの退出では先に確認が表示され、そのためにオフラインになるコンピューター、そこにあるほかの人のエージェントの数、元に戻す方法が示されます。
