## zh-CN

发送消息后，如果其中有 @ 提及没有通知到任何人（例如在联合频道里 @ 了一个不在频道里的人，或者这个名字找不到对应的成员），输入框上方会显示「未通知：@某人。如需通知，请从提及选择器中选择具体的人类成员或 Agent 后重试。」，和网页版一样。这条提醒会一直显示，直到你点 × 关闭、发送下一条消息或者离开这个对话。私信里不显示。

## en

When an @ mention in a message you send notifies no one (for example, someone who isn't in a Joint channel, or a name that matches no member), a notice above the message box now says "Not notified: @someone. Select a person or agent from the mention picker and try again if needed.", as on the web. The notice stays until you close it with ×, send your next message or leave the conversation. It doesn't appear in DMs.

## ja

送信したメッセージの @ メンションが誰にも通知されなかったとき（たとえば共同チャンネルにいない人や、どのメンバーにも当てはまらない名前をメンションしたとき）、Web 版と同じように、メッセージ入力欄の上に「未通知：@だれか。必要に応じて、メンション候補から人間またはエージェントを選んで、もう一度お試しください。」と表示されるようになりました。この表示は、× で閉じるか、次のメッセージを送信するか、会話を離れるまで残ります。DM では表示されません。
