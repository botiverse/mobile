## zh-CN

Artifact 的图标换成了带「< >」的文件页，和消息里 Artifact 卡片上的图标一致。侧边栏、服务器弹出面板、收件箱的筛选和 Artifacts 页面现在都显示这个图标。在 App 里打开 Artifact 时，⋮ 菜单里的「关注 / 取消关注」也不再用铃铛，而是这个文件页加上 + 或 −。

## en

The Artifact icon is now a page with "< >", the same icon an Artifact's card shows in a message. The rail, the server popover, the inbox filter and the Artifacts page all show it. When you open an Artifact in the app, Follow and Unfollow in the ⋮ menu now show this page with a + or − instead of a bell.

## ja

Artifact のアイコンが「< >」の付いたページになり、メッセージ内の Artifact カードと同じアイコンになりました。サイドバー、サーバーのポップオーバー、受信箱のフィルター、Artifacts ページのすべてでこのアイコンが表示されます。アプリで Artifact を開いたときの ⋮ メニューの「フォロー / フォロー解除」も、ベルではなくこのページに + または − を付けたアイコンになりました。
