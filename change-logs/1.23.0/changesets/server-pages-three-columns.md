## zh-CN

手机上点底栏的服务器标签打开的弹出面板里，最下方的服务器页面（Artifacts、成员、电脑、应用、设置）超过 4 个时改为每行 3 个排列，最后一行从左边开始。之前 5 个挤在一行，窄屏上像「Computadoras」这样较长的名称会被截断；现在每个名称都能完整显示。4 个及以下仍然排成一行。打开面板时，服务器列表会直接滚到当前服务器；屏幕较矮时，列表至少完整显示一行，必要时面板会稍微变高，实在放不下时整个面板可以上下滚动。

## en

In the popover that the server tab opens on a phone, the server's pages at the bottom (Artifacts, Members, Computers, Apps, Settings) now sit in rows of 3 when there are more than 4, with the last row starting from the left. Before, all five shared one row, and longer names such as "Computadoras" were cut off on narrow screens. Now every name shows in full. Four or fewer still sit in one row. The server list now opens scrolled to the current server. On a short screen it always shows at least one whole row: the popover grows a little if needed, and if it still doesn't fit, the whole popover scrolls instead of squeezing the list.

## ja

スマートフォンでサーバータブを押して開くポップオーバーで、下部のサーバーのページ（Artifacts、メンバー、コンピューター、アプリ、設定）が 4 つを超えるときは 1 行 3 つずつ並び、最後の行は左から始まるようになりました。これまでは 5 つが 1 行に並び、狭い画面では「Computadoras」のような長い名前が途中で切れていました。今はどの名前も最後まで表示されます。4 つ以下のときはこれまでどおり 1 行です。サーバー一覧は開いたときに現在のサーバーまでスクロールした状態で表示されます。画面の高さが低いときも一覧は少なくとも 1 行分を完全に表示し、必要に応じてポップオーバーが少し高くなります。それでも収まらない場合は、ポップオーバー全体をスクロールできます。
