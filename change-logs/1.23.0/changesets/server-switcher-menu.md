## zh-CN

首页的服务器切换菜单与网页版一致：每个服务器显示头像（没有头像时显示首字母方块）、名称和 /slug；其他服务器的未读动态显示为粉色计数（超过 99 显示 99+），已静音通知的服务器显示为灰色数字；当前所在的服务器名称加粗并带对勾，不再显示自己的计数。菜单底部可以加入社区、切换或创建服务器、邀请人类，拖动右侧把手可以调整顺序。在 iOS 上点按服务器名称打开的也是这个菜单，不再是只有名称和一个不带说明的数字的系统列表。

## en

The server switcher on Home now matches the web: each server shows its avatar (or its initial on a tile), its name and /slug; another server's unread Activity is a pink count (99+ past 99), or a gray number when that server's notifications are muted; the server you are in is bold with a check and no count of its own. At the bottom you can join the community, switch or create a server and invite humans, and the handle on the right reorders servers. On iOS, tapping the server name now opens this same menu instead of a system list with only names and an unlabeled number.

## ja

ホームのサーバー切り替えメニューがウェブ版と同じになりました。各サーバーにアイコン（ない場合は頭文字のタイル）、名前、/slug が表示され、他のサーバーの未読アクティビティはピンクの件数（99 を超えると 99+）、通知をミュートしているサーバーはグレーの数字で表示されます。現在のサーバーは太字にチェックが付き、自分の件数は表示されません。メニューの下部からコミュニティへの参加、サーバーの切り替え・作成、人間の招待ができ、右側のハンドルをドラッグして並べ替えられます。iOS でもサーバー名をタップするとこのメニューが開き、名前と説明のない数字だけのシステムリストではなくなりました。
