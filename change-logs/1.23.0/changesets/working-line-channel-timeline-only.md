## zh-CN

「N 个 Agent 正在这里工作」这一行现在只会出现在频道自己的消息流里，不会再出现在任务会话或讨论串中。之前打开任务会话时，这一行会把整个频道里正在工作的 Agent 都算进去。任务会话和讨论串里仍然会显示谁正在输入。

## en

The "N agents working here" line now only appears in a channel's own timeline, not in task conversations or threads. Before, a task conversation showed it with every agent working in the whole channel. Task conversations and threads still show who is typing.

## ja

「エージェント N 個がここで作業中」の行は、チャンネル自体のタイムラインにだけ表示されるようになり、タスクの会話やスレッドには表示されなくなりました。以前はタスクの会話を開くと、チャンネル全体で作業中のエージェントが数えられて表示されていました。タスクの会話とスレッドでは、これまでどおり入力中のエージェントが表示されます。
