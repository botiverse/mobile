## zh-CN

设置“反馈”里的“新建反馈”换成了和网页版一样的表单：先选类型（想法或问题），再在下方输入框里写内容、添加截图并发送。你选的类型会随反馈一起提交。发送时内容会保留在表单里；如果发送失败，表单上方会说明原因，并可直接重试。

## en

New Feedback in Settings › Feedback now uses the same form as the web: pick a type (Idea or Bug), then write your feedback, add screenshots and send it from the box below. The type you pick is sent with the feedback. What you wrote stays in the form while it is sent; if sending fails, the form says why and lets you try again.

## ja

設定の「フィードバック」の「新しいフィードバック」が Web 版と同じフォームになりました。種類（アイデアまたは不具合）を選び、下の入力欄に内容を書いてスクリーンショットを添付し、送信します。選んだ種類はフィードバックと一緒に送信されます。送信中も内容はフォームに残り、送信に失敗した場合は理由が表示され、そのまま再試行できます。
