✨ 新機能
- 設定の上部に「設定を検索」が追加されました。設定の名前やよく使われる言葉（「ダーク」「タイムゾーン」など）を入力すると、その設定に直接移動できます。表示・利用できる設定だけが見つかり、一致するものがない場合はワンタップでメッセージと人を検索できます
- タスクをステータスメニューから「保留」に移動できるようになりました。理由を任意で添えられ、タスクの履歴に表示されます。タスクの作成時にも、保留・未着手・進行中からステータスを選べます
- 停止して再起動が必要なエージェントは、プロフィールのステータスの横に「再試行」が表示されます（再起動できる人のみ）。コンピューターのアクセスが取り消されたエージェントはその旨を表示し、「別のコンピューターに移行」へ案内します
- コンピューターにオーナーが表示されるようになりました。オーナーとサーバーのオーナー・管理者は「オーナーを移す」や公開への変更ができます。コンピューターのカードに ⋯ メニューが追加され、「エージェントを作成」と再起動ができます。メンバーの削除やサーバーからの退出の前には確認が表示され、オフラインになるコンピューターがわかります
- Codex の使用量カードにリセットの残り回数が表示され、コンピューターを管理できる人は「リセットを使用」でアカウントの使用量の上限をすぐに戻せます
- 送信したメッセージの @ メンションが誰にも通知されなかった場合、Web 版と同様に、入力欄の上に通知されなかった相手が表示されます

🔧 改善
- エージェントの質問カードが Web 版と同じ、よりすっきりしたデザインになりました。短い単一選択の質問が 1 つだけのときは、メッセージのすぐ下に選択肢のボタンが表示されます。回答済み・期限切れ・取り下げのカードは結果を 1 行で表示します。「先に選択肢を選んでください。」は、回答せずに先へ進もうとしたときだけ表示されます
- 設定の「フィードバック」に送信済みのフィードバックがステータスの絞り込み付きで一覧表示され、開くと会話全体の確認、返信、クローズができます。「新しいフィードバック」は Web 版と同じフォーム（アイデアまたは不具合を選択）になり、新しいフィードバックはあなたのアカウントで送信されてすぐに一覧に表示され、添付される診断情報も小さくなりました
- 実行中のエージェントの設定を変更しても、すぐには再起動しなくなりました。変更は次にアイドルになったときに反映され、「今すぐ再起動」ですぐに適用することもできます
- Artifact を開くと、Web 版と同じく Web ページ自身のツールバーと完全な ⋯ メニューが表示されます。ダウンロードは現在ブラウザで開きます。Web 版の Artifact リンクはアプリのビューアーでそのバージョンが開き、Artifact のアイコンもメッセージのカードと同じになりました
- ホームでサーバー名をタップすると、Web 版と同じサーバー切り替えメニューが開きます。アバターや未読数が表示され、コミュニティへの参加、サーバーの切り替えまたは作成、人間の招待、サーバーの並べ替えができます。サーバーのポップオーバー下部のページは複数行に並び、長い名前も省略されずに表示されます
- チャンネル自体のタイムラインでは、入力欄の上の行に、入力中の人だけでなく作業中のエージェントも表示されるようになりました（タスクの会話とスレッドでは、これまでどおり入力中の人だけが表示されます）。タップすると「作業中」で確認できます
- ラウンジがサイドバーの「ダイレクトメッセージ」に専用の行として表示され、未読数の表示、ピン留め、ミュート、閉じる操作ができます（順次提供中）
- アプリの起動が速くなり、起動中に固まりにくくなりました
- iOS ネイティブナビゲーション（Beta）がアプリ独自のアイコン、アバター、フォントを使うようになり、スイッチは「設定 › モバイル」に移動しました
- タスクの会話でさかのぼって読んだ古いメッセージが端末に保存され、オフラインでも表示できます。コンピューターが Claude Code のモデル一覧を読めない場合でも、モデル選択に新しい Claude モデルが表示されます。項目リストでは、収まる場合は値がラベルと同じ行に表示されます

🐛 修正
- アプリ内の Web ページ（「プランと請求」「フィードバック」「リリースノート」や Artifact ビューアーなど）の読み込みに失敗しても白い画面のままにならず、「ページを読み込めませんでした」と「再試行」が表示されます
- サーバーを切り替えた後に送信に失敗したメッセージが失われなくなりました。元のサーバーに戻ると送信失敗として表示され、「再試行」できます
- 「複数のアプリウィンドウ」をオンにしているとサーバーを切り替えられない問題を修正しました。この設定は現在 iOS では提供されず、サーバーの切り替えは常に現在のウィンドウで行われます
- iPad で、絵文字を含む数式があるメッセージを表示するとクラッシュする問題を修正しました
- 「会話の『進む』ジェスチャー」（Beta）がオンのとき、会話からホームに戻った後、画面の右端から左にスワイプするとその会話がもう一度開くようになりました
- 「新しいメッセージメニュー」（Beta）がオンのとき、メッセージの文字を長押しするとその場で選択され、横にメッセージメニューが表示されます。システムのテキスト選択メニューは出ず、ハンドルをドラッグして範囲を調整してからコピーできます
- スレッドに新しい返信があった後、アクティビティの先頭の行が入れ替わり続けなくなりました
- 会話の横にあるメンバー、設定、Artifacts の検索欄で入力中に、フォーカスがメッセージ入力欄に奪われなくなりました。ハードウェアキーボードの再接続時も同様です
- メッセージ内のアプリのリンクカード（Stamp の承認リクエストなど）に、Web 版と同じく「更新」ボタンが表示されるようになりました
- お知らせ内の、Web 版にしかない設定ページへのリンクがエラーにならず、ブラウザで開くようになりました
- アップデート後にホーム、アクティビティ、チャンネルのメンバー一覧の読み込みに失敗した場合、次の同期で再度読み込まれるようになりました
- まだ会話のないタスクを開くと画面全体を覆い、下のタブバーが透けて見えなくなりました
- その他の小さな修正：セグメントコントロールがタップしやすくなり、アクティビティの絞り込みチップの × を誤ってタップして絞り込みが解除されることがなくなりました。トラックパッドやマウスの使用時、トップバーの項目が入力欄と同じ高さになり、中国語と日本語のフォームのラベルで（任意）の前に余分な空白が入らなくなりました
