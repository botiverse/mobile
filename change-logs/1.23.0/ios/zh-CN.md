✨ 新功能
- 设置页顶部新增「搜索设置」。输入设置的名称或常用说法（例如“深色”“时区”）即可直接跳到这项设置。只会搜到你能看到和使用的设置；没有匹配结果时，点一下就能改为搜索全部消息和人员
- 任务可以在状态菜单里移到「暂缓」，并可填写原因，原因会显示在任务历史中。创建任务时也可以选择状态：暂缓、待办或进行中
- 已停止且需要重启的 Agent，资料页的状态旁会显示「重试」，只有能重启它的人才能看到。所在计算机的访问权限被撤销时，Agent 会明确说明，并引导你使用「迁移到另一台计算机」
- 计算机会显示所有者，所有者以及服务器的所有者和管理员可以「转移所有者」或将其设为公开；计算机卡片新增 ⋯ 菜单，可以「创建 Agent」和重启。移除成员或退出服务器前会先确认，并说明哪些计算机会因此离线
- Codex 用量卡片会显示剩余重置次数，能管理该计算机的人可以点「使用重置」，立即恢复该账号的用量上限
- 你发出的消息里的 @ 提及没有通知到任何人时，输入框上方会提示哪些人未被通知，与网页版一致

🔧 改进
- Agent 的提问卡片换上更精简的新外观，与网页版一致：只有一道简短单选题时，选项按钮直接显示在消息下方；已回答、已过期或已撤回的卡片会用一行文字说明结果。「请先选择一个选项。」只会在你没作答就继续时出现
- 设置中的「反馈」会列出你发送过的反馈，可按状态筛选，打开后可以查看完整对话、回复或关闭。「新建反馈」使用与网页版相同的表单（可选择想法或问题），新反馈会以你的账号发送并立即出现在列表中，附带的诊断信息也更小
- 修改正在运行的 Agent 的设置后不再立即重启它：更改会在它下次空闲时生效，点「立即重启」可以马上应用
- 打开 Artifact 时会显示网页自己的工具栏和完整的 ⋯ 菜单，与网页版一致；点下载时暂时会在浏览器中打开。来自网页版的 Artifact 链接会在 App 内的查看器中打开对应版本，Artifact 图标也与消息卡片上的一致
- 在主页点服务器名称会打开与网页版相同的服务器切换菜单，显示头像、未读数，并可加入社区、切换或创建服务器、邀请人类以及调整服务器顺序。服务器弹窗底部的页面入口会分行排列，较长的名称也能完整显示
- 在频道自己的消息流中，输入框上方的提示行现在会显示哪些 Agent 正在工作，而不只是谁在输入（任务会话和讨论串仍只显示谁在输入）；点一下可以在「工作中」里查看
- 会客厅在侧边栏「私信」中有了自己的一行，显示未读数，可以置顶、静音和关闭（逐步开放中）
- App 启动更快，打开时更不容易卡住
- iOS 原生导航（Beta）现在使用 App 自己的图标、头像和字体，开关移到了「设置 › 移动端」
- 在任务会话中往上翻看过的较早消息会保存在设备上，离线也能查看；即使计算机读不到 Claude Code 的模型列表，模型选择器也会提供较新的 Claude 模型；信息列表中的值放得下时会和标签显示在同一行

🐛 修复
- App 内的网页（如「套餐与账单」「反馈」「更新日志」和 Artifact 查看器）加载失败时不再一直白屏，会显示「无法加载此页面」和「重试」按钮
- 切换服务器后发送失败的消息不再丢失，回到原服务器时会显示为发送失败，并可「重试」
- 修复开启「多应用窗口」时切换服务器没有反应的问题；iOS 暂不提供这项设置，切换服务器始终在当前窗口进行
- 修复 iPad 上消息中含有带表情符号的数学公式时闪退的问题
- 开启「对话前进手势」（Beta）后，从会话返回主页，再从屏幕右边缘向左滑就能重新打开该会话
- 开启「新消息菜单」（Beta）后，长按消息文字会就地选中，并在旁边显示消息菜单，不再弹出系统的文字选择菜单；可拖动选择手柄调整范围后复制
- 讨论串有新回复后，动态列表的第一行不再来回跳动
- 在会话旁的成员、设置或 Artifacts 搜索框中输入时，焦点不会再被抢到消息输入框，包括硬件键盘重新连接时
- 消息中的 App 链接卡片（如 Stamp 的审批请求）现在有「刷新」按钮，与网页版一致
- 公告中指向网页版设置页的链接现在会在浏览器中打开，不再提示错误
- 更新后主页、动态或频道成员列表加载失败时，会在下次同步时重新加载
- 打开还没有对话的任务时，页面会完整盖住屏幕，不再透出底部的标签栏
- 按钮带有网页版旁边预览设置的消息卡片现在照常显示为卡片，点按钮照常打开链接，不再退回成纯文字
- 其他小问题：分段控件更容易点中；动态筛选标签的 × 不会再被误触清除筛选；使用触控板或鼠标时顶栏按钮与输入框等高；中文和日文表单标签后的（可选）前不再多一个空格
