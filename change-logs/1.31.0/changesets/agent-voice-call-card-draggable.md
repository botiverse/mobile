## zh-CN
悬浮 Agent 语音通话卡片现支持自由拖动挪动位置：单手可沿屏幕安全区域上下（宽屏及窄卡片支持二维自由）拖动，避免遮挡消息输入框或对话内容；自动避让状态栏、底部导航栏、异形屏安全区与软键盘，并在通话期间跨刷新与页面切换保持位置，同时保留卡片内静音、扬声器与挂断按钮的正常点击。

## en
Made the floating Agent Voice call card draggable so it never blocks the message composer or conversation: drag vertically on compact phones (and freely in 2D on wide screens), clamped cleanly within status bar, navigation bar, horizontal safe-area, and keyboard insets with subtle edge feedback, preserved across live updates and navigation during the call without interfering with mute, speaker, or hang-up taps.

## ja
フローティング Agent 音声通話カードをドラッグして自由に移動できるようになりました。コンパクト画面では上下方向、ワイド画面では縦横 2D に移動でき、メッセージ入力欄や会話を遮りません。ステータスバー・ナビゲーションバー・横方向のセーフエリア・キーボード領域内に収まるよう自動クランプされ、通話中の再描画や画面遷移でも位置を維持しつつ、ミュート／スピーカー／通話終了ボタンのタップ操作を妨げません。
