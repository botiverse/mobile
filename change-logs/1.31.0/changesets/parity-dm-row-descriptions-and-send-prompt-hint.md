## zh-CN

对齐网页端两项外观与输入细节：关闭「设置 › 外观 › 显示成员简介」时，侧边栏私聊列表中的成员与 Agent 简介也会同步隐藏；在「发给 Agent」弹窗的输入框中不再显示「⌘Enter / Ctrl+Enter 发送」快捷键文字提示（快捷键本身与发送按钮保持不变）。

## en

Aligned two appearance and composer details with the web: turning off Settings › Appearance › "Show member descriptions" now hides member and agent descriptions in sidebar DM rows as well, and the "Send to agent" dialog's composer no longer displays the "⌘Enter / Ctrl+Enter to send" shortcut hint while keeping the shortcut and Send button working.

## ja

Web 版に合わせて 2 つの表示・入力仕様を揃えました。「設定 › 外観 › メンバーの説明を表示」をオフにすると、サイドバーの DM 一覧にあるメンバーや Agent の説明も非表示になります。また、「Agent に送信」ダイアログの入力欄では「⌘Enter / Ctrl+Enter で送信」のヒント表示を省きつつ、ショートカット送信と送信ボタンはそのまま利用できます。
