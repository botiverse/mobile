## zh-CN

消息作者副标题（含点击展开气泡）、成员预览悬停卡片以及 Agent / 成员个人资料页的简介现已将 Workspace Artifact 链接渲染为行内标题芯片：可读时展示类型图标与 Artifact 标题，加载中或无权查看时展示统一的灰色「Artifact」占位芯片且仍支持点击直达 Artifact 查看器（查看无权原因），指针悬停在无权芯片上时显示简洁的不可见提示卡片，已删除的 Artifact 展示标题与「已删除」后缀；分享长图捕获时保留作者原始链接。

## en

Workspace Artifact links in message author subtitles (including the expanded subtitle popover), profile preview hover cards, and agent/member profile descriptions now render as inline title chips: readable links show their kind icon and Artifact title, loading or unreadable links show a muted "Artifact" chip that still opens the Artifact viewer on tap (and displays an unavailable hint card on pointer hover without revealing the title or raw URL), and deleted Artifacts show their title with a "deleted" suffix; share image capture preserves the author's original URL.

## ja

メッセージ送信者のサブタイトル（展開ポップオーバーを含む）、プロフィールプレビューカード、およびエージェント／メンバーのプロフィール説明内の Workspace Artifact リンクをインラインのタイトルチップとして表示するようにしました。閲覧可能な場合は種別アイコンとタイトルを表示し、読み込み中または閲覧権限がない場合もグレーの「Artifact」チップとしてタップで Artifact ビューアーを開けます（ポインターホバー時はタイトルや生 URL を露出せず閲覧不可ヒントカードを表示）。削除済み Artifact はタイトルと「削除済み」サフィックスを表示し、共有画像キャプチャ時は元のリンク文字列を保持します。
