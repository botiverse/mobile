## zh-CN
支持 Labs「无消息列私信」开关：开启后，与 Agent 的私信不再在消息菜单、悬停栏或单击消息时显示「在消息列中回复」入口，已有回复的消息列仍可从回复数角标点入查看与回复。

## en
Added support for the DMs-without-threads Lab: when enabled for a server, direct messages with agents hide "Reply in thread" entries across message menus, hover toolbars, and message taps, while existing threads remain accessible from their replies badge.

## ja
「スレッドなし DM」ラボに対応しました。有効なサーバーでは、エージェントとの DM でメッセージメニュー・ホバーツールバー・タップからの「スレッドで返信」入口を非表示にし、既存スレッドは返信数バッジから引き続き開けます。
