## zh-CN

对齐 1.31.0 Web 行为：当开启快速模式的 Agent 实际会话回退到默认档位时，Agent 资料的“模式”行显示为默认并在下方展示说明提示；宽屏下切回“动态”页签时，自动重新打开之前已读的任务会话（有未读或标为未读的任务保持关闭以免误标已读）。

## en

Aligned 1.31.0 web parity: when a fast-mode agent's live session falls back to a non-fast service tier, the Mode row in the Agent profile displays Default with a muted fallback note underneath; on wide layouts, returning to Activity reopens a previously open read task conversation while keeping unread or marked-unread tasks closed.

## ja

1.31.0 の Web 挙動に合わせました。高速モード設定のエージェントが実際のセッションでデフォルトにフォールバックした場合、エージェントプロフィール画面の「モード」にデフォルトと補足メッセージを表示します。また、ワイド画面でアクティビティに戻った際、既読のタスク会話を自動で再度開き、未読または未読マーク付きのタスクは閉じたままにします。
