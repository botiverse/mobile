## zh-CN

在 iOS 上触发敏感操作二次验证时，如果账号只有旧版通行密钥且同时绑定了身份验证器或备用码，点击「使用通行密钥」现在会直接打开浏览器完成通行密钥验证，不再闪出无法使用的警告并跳到验证码输入；若关闭浏览器，页面会保留「在浏览器中继续」并在下方提供切换到身份验证器或备用码的入口。

## en

When verifying a sensitive action on iOS with an older passkey on an account that also has an authenticator app or backup codes, tapping "Use passkey" now opens the browser passkey verification flow directly instead of showing an unsupported warning banner and jumping to code entry. Closing the browser keeps "Continue in browser" as the primary action with links below to switch to an authenticator code or backup code.

## ja

iOS で旧パスキーと認証アプリまたはバックアップコードを併用しているアカウントで再認証する際、「パスキーを使う」をタップすると警告バナーを表示してコード入力へ切り替わる代わりに、直接ブラウザのパスキー確認へ進むように改善しました。ブラウザを閉じた場合は「ブラウザで続行」の下に認証コードやバックアップコードへの切り替えリンクが表示されます。
