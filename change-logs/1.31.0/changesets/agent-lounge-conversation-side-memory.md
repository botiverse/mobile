## zh-CN

修复了在 Agent 对话里切换到「私密模式」后，退出再从主页列表点进同一 Agent 时仍默认打开「会客厅」的问题。现在会按账号、服务器与 Agent 在本地记住你上次使用的模式，再次进入时直接回到上次那一边（首次进入仍默认打开会客厅）。

## en

Fixed an issue where switching an agent conversation to Private chat still reopened the agent's Lounge the next time you tapped the agent in Home. The app now remembers the last side you had open (Private chat or Lounge) locally per account, server, and agent, reopening that side next time (defaulting to the Lounge on first visit).

## ja

エージェントとの会話でプライベートチャットに切り替えた後、ホーム一覧から同じエージェントを開き直すと再びラウンジが開いてしまう不具合を修正しました。アカウント・サーバー・エージェントごとに最後に開いていた側（プライベートチャットまたはラウンジ）をローカルに記憶し、次回は同じ側を開きます（初回はラウンジ）。
