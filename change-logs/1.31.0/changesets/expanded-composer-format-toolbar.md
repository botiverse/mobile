## zh-CN

宽屏展开输入框升级（对齐网页端）：展开后保留完整的边框样式，顶部新增 Markdown 格式工具栏（加粗、斜体、删除线、代码、链接；窄列下有序/无序列表、引用与代码块自动收进「更多格式」菜单）并将收起按钮（含 Esc 快捷键提示）放在工具栏右侧；展开状态下按 Enter 换行，按 ⌘/Ctrl+Enter 发送并始终显示发送快捷键提示。

## en

Upgraded the expanded wide-viewport composer for web parity: it now keeps its framed ink border, adds a top Markdown formatting toolbar (bold, italic, strikethrough, inline code, link; numbered/bulleted lists, quote, and code block fold into a "More formatting" menu in narrow columns) with the Collapse button (with Esc hint) at the end, and switches expanded Enter to insert a newline while ⌘/Ctrl+Enter sends with the send-shortcut hint always shown.

## ja

ワイド画面の展開コンポーザーを Web に合わせて刷新しました。枠付きフレームを維持したまま上部に Markdown 書式バー（太字・斜体・取り消し線・コード・リンク、狭い列ではリスト・引用・コードブロックを「その他の書式」メニューに格納）と右端の折りたたみボタン（Esc ヒント付き）を配置し、展開中は Enter で改行、⌘/Ctrl+Enter で送信（送信ショートカットヒントを常時表示）できるようにしました。
