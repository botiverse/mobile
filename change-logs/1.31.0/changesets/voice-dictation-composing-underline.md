## zh-CN
流式语音输入中尚未定稿的文字现在会以点状下划线呈现为输入态（composing），并在该句定稿、润色、停止、按 Esc 取消（同时撤销未定稿片段）或手动编辑草稿时立即清除，与 Web 端保持一致；此外，当输入框未聚焦时按下或按住语音键会自动聚焦输入框以显示光标与输入进度，同时在触屏设备上保持软键盘收起，避免按住说话时按钮上移打断手势。

## en
Uncommitted streaming voice dictation text now displays a dotted composing underline strictly beneath the live partial segment, clearing immediately on finalization, refinement, stop, Escape cancel (which discards uncommitted partial text), or manual draft edits for full parity with Web. Starting or holding voice dictation while the composer is unfocused now automatically focuses the input so the caret and composing feedback appear right away, while keeping the soft keyboard closed on touch devices so press-and-hold never shifts the mic button mid-gesture.

## ja
ストリーミング音声入力の未確定テキストに点線アンダーラインの変換中（composing）表示を追加しました。確定・整形・停止・Esc でのキャンセル（未確定部分の破棄を含む）・手動編集時に即座に解除され、Web 版と一致した挙動になります。また、入力欄が未フォーカスの状態で音声ボタンを押す・長押しすると自動でフォーカスしてカーソルと入力状態を表示しつつ、タッチ端末ではソフトキーボードを開かずに長押し操作がずれないようにしました。
