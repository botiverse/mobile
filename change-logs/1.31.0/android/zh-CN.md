✨ **新功能**
- **任务批量操作与动态「任务」筛选**：任务页长按列表行或看板卡片即可多选（支持全选），通过底部栏批量改状态、指派负责人、关注或删除（失败项可重试）；「动态」筛选新增「任务」选项并按工作空间记忆。
- **内置浏览器全面升级**：底部栏新增前进/后退，菜单新增「重新加载」与一键「转发到 Raft」，支持网页弹窗、全屏视频与页内新窗口，查看 Raft 应用页时保留「在浏览器中打开」；拦截无手势自动拉起外部应用并为外链增加确认弹窗，「设置 › 存储」新增清除「内置浏览器」缓存与 Cookie，退出或切换账号时自动清理独立浏览数据。
- **宽屏展开输入框与 Markdown 工具栏**：宽屏输入框新增「展开 / 收起」按钮，展开后提供顶部 Markdown 格式工具栏（窄列收进「更多格式」），按 Enter 换行、⌘/Ctrl+Enter 发送，切会话、发送或按 Esc 自动收起并保留草稿。
- **额度耗尽通知与删机通知主人**：所有者与管理员可在「通知」查看运行时账号额度耗尽提醒（含受影响计算机、Agent 数与恢复时间，跨设备同步已读与关闭）；删除自己接入的计算机时若仍有他人 Agent，可逐个「通知主人迁走」或二次确认强制解绑并删除。
- **视频直接下载与快捷回应升级**：聊天内联视频卡片右上角新增「下载」按钮，无需预览即可保存；快捷回应栏在「✅」后新增第 8 枚「🍻」；鼠标/触控板悬停工具栏支持一键切换最常用回应（默认 👍），悬停片刻展开完整栏。
- **简介与副标题行内 Artifact 标签**：消息作者副标题、成员预览卡片及 Agent/成员简介中的 Workspace Artifact 链接渲染为行内标题标签，展示类型图标、标题及已删除或无权查看状态，点击直达查看器。
- **直装包「后台常驻连接」开关**：直装安装包在「设置 › 通知」新增可选的「后台常驻连接」（默认关闭），帮助无法连接 Google 推送的网络环境保持后台连接接收消息通知。

🔧 **改进**
- **计算机「需要处理」摘要与诊断包**：计算机页顶部新增「需要处理」摘要条（展示原因、受影响 Agent、恢复时间与一键筛选），补齐磁盘不足升级失败说明、跳过缓存的工作区扫描（部分扫描标注「至少 …」）与拒连离线计算机的版本重装指引；本人计算机的 Agent「报告问题」可选附带「Computer 诊断包」，「反馈」支持附加 1 个不超过 10 MiB 的诊断 `.zip`。
- **Agent 创建、状态与用量详情更清晰**：创建或编辑 Agent 时可从同台计算机其他 Agent 复制「环境变量」（不覆盖已有键，超 8 项可搜索），计算机选择器完整换行展示备注，添加成员页「添加 Agent」改为直选弹窗；用量限额暂停时标明受限模型、窗口周期与重置时间；需人工处理的 Agent 统一亮橙灯，补齐「模型不可用」（含更换模型入口）、停用运行时指引及快速模式回退说明。
- **外部频道管理与邀请流程焕新**：「邀请外部人员」首步聚焦邮箱并附「连接你的服务器」入口与精简确认页；跨服副本按服务端权限统一展示管理入口，参与服管理员可移除己方 Agent；移除仍在其他服务器关联的成员时保留列表并说明仅移除本服一侧；参与服侧的历史外部任务以只读展示。
- **任务增量同步、Artifact 任务直达与更多 Mermaid 图**：增量同步直接应用任务变更，任务页「全部」视图单次请求加载计数；来自任务的 Artifact 来源链接直达原生任务并定位目标消息（摘要封面文字环绕右上角徽标，并精简过渡期顶栏按钮）；更多 Mermaid 图（方块图、甘特图、状态图、C4、思维导图、架构图、Git 与 Wardley 图）可直接渲染。
- **动态实时同步与浏览流畅度提升**：任一设备将「动态」项标为「完成」或撤销时跨设备实时同步；频道成员与 Agent 动态总览在切回前台或重连时自动后台刷新；整体优化打开会话、滑动消息与后台切回前台的流畅度。
- **分享图标、设置搜索与界面细节**：系统分享频道建议改用服务器图标加公开/私有/外部频道角标；设置搜索新增「通行密钥」与「两步验证」；统一「频道设置」名称与菜单单行自适应宽度；去除应用内链接多余外部箭头及加载后应用图标紫色底色，内置浏览器长域名从头部截断保留主域名；「显示成员描述」同步控制侧栏私信简介，30 天历史提示向管理员补充近 7 天 Agent 触发次数，浅色警告条改为琥珀色。
- **旧 `preview` 更新通道平滑迁移**：停用旧 `preview` 通道，原 `preview` 用户升级至 1.31.0 后自动并入正式通道并继续接收应用内增量更新。

🐛 **修复**
- **清理消息流断层与首帧闪烁**：移除消息流中间加载与缺口行，边界加载最多同时显示一个；缓存已加载的引用消息链接预览；修复从「动态」进入频道或私信误命中旧预热快照看不到新消息的问题；「设置 › 计算机」、Agent 详情、「反馈」与「Artifacts」重进即显缓存，并修复卡在加载中或首载误触下拉刷新的问题。
- **动态、任务、回复与通知跳转修复**：动态列表中的应用私信支持菜单静音/取消静音与左滑静音，修复标为「完成」后短暂闪回、打开已读动态误跳到不可读行（宽屏切回动态自动重开已读任务）及回复消息列缺少关注/取消关注菜单项；修复连点同会话推送叠压多页及手机首页「已保存」「草稿」跳转错误；主页「工作中」不再混入他服 Agent，仅面向 Agent 的提示不再计入人类未读，批量切换 Codex 模型保留访问设置，修复 1970 占位重置时间显示异常。
- **聊天音视频内存稳定**：滑出屏幕、切页或退到后台时自动释放闲置内联音视频播放器并限制缓冲占用，修复媒体密集会话中的内存暴涨、卡顿与闪退。
- **内置浏览器与 Artifact 加载可靠**：修复 Artifact 查看器遇网络错误卡在「正在获取页面」（现立即显示重试）；修复内置浏览器在外部登录、切应用或锁屏退后台时误报超时或白屏；打开前台网页时自动中止后台 Artifact 预热，避免阻塞超时。
- **会话保持、切服与草稿稳定**：权限拒绝（403）现保留登录态并展示原因而不再误登出；新建服务器后直接进入新服，长列表切服自动滚入当前服，切服中锁屏返回不再误报失败；停止启动时重复查询他服或已删频道草稿。
- **诊断日志、附件选择与暂停更新恢复**：修复诊断日志异常导致反馈丢失诊断包，恢复「设置 › 诊断 / 关于」复制分享中的脱敏近期日志；修复附件/拍照选择器异常关闭后卡死；修复 Wi-Fi 预下载暂停切移动网络后点击更新长期卡在下载中。
- **提示条、键盘与界面细节修复**：修复弹窗或抽屉内提示条被遮挡、从系统小窗切回消息列表时键盘瞬间闪现、从「反馈」详情返回直退「设置」、底部链接预览首帧闪跳及触屏+鼠标点击悬停栏消失；外部分享标题改显条目数，恢复 8 枚回应贴纸高饱和配色，禁用且开启的开关保留淡黄区分，并对齐页头、头像外圈与「作为任务」间距。
