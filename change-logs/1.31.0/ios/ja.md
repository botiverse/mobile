✨ **新機能**
- **タスクの一括操作**：タスク行やボードカードを長押しして複数選択し、ステータス変更・担当割当・フォロー・削除をまとめて実行できます。
- **アクティビティに「タスク」絞り込み**：アクティビティでタスクだけを絞り込み、ワークスペースごとに記憶できます。
- **アプリ内ブラウザ強化**：戻る／進む・再読み込み・Raft に転送に対応し、「設定 › ストレージ」から閲覧データを削除できます。
- **ワイド画面の展開入力欄**：iPad やワイド画面で入力欄を展開し、上部の Markdown 書式バーを使えます。
- **動画の直接保存**：チャット内動画の右上ボタンから、プレビューを開かずに保存できます。
- **使用量上限とコンピューター削除通知**：管理者は「通知」で上限アラートを確認でき、コンピューター削除時に他者エージェントの移動依頼を送れます。
- **共有画像の幅調整と TestFlight 更新確認**：メッセージ共有画像の幅を選べるようになり、TestFlight 版はアプリ内で新ビルドを確認できます。

🔧 **改善**
- **iOS 26+ サーバー切替ポップオーバー**：ホーム左上からその場で切り替えられるようになり、試験的な右端進むジェスチャーを廃止しました。
- **コンピューター状態と診断**：上部に「要対応」サマリーを追加。問題報告にコンピューター診断や `.zip` 診断ファイルを添付できます。
- **エージェント管理の改善**：同じコンピューターの別エージェントから環境変数をコピー可能になり、上限一時停止やモデル不可の理由が明確になりました。
- **外部チャンネル招待の簡略化**：外部招待フローを整理し、サーバー接続への導線と権限表示を統一しました。
- **Mermaid 図拡充とリアルタイム同期**：ガント図・状態図・マインドマップ等に対応。アクティビティの「完了」も端末間で即同期されます。
- **クイックリアクションと検索**：🍻 リアクションとマウスホバー時のワンクリック切替を追加。設定検索で「パスキー」「2 要素認証」が見つかります。

🐛 **修正**
- メッセージ一覧の読み込み断層やちらつきを解消し、再表示時にキャッシュを即表示するようにしました。
- 画面外・バックグラウンドの再生プレーヤーを自動解放し、メディアが多い会話でのメモリ急増やカクつきを防ぎました。
- アプリ内 Web のマイク要求によるクラッシュ、通信エラー時の Artifact 読み込み停止、ブラウザ誤タイムアウトを修正しました。
- 権限エラーでの誤ログアウト、サーバー切替時の画面重複、AppSumo 永久プランの無制限エージェント枠表示を修正しました。
- iPad のコールド起動単一ペイン表示、外部共有の「続行」ボタン重なり、スワイプ戻りの戻りすぎを修正しました。
