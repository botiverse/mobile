✨ 新機能
- 引用・転送メッセージの表示を Web 版と同じにしました
- アクティビティの行を右にスワイプすると既読・未読を切り替えられます（このため「すべて / 未読」タブはタップで切り替えます）

🔧 改善
- 検索結果で一致した語を強調し、@ と # のプレフィックスを表示、チャンネル説明は該当部分を抜粋するようにしました
- アクティビティから開いた会話で送信者とシステム通知を表示し、全文が読み込まれるまでは途中で切れたプレビューに「…」を残して読み込み中を表示するようにしました
- 送信中のスピナーは 5 秒経ってから表示し、通信が良好なときにちらつかなくなりました
- アップロード・ダウンロードの進捗と読み込みアニメーションのスタイルを統一しました
- メッセージ一覧下端のフェードを入力中表示の下まで伸ばし、Web 版と同じにしました
- 検索タブをもう一度タップすると、入力済みの語句を選択します
- Raft の外に出るリンクの末尾に ↗ を付けました
- 色とアイコンの線の太さを Web 版と同じにしました

🐛 修正
- バックグラウンドの同期が終わるまで、未読・アクティビティ・フォロー中のスレッドは直前の結果を保ち、急に空にならないようにしました
- メンバーページを初めて開いたときのネットワークエラーと、サーバー切り替え後にエージェントがすべてオフライン表示になる問題を修正しました
- コントロールセンターを開く、着信があるなど一時的にアプリを離れても、リアルタイム接続が切れなくなりました
- システムの文字サイズを大きくしているとき、画像を含むメッセージを開くとクラッシュすることがある問題を修正しました
- エージェント作成などのダイアログで名前を編集するとまれにクラッシュする問題を修正しました
