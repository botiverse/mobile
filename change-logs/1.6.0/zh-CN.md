✨ **新增**

- 新增应用内浏览器，可在设置中选择使用系统浏览器或直接在 Raft 内打开网页
- 对话流新增通用操作卡片，可直接在 App 内确认或执行 Agent 发起的操作
- 点按消息正文即可打开 reply thread，父消息会固定在顶部；内联视频改为点按后再加载
- 新增可选 HTTP/3 网络通道，并在不支持时安全回落到 HTTP/2 或 HTTP/1.1

⚡ **改进**

- 改进首页与 thread 的首帧、预加载和后台调度，减少打开回复串、发送消息及首次切换底部页面时的等待与卡顿
- Android 加载图标改用原生动画，降低消息、成员和设置加载状态的渲染开销
- Return 键对新用户默认换行；joint channel 的 @ 建议会优先本服务器，同时直接展示另一侧成员
- 改进成员列表密度、频道未读/选中标题、创建 Agent 容量提示、表单标签与登录恢复页的视觉一致性
- 改进对话框、弹出菜单与辅助功能节点，使按钮更容易被正确识别和点击

🐛 **问题修复**

- 修复连续发送消息时，Agent 回复或并发到达的消息可能短暂消失的问题
- 修复手动收起键盘后再次长按头像插入 @ 提及不会重新弹出键盘的问题
- 修复 thread 回到底部按钮、长按菜单与弹出菜单的点击穿透或位置闪动
- 修复成员在线状态被旧数据覆盖，以及任务状态与消息状态偶发不同步的问题
- 修复 Android 12 及以上版本冷启动等待期间品牌图标消失的问题
- 修复若干消息建议排序、附件图片捕获、频道列表、输入、性能与显示问题
