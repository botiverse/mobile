## zh-CN

新增网页链接打开方式设置：可继续使用系统默认浏览器，也可直接在 Raft 内浏览网页。内置浏览器支持加载状态、前进、后退和刷新；OAuth、附件、系统设置及不受支持的链接仍会安全地交给系统处理。

## en

Added a web link opening preference so links can continue to use the default system browser or open directly inside Raft. The in-app browser supports loading state, back, forward, and reload, while OAuth, attachments, system settings, and unsupported links continue to open safely through the system.
