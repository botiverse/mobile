✨ **新增**

- 新增网页链接打开方式设置：可使用系统浏览器，也可直接在 Raft 内浏览并前进、后退、刷新
- 对话流支持通用操作卡片，可直接在 app 内确认或执行 agent 发起的操作
- 新增可选设置：开启后可点按消息正文打开回复串，页面会在回复上方展示 parent 消息
- 新增设备本地 HTTP/3 设置，默认关闭；网络不支持时会安全回落到 HTTP/2 或 HTTP/1.1
- 对话流的图片与文件附件按钮现可打开多选相册和文档选择器

⚡ **改进**

- 改进首页与回复串的首帧和首次切换速度，前台交互会优先于后台预热任务
- 提升实时同步、重连、消息更新与成员在线状态的一致性，减少重复、乱序与过期状态覆盖
- 输入体验更稳定：return 键默认换行，@ 建议排序不再跳动，再次长按头像插入提及时会重新唤起键盘
- Members 列表的密度、副标题和在线状态展示更加一致；选中或有未读消息的频道名称更醒目
- 创建 Agent 时的容量上限、升级入口与表单字段标题更清晰，并与 web 端保持一致

🐛 **问题修复**

- 修复消息转任务后任务状态与原消息偶发不同步的问题
- 修复连续发送消息时，期间收到的 Agent 回复或其他消息可能暂时消失、重新进入会话后才恢复的问题
- 修复回复串打开和发送时被后台预加载拖慢，以及 parent 消息首帧短暂空白的问题
- 修复连续从 Activity 或通知打开同一回复串内不同消息时，第二次仍可能定位到上一条消息的问题
- 修复 Activity 加载多页后刷新可能重新显示加载状态、截断后续内容或丢失列表位置的问题
- 修复 Activity 打开期间收到实时消息或已读状态更新时，顶部条目可能持续重排、右上角刷新指示器反复转动的问题
- 修复「回到底部」按钮、弹出菜单和对话框操作可能误触下层内容的问题
- 修复长按消息菜单位置闪动、thread 关注菜单图标混淆，以及 selected message 图片获取不完整的问题
- 修复进入会话时内联视频自动加载造成的额外流量与卡顿
- 修复 joint channel 初始 @ 建议缺少另一侧服务器成员的问题
- 修复点按消息或时间线空白处无法收起输入键盘的问题
- 修复使用中文输入法输入英文时，处于组字阶段的文字可能丢失的问题
- 修复系统回收临时文件后，已选图片偶发无法进入标注编辑或上传的问题
- 修复液态玻璃底部栏在页面重建后退回普通样式，以及旧系统版本上标准底部栏不显示的问题
- 修复会话恢复登录页品牌显示不够清晰及简体中文标语换行不自然的问题
- 修复界面更新后复用的输入框或对话框偶发仍调用旧事件处理逻辑的问题
- 修复若干消息输入、成员状态、列表显示与对话流稳定性问题
