## zh-CN

如果你把消息文字大小设成了“小”或“大”，打开 app 后频道里的消息会直接以这个大小显示，不会再先按“中”显示、几秒后才变过来。

## en

If you set message text size to Small or Large, channel messages now show at that size right after opening the app, instead of starting at Medium and changing a few seconds later.

## ja

メッセージの文字サイズを「小」または「大」にしている場合、アプリを開いた直後からその大きさでチャンネルのメッセージを表示します。最初は「中」で表示されて数秒後に変わることはなくなりました。
