## zh-CN

“验证是你本人”现在可以直接在 App 里用通行密钥确认：有通行密钥的账号会先看到“使用通行密钥”，验证通过后，被拦下的操作会自动继续。仍可改用身份验证器代码或备用码。只设置了通行密钥的账号不用再去网页版完成这一步；如果这台设备上没有可用的通行密钥，会改用其他方式，没有其他方式时仍提示去网页版。

## en

"Verify it's you" now takes a passkey right in the app: accounts with a passkey see "Use Passkey" first, and once it's verified the blocked action carries on by itself. The authenticator code and backup code are still there. Accounts with only a passkey no longer have to finish this step on the web; if this device has no passkey it can use, the dialog moves on to your other ways, or to the web when there are none.

## ja

「本人確認」で、アプリ内からそのままパスキーを使って確認できるようになりました。パスキーのあるアカウントには最初に「パスキーを使用」が表示され、確認できるとブロックされていた操作が自動で続きます。認証アプリのコードやバックアップコードも引き続き使えます。パスキーだけを設定しているアカウントも、Web 版でこの手順を行う必要はなくなりました。このデバイスで使えるパスキーがない場合は別の方法に切り替わり、ほかの方法がないときは Web 版での確認を案内します。
