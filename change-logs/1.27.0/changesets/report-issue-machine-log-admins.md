## zh-CN

报告 Agent 问题时，服务器所有者和管理员也可以附上这台电脑的运行日志尾部（和网页一样）；只有在你自己连接的电脑上默认勾选。

## en

When reporting an agent's issue, server owners and admins can also attach the machine's runner log tail, as on the web; it starts ticked only on a computer you connected yourself.
