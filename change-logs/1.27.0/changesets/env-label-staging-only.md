## zh-CN

连接自建服务器时，屏幕上不再一直浮着显示当前服务器的小标签；只有连 Raft 的 staging 服务器时才显示。

## en

When you're connected to a self-hosted server, the floating label showing the current server no longer stays on screen. It now only appears on Raft's staging server.

## ja

セルフホストのサーバーに接続しているとき、現在のサーバーを示すフローティングラベルが常に表示されなくなりました。Raft の staging サーバーに接続しているときだけ表示されます。
