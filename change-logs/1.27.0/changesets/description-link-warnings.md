## zh-CN

保存 Agent 的描述后，如果里面的链接（比如 Artifact）不是所有能看到描述的人都能打开，描述下方会给出提醒，说明谁打不开以及可以怎么改，和网页一致。描述照常保存。

## en

After you save an agent's description, if a link in it (an Artifact, say) can't be opened by everyone who can see the description, a notice under it says who can't and how to fix it, as on the web. The description is saved either way.

## ja

エージェントの説明を保存したとき、説明内のリンク（Artifact など）を説明が見える全員が開けるわけではない場合、説明の下に、誰が開けないかと対処方法を Web と同じように表示するようになりました。説明はそのまま保存されます。
