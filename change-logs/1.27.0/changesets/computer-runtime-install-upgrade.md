## zh-CN

在计算机页面上，可以直接安装或升级运行时，与网页版一致（需服务器开启该功能，并且只对连接这台计算机的人或服务器所有者、管理员显示）。运行时卡片上的「升级」会在计算机上运行该运行时自己的更新程序，完成后说明结果，例如「已将 Claude Code 从 2.0.1 升级到 2.0.5。」。在「显示所有支持的运行时」中，计算机可以安装的未安装运行时会提供「安装」：先显示计算机将运行的官方安装命令和安装程序文档，确认后才会运行；不能在这里安装时，会显示需要自己在计算机上运行的步骤。Raft 不会自行安装或升级任何运行时。

## en

You can now install or upgrade a runtime from a Computer's page, as on the web (when the server has it turned on, for the person who connected the Computer or a server owner or admin). Upgrade on a runtime's card runs that runtime's own updater on the Computer and then says what happened, for example "Upgraded Claude Code from 2.0.1 to 2.0.5." Under "Show all supported", a runtime that isn't installed but that the Computer can install offers Install: it first shows the official installer command the Computer would run and its documentation, and runs only after you confirm. Where it can't run from here, it shows the steps to run on the Computer yourself. Raft never installs or upgrades a runtime on its own.

## ja

ウェブ版と同じように、コンピューターのページからランタイムをインストール・アップグレードできるようになりました（サーバーでこの機能が有効な場合に、コンピューターを接続した人、またはサーバーのオーナーか管理者に表示されます）。ランタイムのカードの「アップグレード」を押すと、コンピューター上でそのランタイム自身のアップデーターが実行され、「Claude Code を 2.0.1 から 2.0.5 にアップグレードしました。」のように結果が表示されます。「対応しているものをすべて表示」では、インストールされていないもののコンピューターがインストールできるランタイムに「インストール」が表示されます。まずコンピューターが実行する公式インストーラーのコマンドとドキュメントが表示され、確認した後にだけ実行されます。ここから実行できない場合は、コンピューター上で自分で実行する手順が表示されます。Raft がランタイムを勝手にインストールまたはアップグレードすることはありません。
