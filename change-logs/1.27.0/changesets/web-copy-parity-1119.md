## zh-CN

外部频道的说明改成“通过邮箱邀请朋友、客户或合作伙伴加入同一个频道”；邮箱输入框下说明每个人都会收到带加入链接的邮件，没有 Raft 账号也可以。要连接的服务器上已有同名频道时，会提示先在那个服务器里给频道改名再连接。运行时升级或安装尝试太多时，提示过几分钟再试，而不是“再试一次”。迁移 agent 时如果源电脑读不了 MEMORY.md 或 notes/，会说明原因和怎么修。

## en

The External channel option now says you invite friends, clients, or partners through email, and the email box says everyone gets an email with a link to join, even without a Raft account. Connecting a server that already has a channel with the same name now says to rename that channel there first. A runtime Upgrade or Install refused for too many attempts now says to try again in a few minutes instead of "try again". An agent migration stopped because the source computer can't read MEMORY.md or notes/ now says why and how to fix it.

## ja

外部チャンネルの説明を「友人、クライアント、パートナーをメールで同じチャンネルに招待できます」に変え、メール欄の下に Raft のアカウントがなくても参加用リンクがメールで届くことを表示します。接続先のサーバーに同じ名前のチャンネルがあるときは、先にそのチャンネルの名前を変えるよう案内します。ランタイムのアップグレードやインストールの試行が多すぎるときは、「もう一度」ではなく数分後に試すよう表示します。移行元のコンピューターが MEMORY.md や notes/ を読めずにエージェントの移行が止まったときは、理由と直し方を表示します。
