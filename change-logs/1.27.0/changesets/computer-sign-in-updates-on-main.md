## zh-CN

在电脑的运行时登录对话框里，登录进度更新和输入框内容不会再偶尔互相覆盖（例如刚输入的验证码或刚到的一步丢失）。同时打开多个服务器时，运行时名称也不会偶尔显示成旧名称。

## en

In a Computer's runtime sign-in dialog, sign-in progress updates and what you type no longer occasionally overwrite each other (for example, a just-typed code or a just-arrived step being lost). With several servers open, runtime names no longer occasionally show an older name.

## ja

コンピューターのランタイムのサインインダイアログで、サインインの進行状況の更新と入力内容がまれに上書きし合う（入力したばかりのコードや届いたばかりのステップが消える）ことがなくなりました。複数のサーバーを開いているときに、ランタイム名がまれに古い名前で表示されることもなくなりました。
