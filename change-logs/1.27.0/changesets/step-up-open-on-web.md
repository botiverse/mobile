## zh-CN

“验证是你本人”提示去网页版完成时（这台设备用不了你的通行密钥，也没有身份验证器代码或备用码），现在多了一个“在网页打开”按钮，直接在浏览器里打开同一操作所在的网页：添加电脑打开该服务器的“电脑”页，更换机器密钥打开那台电脑的页面，修改密码、登录方式或退出设备打开“账户”设置，消息卡片打开它所在的会话。

## en

When "Verify it's you" sends you to the web (this device can't use your passkey and there's no authenticator or backup code), it now has an "Open on the web" button that opens the page for the same action in your browser: adding a computer opens the server's Computers page, a new machine key opens that computer's page, password, sign-in method and signed-in device changes open Account settings, and a message card opens its conversation.

## ja

「本人確認」で Web 版での確認を案内されるとき（このデバイスでパスキーを使えず、認証アプリのコードやバックアップコードもない場合）、「Web 版で開く」ボタンが表示されるようになりました。同じ操作のページをブラウザで直接開きます。コンピューターの追加ならサーバーのコンピューターページ、マシンキーの更新ならそのコンピューターのページ、パスワード・ログイン方法・ログイン中のデバイスの変更なら「アカウント」設定、メッセージカードならその会話が開きます。
