## zh-CN

创建或编辑 Agent 时，运行时设置里的长列表（比如 Built-in 的 33 个服务商）可以按名字、id、所属服务商或说明搜索，输入几个词也能找到，和网页一致；以前没有显示 id 的列表搜不到 id。

## en

In an agent's runtime settings, long lists (such as Built-in's 33 providers) can be searched by name, id, provider or description, several words at once, as on the web. Lists that don't show ids could not be searched by id before.

## ja

エージェントのランタイム設定の長いリスト（Built-in の 33 のプロバイダーなど）を、名前・ID・プロバイダー・説明で、複数の語でも検索できるようになりました（Web と同じ）。以前は ID を表示しないリストでは ID で検索できませんでした。
