## zh-CN

Agent 因为运行时没在计算机上登录而启动不了时，资料页的状态显示橙色「需要登录 {运行时}」，点一下打开那台计算机去登录，不再是灰色的离线（和网页一致）。

## en

When an agent can't start because its runtime isn't signed in on the computer, its profile status now reads "Sign-in needed for {runtime}" with the orange error light, and tapping it opens that computer to sign in, instead of a grey Offline. Same as the web.

## ja

ランタイムがコンピューターでログインしていないためにエージェントが起動できないとき、プロフィールのステータスがグレーの「オフライン」ではなく、オレンジのエラーライトと「{ランタイム} へのログインが必要です」になり、タップするとログインするコンピューターが開きます。Web と同じです。
