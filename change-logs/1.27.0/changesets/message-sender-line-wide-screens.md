## zh-CN

在平板等大屏上，消息很宽时，消息顶部的发送者一行（名字、简介和时间）现在只占这一行的前五分之四，过长的简介在那里用省略号收尾，不再一直延伸到最右边，读起来更像消息的标签，与网页版一致。手机上和较窄的消息栏不变。

## en

On tablets and other large screens, when a message is wide, the line at the top of the message with the sender's name, description and time now takes only the first four fifths of the width: a long description ends in an ellipsis there instead of running all the way to the right edge, so the line reads as a label for the message, as on the web. Phones and narrower message columns are unchanged.

## ja

タブレットなどの大きな画面でメッセージの幅が広いとき、メッセージ上部の送信者の行（名前、説明、時刻）は幅の 5 分の 4 までに収まるようになりました。長い説明はそこで省略記号で終わり、右端まで続かないので、Web 版と同じくメッセージのラベルとして読みやすくなりました。スマートフォンや狭いメッセージ欄はこれまでどおりです。
