## zh-CN

在 Agent 资料页点「复制诊断信息」后，按钮现在显示「诊断信息已复制」，不再是英文的「Diagnostics copied」。同一页里还有几处英文也改成了当前语言：活动日志里「思考中」「输出」「上下文压缩已开始 / 已完成」这几类条目的标题、没有时间的条目、提醒标签页里的相对时间（如「3 小时后」）、修改服务器角色时下拉菜单里的「管理员 / 成员」，以及成员资料页「创建的 Agent」列表里没有运行时的 Agent 下方的「Agent」。

## en

On an agent's profile, after you tap Copy diagnostic info the button now reads "Diagnostics copied" in your language instead of always in English. A few more English words on the same pages now follow your language too: the titles of Thinking, Output and context compaction rows in the activity log, a row with no time, the relative times on the Reminders tab (such as "in 3 hours"), the Admin and Member choices when you change an agent's server role, and the "Agent" line under an agent with no runtime in a member's created agents list.

## ja

エージェントのプロフィールで「診断情報をコピー」をタップした後のボタンが、英語の「Diagnostics copied」ではなく表示言語で「診断情報をコピーしました」と表示されるようになりました。同じ画面のほかの英語も表示言語になりました：アクティビティログの思考・出力・コンテキスト圧縮の行のタイトル、時刻のない行、リマインダータブの相対時刻（「3 時間後」など）、サーバーロールを変更するときの「管理者 / メンバー」の選択肢、メンバーのプロフィールの作成したエージェント一覧でランタイムのないエージェントの下に出る「Agent」の表記。
