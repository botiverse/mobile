## zh-CN

新增实验性运行时 DeepSeek Harness：在运行时列表和 Computer 页面上显示它的名字和图标；它的运行时卡片只显示状态和“安装”，并说明 DeepSeek 密钥在哪里设置（Raft 里不用登录）。Antigravity 不再标为已弃用，在服务器的运行时列表加载出来之前也不会显示“（已弃用）”。

## en

Adds the experimental DeepSeek Harness runtime: runtime lists and the Computer page show its name and mark, and its runtime card shows only its status and Install, with a line on where its DeepSeek key is set (there is no sign-in in Raft). Antigravity is no longer marked deprecated, including before the server's runtime list has loaded.

## ja

試験的なランタイム DeepSeek Harness に対応しました。ランタイムの一覧とコンピューターのページに名前とマークが表示され、ランタイムカードには状態と「インストール」だけが表示され、DeepSeek のキーをどこで設定するかを案内します（Raft でのログインはありません）。Antigravity は非推奨と表示されなくなり、サーバーのランタイム一覧を読み込む前も「（非推奨）」と表示されません。
