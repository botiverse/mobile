## zh-CN

创建和编辑智能体时，运行时设置里的开关项（例如 Codex 的「Fast mode」）现在和网页版一样显示为选项卡片：复选框在左，名称在右，说明写在名称下方，点卡片任意位置都能勾选或取消。表单其余部分也对齐了网页版：下拉框里的选中值改用与输入框相同的字体；错误提示会替换该项的说明，而不是叠在下面；模型列表不可用时的提示改为一行说明，「重试」放在句末；保存的值不在当前列表中时会说明；「高级」分组的标题和缩进与网页版一致。

## en

When you create or edit an agent, on/off settings in its runtime form (such as Codex's Fast mode) now look as they do on the web: an option card with the checkbox on the left, the name beside it and its description under the name, and a tap anywhere on the card turns it on or off. The rest of the form follows the web too: a picker's chosen value uses the same type as a text box, an error replaces the field's help text instead of sitting under it, a model list that can't be loaded says why in one line with Retry at the end, a saved value that's no longer in the list says so, and the Advanced group's heading and indent match the web.

## ja

エージェントの作成・編集で、ランタイム設定のオン／オフ項目（Codex の「Fast mode」など）が Web 版と同じオプションカードになりました。左にチェックボックス、右に名前、名前の下に説明が表示され、カードのどこをタップしてもオン／オフを切り替えられます。フォームのほかの部分も Web 版に合わせました。選択欄の値は入力欄と同じ書体になり、エラーは項目の説明の代わりに表示され、モデル一覧を読み込めないときは理由を 1 行で示して文末に「再試行」を置き、保存済みの値が一覧にない場合はその旨を表示し、「詳細設定」の見出しとインデントも Web 版と同じになりました。
