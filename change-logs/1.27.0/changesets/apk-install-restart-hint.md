## zh-CN

点 APK 附件的“安装”时，如果 Raft 还没有“安装未知应用”权限，会先说明：打开这个开关后 Android 会重启 Raft，之后回到 Raft 再点一次“安装”；点“打开设置”才会进入系统设置。

## en

Tapping Install on an APK attachment when Raft can't install unknown apps yet now first explains that Android restarts Raft when you turn that on, and to come back and tap Install again; Open Settings then takes you to the switch.

## ja

Raft に「不明なアプリのインストール」が許可されていない状態で APK 添付ファイルの「インストール」をタップすると、オンにすると Android が Raft を再起動すること、その後 Raft に戻ってもう一度「インストール」をタップすることを先に案内するようになりました。「設定を開く」でシステム設定に移動します。
