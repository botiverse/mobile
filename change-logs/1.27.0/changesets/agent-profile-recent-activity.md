## zh-CN

Agent 资料页新增「最近动态」卡片：在你能查看动态的 Agent 上，资料里直接看到它现在的状态、这一轮（或上一轮）在回应谁、做了什么，以及最近几轮各一行，例如「已结束，结局未知」「未发消息」。点「最近动态」可打开「动态」标签查看全部。

## en

An agent's profile now has a Recent activity card: for an agent whose activity you can see, the profile shows what it is doing now, who its current (or last) turn answers and what it did, and its last few turns one line each, such as "Ended, outcome unknown" or "No message sent". Tap Recent activity to open the Activity tab and see everything.

## ja

エージェントのプロフィールに「最近のアクティビティ」カードが加わりました。アクティビティを見られるエージェントでは、いまの状態、このターン（または前回）が誰に応えているか、何をしたか、そして最近のターンが 1 行ずつ（「終了（結果不明）」「メッセージ送信なし」など）プロフィールに表示されます。「最近のアクティビティ」をタップすると「アクティビティ」タブが開き、すべてを確認できます。
