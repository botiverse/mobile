## zh-CN

用 8 位短 ID 指向消息或讨论串的 Raft 链接，现在能正确打开对应的消息和讨论串，不再提示找不到。

## en

Raft links that name a message or thread by its 8-character short ID now open that message or thread instead of saying it can't be found.

## ja

メッセージやスレッドを 8 文字の短い ID で指す Raft リンクを開くと、「見つかりません」ではなく、そのメッセージやスレッドが開くようになりました。
