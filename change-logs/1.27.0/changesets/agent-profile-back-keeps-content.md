## zh-CN

从一个 Agent 的资料页打开它的电脑，再打开另一个 Agent 的资料页后返回，第一个 Agent 的资料页会原样显示，不再先闪一下“加载中…”。

## en

After you open an agent's profile, go to its computer, open another agent's profile and then go back, the first agent's profile shows right away as you left it, without a "Loading…" page first.

## ja

Agent のプロフィールからそのコンピューターを開き、さらに別の Agent のプロフィールを開いてから戻ると、最初の Agent のプロフィールが「読み込み中…」を挟まずに、そのまま表示されるようになりました。
