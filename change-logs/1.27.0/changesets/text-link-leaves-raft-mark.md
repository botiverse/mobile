## zh-CN

（界面）会带你离开 Raft 的文字链接（运行时表单里的说明链接、运行时安装的「查看源码」、运行时登录的验证地址、使用数据的「了解更多」、外部智能体的 SDK 指南）末尾现在有一个小的 ↗ 图标，和网页一样；消息里的链接和 Raft 内部的链接不加。运行时登录的「打开页面」按钮也改用同一个 ↗ 图标。

## en

(Interface) Text links that take you out of Raft (links in a runtime form's hints, a runtime install's View source, a runtime sign-in's verification address, Usage data's Learn more, the external agent SDK guide) now end in a small ↗, as on the web. Links in messages and links inside Raft don't get one. The runtime sign-in Open page button uses the same ↗.

## ja

（インターフェース）Raft の外へ移動するテキストリンク（ランタイムフォームのヒント内のリンク、ランタイムインストールの「ソースを見る」、ランタイムサインインの確認用アドレス、使用状況データの「詳細」、外部エージェントの SDK ガイド）の末尾に、Web と同じく小さな ↗ が付くようになりました。メッセージ内のリンクと Raft 内部へのリンクには付きません。ランタイムサインインの「ページを開く」ボタンも同じ ↗ を使います。
