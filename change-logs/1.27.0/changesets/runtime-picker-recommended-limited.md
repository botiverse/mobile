## zh-CN

创建智能体和编辑运行时时，运行时列表里 Claude Code 和 Codex 标着“推荐”，干活时不能接收新消息的运行时标着“能力有限”；选好运行时后，选择框下方会说明它在 Raft 里缺少哪些能力。运行时不再显示“实验性”标记。

## en

When you create an agent or change its runtime, the runtime list marks Claude Code and Codex as Recommended and runtimes that can't take new messages while working as Limited; after you pick a runtime, a line under the picker says what it lacks in Raft. Runtimes no longer show an Experimental badge.

## ja

エージェントの作成やランタイムの変更で、ランタイム一覧の Claude Code と Codex に「おすすめ」、作業中に新しいメッセージを受け取れないランタイムに「機能制限あり」を表示します。ランタイムを選ぶと、Raft で足りない機能が選択欄の下に表示されます。ランタイムの「試験的」表示はなくなりました。
