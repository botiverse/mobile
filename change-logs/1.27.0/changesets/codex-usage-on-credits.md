## zh-CN

Codex 的每周额度用完、但账号还有积分时，计算机的用量卡片、计算机列表和运行时选择器不再显示「已用完」，而是显示「已达上限 · 正在使用积分」，用量状态点也不再变成警告色；卡片上会显示剩余积分（例如「积分 30784」），积分不限量时显示「积分不限量」。重置按钮仍然可用，但不再作为主要操作。需要服务器支持，未更新的服务器上显示与之前相同。

## en

When a Codex weekly limit is used up but the account still has credits, the Computer usage card, the Computers list and the runtime pickers no longer say Used up: they say Limit reached · using credits, and the usage dot no longer turns to a warning. The card shows the credits left (for example 30784 credits), or Unlimited credits. A limit reset is still offered, but no longer as the main action. This needs the server's support; until the server is updated, usage shows as before.

## ja

Codex の週間上限に達していてもアカウントにクレジットが残っている場合、コンピューターの使用量カード、コンピューター一覧、ランタイムの選択画面で「上限到達」だけを表示せず「上限到達 · クレジット使用中」と表示し、使用状況のドットも警告色になりません。カードには残りのクレジット（例:「クレジット 30784」）、または「クレジット無制限」が表示されます。リセットは引き続き使えますが、主な操作としては表示されなくなります。サーバー側の対応が必要で、サーバーが更新されるまでは従来どおりの表示です。
