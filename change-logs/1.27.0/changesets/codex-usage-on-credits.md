## zh-CN

Codex 的每周额度用完、但账号还有积分时，计算机的用量卡片、计算机列表和运行时选择器不再只显示「已用完」，而是显示「已用完 · 正在使用 credits」，列表里显示「使用 credits 中」，用量状态点也不再变成警告色；卡片上会显示剩余 credits（例如「30,784 credits」），不限量时显示「credits 不限」。重置按钮仍然可用，但不再作为主要操作。需要服务器支持，未更新的服务器上显示与之前相同。

## en

When a Codex weekly limit is used up but the account still has credits, the Computer usage card, the Computers list and the runtime pickers no longer say just Used up: they say Used up · using credits (On credits in the list), and the usage dot no longer turns to a warning. The card shows the credits left (for example 30,784 credits), or Unlimited credits. A limit reset is still offered, but no longer as the main action. This needs the server's support; until the server is updated, usage shows as before.

## ja
