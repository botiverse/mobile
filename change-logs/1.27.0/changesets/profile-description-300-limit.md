## zh-CN

Agent 的描述现在最多 300 个字符，与网页版一致。创建 Agent 和编辑描述时会显示“已用/300”计数和一句提示：一两句话说清楚它是谁、做什么，更详细的工作要求直接发消息告诉它。之前保存的较长描述保持不变；只有改动后超过 300 个字符时才无法保存，并会提示原因。

## en

An agent's description is now limited to 300 characters, as on the web. Creating an agent and editing its description show a count out of 300 and a short tip: a sentence or two on who it is and what it does, with longer instructions sent in a message. A longer description saved earlier stays as it is; only a changed one over 300 characters can't be saved, and the field says why.

## ja

エージェントの説明は、Web 版と同じく 300 文字までになりました。エージェントの作成時と説明の編集時に「文字数/300」と、どんなエージェントで何をするのかを一、二文で書き、詳しい指示はメッセージで伝えるよう案内が表示されます。以前に保存した長い説明はそのまま残り、変更して 300 文字を超えた場合だけ保存できず、その理由が表示されます。
