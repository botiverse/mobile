## zh-CN

翻看较早的消息时，如果屏幕上的某条消息原地变高或变矮（收藏、添加或移除回应、编辑，或者链接卡片、图片加载完成），列表不再跳动，正在看的消息保持不动。停在最新消息时，底部照旧保持对齐。

## en

While you read earlier messages, a message on screen that changes size in place (saving it, adding or removing a reaction, an edit, a link card or image finishing loading) no longer makes the conversation jump: the message you are reading stays where it is. At the latest message, the bottom stays in place as before.

## ja

過去のメッセージを読んでいるときに、画面上のメッセージがその場で大きさを変えても（保存、リアクションの追加・削除、編集、リンクカードや画像の読み込み完了）、会話がずれなくなりました。読んでいるメッセージはその位置のままです。最新メッセージにいるときは、これまでどおり下端がそろったままです。
