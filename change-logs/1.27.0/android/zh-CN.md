✨ **新功能**
- **个人助理**（逐步开放）：
  - 主页的「已保存」和「草稿」下方新增「助理」入口：已有助理时打开你和它的私信，还没有时打开介绍页，可以「创建助理」。宽屏的侧边栏里也有这个入口。
  - 助理资料页可以开关「在所有页面显示 Ottie」、查看并断开微信连接，也可以删除助理。宽屏上可以直接在 App 里「连接微信」，扫二维码即可。
  - 「语言与地区」「主题」「通知」页面会在「由你的助理更改」里列出助理替你改过的设置，助理资料页也新增了「最近的更改」。
- **设置**补齐了网页版已有的功能：
  - 「账户 › 已登录的设备」可以退出某一台设备或其他所有设备；「用 Raft 登录过的 App」可以查看并撤销。
  - 「服务器 › 已归档频道」和「已归档的 Agent」可以点开（频道只读打开，Agent 可「查看工作区」）。服务器所有者可以在「服务器信息」里删除服务器。
  - 平板上「外观」新增「键盘快捷键」；服务器开启 Labs 后会显示「Labs」页面（逐步开放）。
- 「确认是你本人」可以直接在 App 里「使用通行密钥」；需要去网页版完成时，「在网页打开」会直接打开同一操作所在的页面。
- 输入框里待发送的附件可以长按拖动调整顺序。长按消息发送人的名字，可以复制名称或 Handle。
- Agent 资料页新增「最近动态」卡片：显示它现在在做什么，以及最近几轮的情况。
- 可以在计算机页面上安装或升级运行时，确认后才会执行（逐步开放）。支持实验性的 DeepSeek Harness 运行时。
- 邀请服务器以外的人时，本服务器的成员也可以勾选「邀请对方连接自己的服务器」。

🔧 **改进**
- 搜索会查找服务器上所有你能看到的频道和人，包括已归档和未加入的频道，按「频道」「人」「计算机」分组，可以「显示全部」和「加载更多」。未加入的公开频道会打开预览，可以直接加入；在输入框里输入 # 也会列出已归档的频道。
- 设置更好找了：「移动端」页并入「外观」，几项设置改了更清楚的名字（如「回车键发送」「手机通知延迟」），「退出登录」改为弹出确认框，「套餐与账单」和「管理」只对所有者和管理员显示。「关于」更简洁：「版本」显示构建号、长按可复制完整版本信息，连接自部署服务器时显示「连接的服务器」，去掉了「打开 Raft」一项，复制的环境信息不再附带日志。
- 「动态」：新的 @提及会出现、在其他地方标为完成的会话会消失，不用等回到 App；重新连接后只更新有变化的会话（逐步开放）。「未读」筛选里读过的会话有新消息时会回到最上面；触屏上较早的会话也显示时间；「可能不是最新的」提示已移除。
- 消息列：原消息滚出视野后，标题显示发送者和原消息第一行；点标题可以滚回原消息，「在频道中查看」会在频道里定位到原消息。看过的会话打开时不再闪「加载中」，「回到底部」点一次就够，加载时显示「正在加载消息…」。
- 选择消息时的操作栏把「转发」「生成图片」「复制链接」「复制 Markdown」直接显示为图标按钮，与网页版一致。
- 运行时设置与网页版一致：Claude Code 和 Codex 标为「推荐」，部分运行时标为「能力有限」；开关项改为选项卡片；长列表可以按 id 或服务商搜索；推理强度不能调整时仍会显示并说明原因；运行时未登录或版本太旧而列不出模型时会直接说明。Codex 的速度选项按所选模型显示（需服务器支持）。
- 计算机：Codex 显示「已用完 · 正在使用 credits」和剩余 credits（需服务器支持）。Claude Code 用量卡片只有一个「使用额度重置」（逐步开放）。「添加计算机」会先说明 Agent 在那里能做什么；作为系统服务运行的计算机会说明怎样升级；用量只读取计算机的默认账号。
- Agent 资料页：底部操作改为操作行卡片，只有不能撤销的操作是红色；「原始日志」里状态的说明单独成行，并显示为你的语言；描述限制为 300 个字符，其中的链接不是所有人都能打开时会提醒；所有者和管理员报告问题时也可以附上运行日志。
- 平板和宽屏上：「动态」使用紧凑的行和单行标题，消息的发送者一行不再延伸到最右边，「小」「大」字号与「中」相差完整一档，任务信息会随对话一起滚走。
- 消息里的 Mermaid 流程图排得更清楚，回到前面步骤的线从侧面绕回。
- 侧栏长按菜单的「移动到分区」第一行是会话原本所在的分区，取代了「移出分区」。
- 打开 App 时恢复登录太慢，可以「重试」或「退出登录」。点 APK 附件的「安装」时，会先说明允许安装未知应用后系统会重启 Raft。
- 句子中的链接会和文字一起换行，离开 Raft 的链接末尾带 ↗，@ 候选列表里其他服务器的成员头像角上显示那个服务器的图标，频道操作的图标恢复常规大小，外部频道、连接服务器和迁移 Agent 的提示也更清楚。
- 更多界面会跟随你的语言，包括桌面小组件、登录、附件、转发和 Agent 活动日志的提示；繁体中文、韩语、西班牙语、葡萄牙语和俄语在「计算机」和升级页面不再显示英文。
- 连接开启隐私模式的服务器时，不再提供「报告问题」和「新建反馈」，也不会上传诊断信息和崩溃报告。

🐛 **修复**
- 修复了在宽屏上打开图片预览等页面、在宽屏布局里跳转到消息列中的消息、成员页或消息列表尺寸变化后，以及打开含特定 Markdown 写法的消息时的闪退。
- 输入的文字会在输入过程中保存为草稿，App 崩溃时最多只丢失最后一刻的输入。
- 翻看较早的消息时，消息变高或变矮不再让对话跳动；Artifact 卡片和翻译中的消息在加载时保持大小；展开消息后会自动滚到展开的内容。
- 打开 App 后消息立即以你选的字号显示；宽屏上打开几秒后字号不再突然变化。
- 「动态」：读过的会话不再变回未读，在其他设备上标为未读的会话会保持未读（逐步开放）。Artifact 总是打开最新版本，收起列表时按返回会关闭会话，外部频道里其他服务器的人显示自己的头像和名字。
- Artifact：「下载」会直接在 App 里保存文件，不再跳到浏览器；页面加载时 ⋯ 和版本菜单也能正常显示；所在服务器已退出的共享频道里的 Artifact 显示为「共享频道」。
- 频道：归档或取消归档后输入框立即切换；「添加成员」里不再列出访客，访客只出现在所有者和管理员的搜索结果里；频道太大无法共享时会显示服务器给出的说明。
- 计算机：开启两步验证时也能「添加计算机」，运行时登录对话框不再丢失刚输入的内容；手机上轻点运行时用量会以底部面板打开，滚动时不会误开。
- Agent 资料页：运行时未登录的 Agent 显示「需要登录」并可打开对应的计算机，返回时上一个资料页立即显示，在「概览」「原始日志」上滑动会先在两者间切换，其余英文标签也会显示为你的语言。
- 用 8 位短 ID 的 Raft 消息链接可以打开，任务交接原因里的链接和 @提及可以点按，较早消息里的图片会继续正常加载。
- 回到 App 时应用卡片会显示最新内容，按钮放置一段时间后也不会先失败一次。
- 附件已过期的消息会提示重新上传，不再提供无法成功的「重试」。
- 其他小问题：打开的菜单在按钮滚出视野后会关闭，宽屏上各栏在边缘干净截断、顶栏适配栏宽，「检查更新」的状态显示为你的语言，连接自部署服务器时不再一直浮着服务器标签，Cindy 的 Pro 试用邀请在手机上只显示一行，App 在后台时更省资源。
