✨ **新機能**
- **パーソナルアシスタント**（段階的に提供）：
  - ホームの「保存済み」と「下書き」の下に「アシスタント」を追加しました。アシスタントがいればその DM が、まだなければ「アシスタントを作成」できるページが開きます。ワイド画面ではレールにも表示されます。
  - アシスタントのプロフィールで「すべてのページに Ottie を表示」のオン・オフ、WeChat の連携状態の確認と解除、アシスタントの削除ができます。ワイド画面では QR コードを読み取って、アプリ内で「WeChat を連携」できます。
  - 「言語と地域」「テーマ」「通知」の「アシスタントが変更した設定」に、アシスタントが変更した内容が表示されます。アシスタントのプロフィールにも「最近の変更」を追加しました。
- **設定**に Web 版にある機能を追加しました：
  - 「アカウント › ログイン中のデバイス」で 1 台ずつ、またはほかのすべてのデバイスをログアウトでき、「Raft でログインしたアプリ」で連携を取り消せます。
  - 「サーバー › アーカイブ済みのチャンネル」「アーカイブ済みのエージェント」をタップして開けます（チャンネルは読み取り専用、エージェントは「ワークスペースを表示」付き）。オーナーは「サーバープロフィール」からサーバーを削除できます。
  - タブレットでは「外観」に「キーボードショートカット」を追加し、サーバーで Labs が有効なときは「Labs」ページが表示されます（段階的に提供）。
- 「本人確認」でアプリ内から「パスキーを使用」できます。Web 版での確認が必要なときは、「Web 版で開く」で同じ操作のページが直接開きます。以前のパスキーしかないアカウントでは、「ブラウザで続ける」でアプリ内で確認を終えられます（段階的に提供）。
- 入力欄の添付を長押ししてドラッグすると、順番を並べ替えられます。送信者名を長押しすると、名前またはハンドルをコピーできます。
- エージェントのプロフィールに「最近のアクティビティ」カードを追加しました。いまの状態と最近のターンが表示されます。
- コンピューターのページからランタイムをインストール・アップグレードできます。実行は必ず確認のあとです（段階的に提供）。試験的なランタイム DeepSeek Harness に対応しました。
- サーバー外の人を招待するとき、このサーバーのメンバーにも「サーバー接続に招待」を送れます。

🔧 **改善**
- 検索で、見ることのできるサーバー上のすべてのチャンネルと人（アーカイブ済み・未参加のチャンネルを含む）が見つかるようになりました。「チャンネル」「人」「コンピューター」に分かれ、「すべて表示」「さらに読み込む」で続きを表示できます。未参加の公開チャンネルはプレビューから参加でき、入力欄で # を入力するとアーカイブ済みのチャンネルも候補に出ます。
- 設定が見つけやすくなりました：「モバイル」ページは「外観」にまとめ、いくつかの項目をわかりやすい名前（「Enter キーで送信」「スマートフォンの通知の遅延」など）に変え、ログアウトは確認ダイアログで尋ね、「プランと請求」と「管理」はオーナーと管理者にだけ表示します。「情報」はすっきりしました：「バージョン」にビルド番号を表示して長押しで詳細をコピーでき、セルフホストのサーバーでは「接続先サーバー」を表示し、「Raft を開く」の項目をなくし、コピーした環境情報にログを含めなくなりました。
- 「アクティビティ」：アプリに戻るのを待たずに新しい @メンションが表示され、ほかの場所で完了にした会話が消えます。再接続後は変わった会話だけを更新します（段階的に提供）。「未読」で読んだ会話に新しいメッセージが届くと一番上に戻り、タッチ操作では前の日の会話にも時刻を表示し、「最新ではない可能性があります」の案内はなくなりました。
- スレッド：元のメッセージが見えなくなると、タイトルに送信者と 1 行目を表示します。タイトルをタップすると元のメッセージに戻り、「チャンネルで表示」はチャンネルで元のメッセージを開きます。一度見た会話は「読み込み中」を挟まずに開き、「最下部に戻る」は 1 回のタップで動き、読み込み中は「メッセージを読み込み中…」と表示します。
- メッセージ選択中のバーで、「転送」「画像を生成」「リンクをコピー」「MD をコピー」が Web 版と同じくアイコンボタンで直接表示されます。
- ランタイム設定が Web 版と同じになりました：Claude Code と Codex に「おすすめ」、一部のランタイムに「機能制限あり」を表示し、オン・オフの項目はオプションカードになり、長いリストを ID やプロバイダーで検索でき、推論の強度を変更できないときも理由付きで表示し、ランタイムがログインしていない、または古くてモデルを一覧できないときはそう表示します。Codex の速度の選択肢は選んだモデルに合わせて表示されます（サーバーの対応が必要）。
- コンピューター：Codex で「上限到達 · クレジット使用中」と残りのクレジットを表示します（サーバーの対応が必要）。Claude Code の使用量カードは「上限リセットを使う」1 つになりました（段階的に提供）。「コンピューターを追加」ではエージェントがそこで何をできるかを先に表示し、システムサービスとして動くコンピューターはアップグレードの方法を案内し、使用量はコンピューターのデフォルトアカウントだけを読み取ります。
- エージェントのプロフィール：末尾の操作は操作行のカードになり、赤は元に戻せない操作だけになりました。「生ログ」のステータスの説明は別の行に表示言語で表示され、説明は 300 文字までになり、説明内のリンクを全員が開けないときは案内が表示されます。オーナーと管理者も問題を報告するときにランナーログを添付できます。
- タブレットや広いウィンドウでは、「アクティビティ」がコンパクトな行と 1 行の見出しになり、メッセージの送信者の行が右端まで伸びなくなり、文字サイズの「小」「大」が「中」からはっきり 1 段階変わり、タスクの詳細は会話と一緒にスクロールします。
- メッセージ内の Mermaid フローチャートがより見やすく配置され、前の手順に戻る線は横から回り込みます。
- サイドバーの長押しメニューの「セクションに移動」は会話の元のセクションが先頭になり、「セクションから外す」の代わりになりました。
- 起動時にログインの復元に時間がかかるときは、「再試行」か「ログアウト」を選べます。
- 文中のリンクは前後の文字と一緒に折り返し、Raft の外へ移動するリンクの末尾には ↗ が付き、@ 候補では他のサーバーのメンバーのアバターにそのサーバーのロゴが表示され、チャンネルの操作のアイコンは通常の大きさになり、チャンネル上部の「メンバー」ボタンの人数は赤いバッジではなくグレーの数字になり、外部チャンネル、サーバーの接続、エージェントの移行の案内もわかりやすくなりました。
- ログイン、アカウント連携、添付ファイル、転送、エージェントのアクティビティログのメッセージなど、表示言語に従う画面が増えました。繁体字中国語、韓国語、スペイン語、ポルトガル語、ロシア語でも「コンピューター」やアップグレードの画面に英語が出なくなり、写真へのアクセス許可の説明も表示言語で表示されます。
- プライバシーモードのサーバーでは「問題を報告」と「新しいフィードバック」を表示せず、診断情報とクラッシュレポートもアップロードしません。
