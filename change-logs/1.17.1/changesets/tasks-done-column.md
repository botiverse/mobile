## zh-CN

任务页的「已完成」和「已关闭」默认收起，以前只显示标题和数量，看起来像有任务却点不到。现在每个分组标题都带一个箭头：收起时朝右，展开时朝下，点标题即可展开查看任务。

## en

On the Tasks page, Done and Closed start collapsed, and their headers used to show only a name and a count, so it looked like a task was there with nothing to tap. Each section header now has an arrow that points right when collapsed and down when open. Tap the header to show the tasks.

## ja

タスクページの「完了」と「クローズ」は最初は折りたたまれていて、これまでは見出しに名前と件数だけが表示されるため、タスクがあるのにタップできないように見えていました。各セクションの見出しに矢印を追加しました。折りたたみ中は右向き、展開中は下向きです。見出しをタップするとタスクが表示されます。
