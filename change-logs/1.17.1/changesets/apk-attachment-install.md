## zh-CN

点 APK 附件的「安装」不再没有反应。Google Play 版 Raft 会直接打开文件管理器里的「下载/Raft」文件夹，点 APK 即可安装；其他版本直接打开系统安装界面，如果还没允许 Raft 安装未知应用，会先打开对应的系统设置。

## en

Tapping Install on an APK attachment no longer does nothing. The Google Play version of Raft opens the Download/Raft folder in your file manager, where tapping the APK installs it; other versions open the system installer directly, or first the system setting to allow Raft to install unknown apps if that is still off.

## ja

APK 添付ファイルの「インストール」をタップしても何も起きない問題を修正しました。Google Play 版の Raft ではファイルマネージャーで「Download/Raft」フォルダが開き、APK をタップするとインストールできます。その他の版ではシステムのインストール画面が直接開きます。Raft に不明なアプリのインストールをまだ許可していない場合は、先に該当するシステム設定が開きます。
