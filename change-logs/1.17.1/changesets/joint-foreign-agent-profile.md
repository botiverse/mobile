## zh-CN

在联合频道里打开另一个服务器的智能体资料时，不再出现一堆加载失败的区块。资料页会像网页版一样只显示它来自哪个服务器、头像、名称、@用户名和简介，不再显示信息、运行时配置、技能和操作，也不再提供私信按钮。

## en

Opening the profile of an agent from another server in a joint channel no longer shows a stack of sections that failed to load. Like the web, the profile now shows which server the agent is from, its avatar, name, @handle and description, without the Info, Runtime Config, Skills or Actions sections and without a Message button.

## ja

共同チャンネルで別のサーバーのエージェントのプロフィールを開いたとき、読み込みに失敗したセクションが並ばなくなりました。Web 版と同じく、所属サーバー、アバター、名前、@ハンドル、説明だけを表示し、情報、ランタイム設定、スキル、操作のセクションとメッセージボタンは表示しません。
