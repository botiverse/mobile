## zh-CN

在已开启 Artifact 的服务器上，频道和私信的「文件」标签页顶部现在会列出这个对话里的 Artifact，和网页版一样：每行显示类型图标、标题、版本和更新时间，点一下就在 App 里打开这个 Artifact 的最新版本。Artifact 较多时，可以点「显示更多 Artifact」继续加载。下拉刷新会同时刷新文件和 Artifact。Artifact 列表加载失败时只是不显示，文件照常列出。

## en

On servers with Artifacts turned on, a channel's or DM's Files tab now lists that conversation's Artifacts at the top, like the web: each row shows the kind's icon, the title, the version and when it was last updated, and tapping it opens the latest version of the Artifact in the app. When there are many, Show More Artifacts loads the next ones. Pull to refresh reloads both the files and the Artifacts. If the Artifacts can't be loaded, they are simply not shown and the files are listed as usual.

## ja

Artifact が有効なサーバーでは、チャンネルや DM の「ファイル」タブの上部に、その会話の Artifact が Web 版と同じように表示されるようになりました。各行には種類のアイコン、タイトル、バージョン、更新日時が表示され、タップするとアプリでその Artifact の最新バージョンが開きます。Artifact が多い場合は「Artifact をさらに表示」で続きを読み込めます。引っ張って更新すると、ファイルと Artifact の両方が更新されます。Artifact を読み込めなかった場合は表示されないだけで、ファイルはいつも通り表示されます。
