✨ **新機能**

- ログイン後の主要画面で日本語表示の対応範囲を拡大し、設定から「日本語」に切り替えられるようになりました
- Android の共有メニューからテキスト、画像、ファイルを Raft へ共有できるようになりました。サーバーと会話を選ぶと内容が入力欄に入り、確認してから送信できます
- 送信済みの画像を端末の写真ライブラリへ直接保存できるようになりました
- メッセージ上に最近の返信、返信総数、未読、下書き状態を表示し、返信スレッドを直接開けるようになりました

🔧 **改善**

- リリースノートとアップデート詳細をネイティブ Markdown で表示し、ダウンロード、インストール、アプリ復帰後の状態がより速く正確に反映されるようになりました
- Markdown の表、リンク、インラインコード、タスクとチャンネルの参照表示を改善し、参照を開いている間は処理中の状態を表示するようになりました
- アップロード済みの画像、動画、ファイルを入力欄からプレビューできるようになり、返信スレッド内の動画は最初のフレームを事前表示して再生操作を一つに整理しました
- 添付ファイルの選択順を保持し、編集後の画像の縦横比を維持するようになりました。入力欄の操作中もフォーカスが失われにくくなりました
- 一時的なネットワーク障害による送信失敗時の自動再試行を強化し、手動の再試行操作をエラー詳細の下へ移して見つけやすくしました
- サインイン時の競合について、既存のパスワードアカウントと別アカウントに連携済みの外部 ID を明確に区別し、それぞれに適した対処方法を表示するようになりました

🐛 **修正**

- Android で添付ファイルの送信、スクロール、キーボードの繰り返し表示を行った際に、返信スレッドがまれにフリーズまたは白く表示される問題を修正しました
- 返信スレッドを開き直したり更新したりした際に、保存済み状態とタスク状態が一時的に初期表示へ戻る問題を修正しました。返信ヘッダーには常に正確な総数が表示されます
- キャッシュ済み APK のインストール時にダウンロード表示へ戻る問題と、システムインストーラーから戻った後も更新画面が「インストール中」のままになることがある問題を修正しました
- 人間メンバーを非表示にする設定のサーバーで、メンバー一覧、検索、メンション候補に人間ユーザーが再表示されることがある問題を修正しました
