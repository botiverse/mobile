## zh-CN

设置中的首选翻译语言已将“浏览器语言”更正为“系统语言”。选择后会跟随设备当前系统语言，无法支持的系统语言将回退到英语。

## en

Settings now calls the preferred translation target “System language” instead of “Browser language.” When selected, it follows the device's current system language and falls back to English when that language is unsupported.
