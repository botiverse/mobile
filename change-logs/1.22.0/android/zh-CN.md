✨ 新功能
- 分享消息生成图片时，可以先预览，再选择图片宽度：手机、平板、宽，或者用滑块自定义宽度，预览会跟着变化。确认后再保存。较宽的表格、代码和公式会自动排进图片宽度内并换行，不会再被截掉。很长的图片会自动降低清晰度，避免保存失败
- 在平板等宽屏上，Thread 右侧多了一条时间线：每条人发的消息一个刻度，Thread 的第一条消息排在最前面，你自己发的刻度颜色更深，当前看到的位置会加粗。用鼠标或触控板悬停（触屏平板上点一下）会展开列表，每条消息一行，悬停或长按某一行能看到完整文字、发送人和时间，点一下就跳到那条消息。手机上（以及没有显示时间线的地方），Thread 右上角 ⋯ 菜单里多了「时间线」，会打开半屏的列表，每条显示两行文字和发送人、时间，点一下就跳到那条消息。人发的消息少于 4 条的 Thread 不显示
- Agent 因模型服务余额不足而停下时，资料页顶部会显示提示，说明要检查这个 Agent 所用模型服务的余额和计费状态。有权限的人可以点「查看模型配置」，其他人会看到请联系服务器管理员处理
- 使用 Built-in Pi 自定义网关模型的 Agent，如果 Computer 回报当前会话至少有一项模型上限是由 Raft 用默认值补上的，Agent 的“资料”页和运行时设置表单里会显示一条警告，提醒你到服务商那边确认实际上限。警告不显示具体数值或来源，也不会阻止 Agent 运行；在运行时表单里改动设置后，警告会先隐藏。没有收到这类回报时什么都不显示

🔧 改进
- 消息引用（如 `#频道 msg=…`、私信里的消息引用）现在和话题引用一样是青色，不再和提及你的黄色混淆。黄色只用于提及你自己
- Agent 发来的简短提问（最多 3 道选择题）现在可以直接在对话里的卡片上回答，不用再打开单独的页面。单选题点一下选项就会提交，卡片显示「已提交 · 撤销」1.5 秒，这段时间内点「撤销」可以改答案，什么都不会发出；多选题或写了「其他…」的回答，按卡片上的按钮提交。有多道题时每题前带编号。卡片被冻结或变化导致没有发出时，会提示「未发送」并保留你的选择。其他提问卡片仍在原来的表单里回答
- 动态列表现在按天分组，分组标题为“今天”“昨天”或日期（不是今年的会带上年份）。今天的会话在第一行末尾显示“刚刚”“3 分钟”“2 小时”这样的简短时间；更早的会话由分组标题标明日期，不再逐行显示时间
- 应用在前台打开时使用的流量和电量大大减少。之前在忙碌的服务器上，即使你不在首页或动态页面，应用也会每隔几秒重新下载整个首页和动态列表；现在它只在你回到这些页面时更新一次，并把同时发出的相同请求合并为一次
- 离线时读过的频道和私信现在会保存下来：重新打开 App 或恢复联网后，未读数不会再跳回来，并会把已读同步到你的其他设备。之后收到的新消息仍然算作未读。如果你把会话标记为未读，或者已经无法访问该会话，这条离线已读就不再发送
- Agent 资料页的状态会用更清楚的话说明启动失败的原因：账号或套餐不包含所选模型、启动后反复以同样方式失败、上下文太大，以及启动超时。自动唤醒暂停时会显示 Raft 下次自动重试的时间。模型不可用或上下文太大时，有权限的人可以直接点「更换模型」打开模型配置
- 点击消息里指向会话、消息列或任务的引用时，如果它已经在设备上，会立即打开，不再先等服务器。只有需要从服务器获取时才会在引用上显示加载圈；打不开时会提示原因（找不到、没有权限、不在当前服务器），并停留在当前页面
- Agent 的活动概览现在显示每一轮最后的输出，点一下可以看全文
- 使用触控板或鼠标时，界面更紧凑：输入框、按钮、标签页、菜单项和侧边栏的行统一为同一高度；页面和面板的标题栏更矮，返回和标题栏里的按钮更小；顶栏更矮，左侧导航栏更窄；开关更小；设置里的卡片留白更宽松、间距更大。用手指操作时，一切保持原样
- 已静音的频道或私信，顶部栏名字旁只显示一个静音图标，不再显示“已静音”文字，给名字和状态留出更多空间
- App 现在只支持 64 位安卓手机。只支持 32 位的手机（多为入门机型）无法再安装；在这些手机上，此前的版本打开就会闪退

🐛 修复
- 智能体资料页的「动态」标签在活动更新时不再跳回顶部。打开时直接停在最新一条；停在底部时，新动态会继续显示在底部；往上翻看时位置保持不动，底部会出现「回到底部」按钮，有新动态时显示「N 条新动态」，点一下回到最新
- 离开一个会话或 thread（返回、打开别的页面或切到后台）之后，它不会再把刚到的新消息悄悄标为已读，这些消息会保持未读，直到你回来看到它们
- 修复动态列表里部分讨论串显示旧回复的问题：在共享频道的讨论串里有新回复（包括你自己发的）后，该行时间已更新，但预览仍停留在之前的旧回复上，点进去才看到别人已经回复。现在列表刷新后会显示最新的回复
- 在还没有讨论的任务里发出第一条消息后，再次打开这个任务会进入它的讨论并看到这条消息，不再停留在“这个任务还没有讨论”的空白页。任务的创建人如果是另一个工作区的 Agent，任务头部也会显示它自己的头像，而不是默认头像
- 深色模式下，在 App 内打开的页面（网页、Artifacts、更新说明）以及系统对话框和选择器现在也是深色的，跟随 App 的外观设置，而不再总是浅色
- 在动态列表顶部或离顶部很近时，新动态到来后列表会停在顶部，新的会话直接显示在最上面，不会再被挤到屏幕外，让你停在“第二屏”。当某个会话有了今天的新动态、出现新的“今天”分组标题时也是如此。如果你已经往下滚动，当前位置保持不变，并显示“↑ N 条新更新”按钮，点按即可回到顶部
- 在频道、私信或 thread 里往上翻看时，下方来了新消息，底部的按钮现在会显示「↓ N 条新消息」，和网页一致；之前它常常只显示「回到底部」。点一下回到最新，回到底部后计数清零
- 分享附件（例如 PDF、图片或视频）到微信等应用，或用“其他应用打开”时，现在会使用附件原本的文件名和正确的文件类型，接收方可以直接打开。之前文件名前面会多出一长串字符、类型显示为未知，无法作为 PDF 打开。上传类型未知的文件时，会根据扩展名识别类型
- 在手机上打开某个页面（例如一个会话）时，点按消息链接或通知会立即打开目标会话，不用再等你返回后才跳转。如果目标会话就是当前页面，不会再重复打开一次
- 打开任务会话时，输入框会立即出现，不再需要等上好几秒
- 公告里指向设置的按钮（例如“选择主题”）现在会直接打开 App 里对应的设置页，不会再跳到浏览器
- 在宽屏布局中收起列表后，关闭会话时列表会重新显示，不会只剩下“选择一个会话”。打开会话后列表会再次收起
- 云端 Agent 的资料页不再把运行时和模型显示为“external”，而是像网页版一样显示它在云端使用的模型；成员页中没有电脑的 Agent 分组改名为“外部与云端”，与网页版一致；归档 Agent 后它会立即从成员列表消失，无需重新加载
- 在 Agent 资料页点右上角的消息按钮打开私信，再返回时，资料页会停留在你原来所在的标签，不再跳到最后一个标签（应用）
- 在手机浏览器里用 Google 登录网页版时，最后一步留在浏览器里完成，不会再跳进 App 后登录失败
