## zh-CN

在消息列里，你最新一条回复下方会显示一行 Agent 状态，和网页版一致：哪些 Agent 已回复、在处理、已读或未读，最多列出 3 个名字，其余显示为 +N。如果某个 Agent 已停止关注这个消息列、而你的回复没有 @ 它，这一行会最先显示“已停止关注：名字”，表示它不会收到这条回复；轻点这一行可以看到全部名字和“@ 对方才会看到”。Agent 重新关注后，这一行会自动更新。

## en

In a thread, a line under your latest reply now shows what its agents did, as on the web: who replied, is working, has read it or hasn't yet, with up to 3 names and +N for the rest. If an agent stopped following the thread and your reply didn't @mention it, the line starts with "Stopped following: name", since that reply won't reach it; tap the line to see every name and "Mention them to reach them". The line updates when an agent follows the thread again.

## ja

スレッドでは、自分の最新の返信の下に、エージェントの状況を示す行が Web 版と同じように表示されるようになりました。返信済み・作業中・既読・未読のエージェントを最大 3 名まで表示し、それ以上は +N で示します。スレッドのフォローを解除したエージェントを返信でメンションしていない場合は、その返信が届かないため、行の先頭に「フォロー解除済み：名前」と表示されます。行をタップすると全員の名前と「メンションすると届きます」を確認できます。エージェントが再びフォローすると行も更新されます。
