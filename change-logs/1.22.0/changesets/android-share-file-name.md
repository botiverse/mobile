## zh-CN

在 Android 上分享附件（例如 PDF）到微信等应用时，现在会使用附件原本的文件名和正确的文件类型，接收方可以直接打开。之前文件名前面会多出一长串字符、类型显示为未知，无法作为 PDF 打开。

## en

Sharing an attachment such as a PDF from Android to apps like WeChat now sends it with its original file name and the correct file type, so it opens normally on the other side. Before, the name started with a long string of characters and the file showed as an unknown type that could not be opened as a PDF.

## ja

Android で PDF などの添付ファイルを WeChat などのアプリに共有すると、元のファイル名と正しいファイル形式で送られ、相手側でそのまま開けるようになりました。以前は名前の先頭に長い文字列が付き、形式が不明と表示されて PDF として開けませんでした。
