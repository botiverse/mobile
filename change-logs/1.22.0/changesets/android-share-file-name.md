## zh-CN

分享附件（例如 PDF、图片或视频）到微信等应用，或用“其他应用打开”时，现在会使用附件原本的文件名和正确的文件类型，接收方可以直接打开。之前在 Android 上文件名前面会多出一长串字符、类型显示为未知，无法作为 PDF 打开。iOS 上分享、存储到“文件”和上传附件时，中文等非英文文件名也不再变成下划线。上传类型未知的文件时，会根据扩展名识别类型。

## en

Sharing an attachment such as a PDF, image or video to apps like WeChat, or opening it with another app, now sends it with its original file name and the correct file type, so it opens normally on the other side. Before, on Android the name started with a long string of characters and the file showed as an unknown type that could not be opened as a PDF. On iOS, sharing, saving to Files and uploading no longer turn Chinese and other non-English file names into underscores. Uploaded files without a known type are now typed from their extension.

## ja

PDF・画像・動画などの添付ファイルを WeChat などのアプリに共有したり、ほかのアプリで開いたりすると、元のファイル名と正しいファイル形式で渡され、相手側でそのまま開けるようになりました。以前は Android で名前の先頭に長い文字列が付き、形式が不明と表示されて PDF として開けませんでした。iOS では共有・「ファイル」への保存・アップロードの際に、日本語などの英語以外のファイル名がアンダースコアに置き換わらなくなりました。形式が不明なファイルをアップロードすると、拡張子から形式を判別します。
