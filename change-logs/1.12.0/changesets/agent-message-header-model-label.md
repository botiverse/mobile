## zh-CN

在消息流中，Agent 发送的消息头部现在会显示其模型名（如 `Claude Sonnet 4.6`），位于发送者名字之后、徽章/副标题之前，与 Web 端样式一致。人类用户和系统消息不显示该标签。

## en

Agent messages in the conversation flow now show their model name (e.g., `Claude Sonnet 4.6`) in the message header, positioned after the sender name and before any badge or subtitle — matching the Web experience. Human and system messages do not show this label.
