## zh-CN

点击消息流中 Agent 的副标题/描述（Subtitle / Description）时，会以 Brutal 风格的气泡浮层（Anchored Popover）展示完整的描述文本，解决长模型名或较窄屏幕下副标题被截断无法查看的问题。点击屏幕外部或滑动列表即可轻量关闭。

## en

Tapping an Agent's subtitle/description in the message header now opens a Brutal-styled anchored popover displaying the full text. This ensures truncated descriptions can be inspected cleanly regardless of long model names or compact mobile screen widths, dismissing seamlessly on outside tap or list scroll.
