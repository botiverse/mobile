## zh-CN

新版底栏中点击「更多」会弹出任务 / 成员 / 设置菜单，选择后直接进入对应页面；已在「更多」页时再次点击也会重新弹出菜单，不再停留在上次打开的子页面，也不再经过额外的中转页。

## en

In the new bottom navigation, tapping More now opens a Tasks / Members / Settings menu and goes straight to the chosen page. Tapping More again while already on it reopens the menu, so it no longer sticks on the last sub-page or passes through an extra hub screen.
