## zh-CN

新增 XLSX 表格附件预览：打开 .xlsx/.xlsm 附件时直接在文件预览页展示工作表页签与有界表格内容（最多 20 个工作表、每表 200 行 × 20 列）。旧版 .xls 与 ODS 文件仍保持下载兜底。同时文件预览页新增「在浏览器中打开」操作，方便大文件通过系统浏览器下载。

## en

Added XLSX spreadsheet attachment previews: opening .xlsx/.xlsm attachments now shows worksheet tabs and a bounded table preview directly in the file viewer (up to 20 sheets, 200 rows × 20 columns per sheet). Legacy .xls and ODS files keep the download fallback. The file viewer also gains an "Open in browser" action so large files can be downloaded through the system browser.
