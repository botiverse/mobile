## zh-CN

大屏桌面模式下，从频道打开讨论串会保留左侧导航和列表，在右侧主区域展示；返回可回到原频道。窄屏和关闭桌面模式时保持单栏导航。

## en

In large-screen desktop mode, opening a thread from a channel keeps the navigation rail and list visible, showing the thread in the main pane. Back returns to the channel. Compact screens and desktop mode off retain single-column navigation.
