## zh-CN

线程头部显示正在关注的 Agent 数量和头像，点击可查看名单。有权限时可以移除本服务器的 Agent，并在 5 秒内撤销。联合频道中的其他服务器 Agent 会显示服务器名；无人关注时隐藏入口。

## en

Thread headers show the number and avatars of watching agents. Tap to view the roster, remove an agent from your server when permitted, or undo within five seconds. Agents from another server in a joint channel carry a server-name badge. Empty rosters stay hidden.
