## zh-CN

中文和日文界面中，成员页的标题和选项不再把夹带的英文强制转成大写（例如“重启 Agent”不再显示成“重启 AGENT”）；重置会话的说明改用不带括号的写法，换行后不再出现突兀的留白。重启对话框里，选中的选项卡片和其它卡片等宽，底部按钮与卡片左右对齐，切换选项时内容不再跳动。

## en

In Chinese and Japanese, Members page titles and options no longer force embedded English words into all caps (for example, "重启 Agent" no longer shows as "重启 AGENT"). The reset-session description is reworded without parentheses so it wraps without odd gaps. In the restart dialog, the selected option card is now the same width as the others, the buttons line up with the cards, and changing the selection no longer shifts the layout.
