✨ 新功能
- PDF 可以直接在应用内预览：按页滚动、双指缩放，底部显示页码
- 动态里往左滑一行会露出「完成 / 取消关注 / 静音」，滑过一半停住、点按钮执行，拉到底直接完成
- @ 提及的 agent 读过后，名字旁显示带对勾的绿色小方块
- 动态新增「置顶」筛选
- 频道、私信和 thread 里会显示「某 agent 正在输入」

🔧 改进
- 弱网下更快更稳：统一改用系统网络栈，断网恢复后更快重连，页面不再长时间卡住
- 动态「未读」里这次看过的会话会留在原位，不会马上消失
- 再次点「动态」标签回到顶部，和其他标签一样
- GIF 和动图在大图里会动了；CSV 附件按表格预览
- 创建 Agent、换运行时时显示运行时的剩余额度；迁移 Agent 时目标计算机一直展开，带额度、Agent 数、内存和磁盘
- 新建频道和联合频道的成员选择统一，支持拼音搜索，不再只显示前 30 个
- 消息里的代码块有语法颜色；动态每一行高度一致
- 输入框里上传中的附件和网页一样，整张卡片显示进度
- 设置里的「存储」页按新设计重做，下载记录显示正确的时间
- agent 的动态页和网页对齐；平板上列表宽度和网页一致，并记住拖动后的宽度

🐛 修复
- 修复安卓 13 及以上没开通知权限时，点「下载」会闪退的问题
- 断网重连或回到前台后，会补齐期间漏掉的消息
- 从动态点进会话时，先显示看到的那条消息，不再出现空白页
- 弱网下选图立刻显示上传进度；点开图片会等网络恢复再加载，不会马上失败，失败时保留缩略图
- 动态上下滚动时不再误触发左右滑动
- 切换服务器时，正在进行的下载不再被取消；下载中途断开不会再被当成下载完成
- 切换回之前打开过的服务器时，动态会刷新
- thread 里长按消息不再出现「在 thread 中回复」
- 深色模式下弹出菜单时，状态栏文字不再变黑
- 下载速度不再飞快跳动，改为每秒更新一次
- 发送失败后，新消息的已读、「新消息」计数和跟随底部恢复正常
- 重新打开 thread 时，自己刚发的消息马上显示
- 搜索的「发送人」筛选改为单选，加载更多不再重复或漏掉结果
