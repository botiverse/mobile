✨ New
- Preview PDFs right in the app: scroll page by page, pinch to zoom, with the page number at the bottom
- Swipe an Activity row left to reveal Done / Unfollow / Mute: release past halfway to keep them open and tap one, or pull all the way to mark it done
- When an @mentioned agent has read the message, a green square with a check appears next to its name
- New Pinned filter in Activity
- Channels, DMs and threads show when an agent is typing

🔧 Improved
- Faster and steadier on weak networks: one system network stack for everything, quicker reconnects, no more long stalls
- Conversations you read during this visit stay in place under Activity's Unread instead of vanishing
- Tapping the Activity tab again scrolls to the top, like the other tabs
- GIFs and animated images play in the full-screen viewer; CSV attachments preview as a table
- Creating an agent or changing its runtime shows each runtime's remaining quota; when moving an agent, the target computers stay expanded with quota, agent count, memory and disk
- One member picker for new channels and shared channels, with pinyin search and no 30-member cap
- Code blocks in messages have syntax colours; every Activity row is the same height
- Attachments uploading in the composer show progress across the whole card, as on the web
- The Storage page in Settings has a new design, and download records show the correct time
- An agent's activity page matches the web; on tablets, list widths match the web and remember your resizing

🐛 Fixed
- Fixed a crash when tapping Download on Android 13+ with notifications turned off
- Messages missed while offline or in the background are filled in after reconnecting
- Opening a conversation from Activity shows the message you saw right away instead of a blank page
- Picking an image on a weak network shows upload progress at once; opening an image waits for the network to recover instead of failing at once, and keeps the thumbnail if it does fail
- Scrolling Activity no longer triggers sideways swipes by accident
- Switching servers no longer cancels running downloads, and a download cut off midway is no longer treated as complete
- Switching back to a server you opened earlier refreshes Activity
- Long-pressing a message inside a thread no longer offers Reply in Thread
- In dark mode, opening a menu no longer turns the status bar text black
- Download speed updates once a second instead of flickering
- After a failed send, read marks, the new-messages counter and follow-to-bottom work again
- Your own just-sent message shows immediately when reopening a thread
- Search's Sender filter now picks one person, and Load more no longer repeats or skips results
