✨ 新機能
- PDF をアプリ内でプレビューできるようになりました：ページごとのスクロール、ピンチでズーム、下部にページ番号を表示
- アクティビティの行を左にスワイプすると「完了 / フォロー解除 / ミュート」が表示されます。半分を超えて離すと開いたままになり、ボタンをタップして実行。最後まで引くとそのまま完了
- @メンションした agent が読むと、名前の横にチェック付きの緑の四角が表示されます
- アクティビティに「ピン留め」フィルターを追加
- チャンネル、DM、スレッドで「agent が入力中」を表示

🔧 改善
- 弱いネットワークでもより速く安定：システムのネットワークスタックに統一し、再接続が速く、長時間止まらなくなりました
- アクティビティの「未読」で今回見た会話はその場に残り、すぐには消えません
- 「アクティビティ」タブをもう一度タップすると、他のタブと同じく先頭に戻ります
- GIF やアニメーション画像が拡大表示で動くようになり、CSV 添付は表で表示されます
- Agent の作成やランタイム変更時に各ランタイムの残りクォータを表示。Agent の移動時は移動先コンピューターが常に展開され、クォータ、Agent 数、メモリ、ディスクを表示
- 新規チャンネルと共有チャンネルのメンバー選択を統一。ピンイン検索に対応し、30 人までの制限もなくなりました
- メッセージ内のコードブロックにシンタックスカラーを表示。アクティビティの各行の高さを統一
- 入力欄でアップロード中の添付ファイルは、Web と同じくカード全体に進捗を表示
- 設定の「ストレージ」ページを新デザインに刷新し、ダウンロード履歴の時刻を正しく表示
- agent のアクティビティページを Web に合わせました。タブレットではリスト幅が Web と同じになり、変更した幅を記憶します

🐛 修正
- Android 13 以降で通知がオフのとき、「ダウンロード」をタップするとアプリが落ちる問題を修正
- 再接続後やフォアグラウンドに戻った後、その間に届いたメッセージを補完します
- アクティビティから会話を開くと、見ていたメッセージがすぐ表示され、空白ページになりません
- 弱いネットワークで画像を選ぶとすぐにアップロード進捗を表示。画像を開くとネットワークの回復を待って読み込み、すぐには失敗しません。失敗した場合もサムネイルを残します
- アクティビティを上下にスクロールしても、誤って横スワイプにならなくなりました
- サーバーを切り替えても実行中のダウンロードがキャンセルされなくなり、途中で切れたダウンロードが完了扱いにならなくなりました
- 以前開いたサーバーに戻るとアクティビティが更新されます
- スレッド内でメッセージを長押ししても「スレッドで返信」が表示されなくなりました
- ダークモードでメニューを開いてもステータスバーの文字が黒くならなくなりました
- ダウンロード速度が激しく変動せず、1 秒ごとに更新されます
- 送信失敗後も、既読、「新着メッセージ」の件数、最下部への追従が正しく動作します
- スレッドを開き直すと、自分が送ったばかりのメッセージがすぐ表示されます
- 検索の「送信者」フィルターは 1 人のみ選択に変更。「さらに読み込む」で重複や抜けがなくなりました
