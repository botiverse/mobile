✨ **新功能**
- 统一网页面板：在对话里点开第三方链接、已安装的 Raft 应用链接或应用卡片，会从屏幕底部拉起统一网页面板（顶部保留一行变淡的原消息提示，可上拉全屏，下拉或点按原消息行回到对话并保持页面打开，原消息下会显示「页面仍打开」）；第三方网页与 Raft 应用使用互相隔离的存储空间。
- 系统「分享到 Raft」与最近会话建议：新增系统分享扩展，支持从微信、相册、文件、Safari 等应用把文字、链接、图片、视频及任意文件（含 `.zip`）直接分享进 Raft 的频道、私信、消息列或任务；系统分享面板顶部还会展示最近活跃的频道与私信建议，点选即可直达预填输入框，退出登录或切换账户时自动清理。
- 全类型文件分享与下载直开：图片、视频、文档和普通文件预览的右上角菜单都新增「分享」，未缓存的文件会先下载再调起系统分享面板；下载完成后，底部提示附带「打开」按钮，离开当前页面也能直接打开已保存的文件。
- Agent「应用」标签页与撤销访问：每个应用只占一行并说明它能做什么；服务器所有者、管理员和 Agent 创建者可一键撤销应用的全部授权，或在「详情」中逐项撤销。
- Agent 迁移记录与图表：服务器所有者和管理员可在 Agent 资料页或计算机详情页打开「查看迁移记录」，通过可缩放交互图表和筛选列表查看 Agent 在计算机间的迁移历史，并可点右侧的 × 关闭失败迁移提示。
- 离线计算机恢复指引：当 Agent 所在的计算机离线时，Agent 资料页会显示与网页版一致的恢复卡片，标明离线计算机与离线时间，并提供两步恢复指引及可一键复制的重启命令。
- 公告原生提问面板：点按公告中的「发给 Agent」链接会直接拉起原生发送面板，自动推荐合适的 Agent 并预览最近私信，修改提示词后可直接私信发送并进入会话。
- iPad 分栏记忆：在 iPad 上，每个会话都会在本机记住旁边打开的消息列、Artifact（含固定版本）或资料（含 Agent 所在标签页），切换会话或返回时自动恢复。

🔧 **改进**
- Artifacts 主页与查看器：全新对齐网页版布局，采用紧凑 16:10 网格卡片与带缩略图的列表行、可折叠「与你相关」与日期分组、按服务器记住的「会话 / 作者 / 状态 / 与你相关」筛选工具栏，以及长按/右键将 Artifact 标为定稿或取消定稿；在查看器中无需切到桌面模式即可双指捏合缩放，移除了多余的「在浏览器中打开」按钮，Artifact 回退页支持带登录态直接打开。
- 任务列表与任务会话头：任务列表改用与网页版一致的紧凑行，手机一屏能看到更多任务；任务会话短对话直接从顶部起排，状态与负责人同排显示，负责人显示头像和姓名（自己显示为「你」），补齐「来源：未记录」与「回复的开头」。
- 设置、外观与账户：「设置 › 外观」合并为更简洁的单分组，在 Mac 上运行的 iPad 应用或连接硬件键盘时新增与账户同步的「发送消息的按键」（Enter 或 ⌘Enter / Ctrl+Enter）；「设置 › 账户」将修改/设置密码移到资料卡正下方，「连接的账户」独立分组，「产品分析」移至「会话」之前。
- iPad、宽屏与横屏空间优化：统一手机与 iPad 的宽屏切换宽度，iPad 触控时采用更易读的正文字号；宽屏触控页头收矮为更紧凑的单行（56 → 48）并统一对齐分栏顶部水平分隔线，宽屏「任务」顶栏改用白底、「Artifacts」标题与计数同行显示、「成员」分栏去掉多余返回箭头，且宽屏任务待处理项直接在右栏展开；横屏避开左右安全区，iPhone Duo 横屏右侧竖列最多直接展示 4 个页面操作并保留底部安全区，去掉输入框与加入频道按钮在底部安全区之上重复叠加的留白以提升可视区域，搜索面板自动避让软键盘且切换左侧栏自动收起键盘；所有侧栏标题栏末尾统一显示关闭按钮（×），触控拖动左侧列表边缘不易误收起，可搜索的选择列表在宽屏下直接在按钮下方展开。
- 动态、GIF、Mermaid 与菜单顺序：手机端「动态」每行改为单行预览，iPad 触控不再常驻「标为完成」按钮；新发 GIF 支持在会话内自动播放并离屏暂停；Mermaid 图表改用正文字体排版并支持换行与更丰富的格式；新增 🍻 回应贴纸并为全部 8 枚贴纸补充深色模式彩色描边；统一各处长按与「⋯」菜单顺序和英文句首大写文案；在标为未读的会话里发消息会自动消除未读状态。
- 更快更省流：聊天图片批量解析链接并增强本地磁盘缓存，重启应用首帧即可直接显示真实头像与服务器图标；离线和弱网下按视口分页读取本地消息并显示未同步区间提示；断线重连和网络恢复时静默补拉，长连接未断且 60 秒内回前台跳过重复刷新；减轻切回首页时的滑动掉帧并加速高分辨率照片预览和编辑解码。
- Agent、计算机与外部频道：创建与编辑运行时优先读取各台计算机上报的实时能力；精简「添加计算机」弹窗并直达连接命令，移除移动端独有的「计算机离线提醒」开关与首页离线提醒以对齐网页版；对齐 Agent 资料页信息排布、悬停资料卡与表单稳定留白；频道成员页直达「邀请外部人员」，「连接你的服务器」支持免费版名额校验，并统一全应用「外部频道」文案。
- 更多交互细节：无法直接预览的文件底栏改为「在其他应用中打开」；硬件键盘在输入框输入 `@` / `#` 可用方向键、Enter/Tab 与 Esc 顺畅选人选频道；搜索与悬浮工具栏支持鼠标悬停提示；复制反馈单链接时一并附带单行摘要；迁移记录手机端「图表 / 表格」切换固定在右侧；统一下载中心托管并对齐各页面空状态样式。
