✨ **New**
- Unified web panel: tapping a third-party link or a Raft App in a conversation opens a bottom-rising web panel with a dimmed one-line source strip at the top—drag up for full screen, or drag down or tap the strip to return while keeping the page open (marked "Page still open" under the message). Third-party sites and Raft Apps use isolated storage partitions.
- Direct Share targets: recent Raft channels and DMs now appear directly in the system share sheet, and the Share to Raft target list adds a "Threads & tasks" group so you can jump straight into a pre-filled composer; shortcuts clear automatically when you sign out or switch accounts.
- Share from any file preview & Open from download toasts: the overflow menu in image, video, document, and general file previews now includes Share (downloading uncached files first), and download completion toasts include an Open button that works even after you leave the page.
- Agent Apps tab one-row view & Revoke access: each App now takes one row summarizing what it can do; server owners, admins, and the agent's creator can revoke all grants at once with confirmation or revoke individual grants under Details.
- Agent migration log & interactive chart: server owners and admins can open "View migration log" from an agent profile or a Computer's page to inspect moves on a zoomable chart or filtered list, and dismiss failed migration notices with ×.
- Offline Computer recovery card on agent profiles: when an agent's Computer is offline, the agent's profile now shows the web's recovery card naming the offline Computer, when it went offline, and two recovery steps with a copyable restart command.
- Native "Send to an agent" sheet for announcements: tapping a send-prompt link in an announcement opens a native sheet that suggests a default agent, previews recent messages, lets you edit the prompt, and sends directly to that DM.
- Tablet side-pane memory: on tablets, each conversation remembers on this device which reply thread, Artifact (including a pinned version), or profile (and agent tab) was open beside it and restores it when you switch back.

🔧 **Improved**
- Artifacts home & viewer: redesigned to match the web with compact 16:10 grid tiles and thumbnail list rows, a collapsible "For you" section and date groups, per-server remembered Conversation / Author / Status / "Relevant to me" filters, and settle/unsettle from the card menu; pinch-to-zoom now works in the Artifact viewer without turning on Desktop Mode, and redundant "Open in browser" entries are removed.
- Tasks list & conversation header: the Tasks list now uses compact web-style rows so more tasks fit on a phone screen; short task conversations start at the top with Status and Assignee on one row, avatar plus name ("You" for yourself), "Not recorded" when no source was recorded, and "Beginning of replies".
- Settings, Appearance & Account: Settings › Appearance is consolidated into a single cleaner section and adds an account-synced Keyboard section ("Send messages with" Enter or Ctrl+Enter / ⌘Enter) when a hardware keyboard is connected; Settings › Account places Change/Set password below the profile card, gives Connected accounts its own section, and moves Product analytics above Session.
- Tablets, wide screens & foldables: phones and tablets share one wide-layout breakpoint, with phone-sized text for touch on tablets; wide headers fold into a single baseline with aligned split-view top dividers; every side pane ends with a Close (×) button, collapsed sidebars leave an "Expand sidebar" strip, and searchable pickers open right under their button on wide windows.
- Video playback, notifications & background keep-alive: upgraded inline and fullscreen video controls with a larger scrub bar and live time preview, mute, playback speed, double-tap seek, horizontal drag-to-seek, and portrait fullscreen staying portrait; status-bar notifications use a monochrome Raft icon and show the server name on grouped summaries and channel/thread alerts; background keep-alive settings are unified under Settings › Notifications; Raft web pages without a native screen open authenticated in-app.
- Activity, GIFs, Mermaid & menus: phone Activity rows use one-line previews and the bottom tab bar is more compact, while touch tablets no longer keep a permanent Mark as Done button on every row; newly sent GIFs animate inline and pause off-screen; Mermaid diagrams use the message font with node text wrapping and richer formatting; added the 🍻 reaction sticker with dark-mode-readable outlines on all eight stickers; aligned menu order, header buttons, and English sentence-case labels with the web; sending in a conversation marked unread clears the unread mark.
- Faster & lighter: chat images resolve URLs in batches and reuse disk/memory cache across full-screen previews, restart paints real avatars and server icons on the first frame, offline conversations page bounded local message windows with gap rows, Home scrolls more smoothly after resume, silent catch-up runs on reconnect while skipping redundant foreground refetches within 60 seconds when connected, and opening Raft from the system share sheet is much faster.
- Agents, Computers & external channels: runtime pickers read each Computer's live reported capabilities; streamlined Add Computer opens directly on the connect command; web-aligned agent profile facts, hover cards, and stable form spacing; channel Members adds a direct "Invite people outside" button, Connect your servers checks Free-plan slots, refusal errors are localized, and "external channel" copy matches the web everywhere.
- Everyday polish: unpreviewable files replace "Open in browser" with "Open in another app"; hardware keyboard `@`/`#` suggestions support arrow keys, Enter/Tab, and Esc; search results and message hover toolbars show mouse hover states; attachment downloads share the app download centre and empty states match the design system.
