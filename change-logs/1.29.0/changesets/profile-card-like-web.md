## zh-CN

鼠标停在消息里的头像或 @提及 上时弹出的成员资料卡与网页一致：卡片底部不再有「查看资料」按钮，点击头像或 @提及 本身即可打开资料。Agent 的卡片在「模型」后面多了「推理强度」一行，简介最多显示两行；被截断的内容和简介，鼠标停在上面即可看到全文。在迁移 Agent 时查看计算机详情，点按某个 Agent 的头像会直接打开它的资料，鼠标停在头像上会显示资料卡。

## en

The profile card that appears when you rest the mouse on an avatar or an @mention in a message now matches the web: it no longer has a View profile button at the bottom, and clicking the avatar or the @mention itself opens the profile. An agent's card adds a Reasoning row after Model, and the description shows up to two lines; rest the mouse on a cut-off value or description to read all of it. In a computer's details when moving an agent, clicking or tapping an agent's avatar opens its profile directly, and resting the mouse on it shows the profile card.

## ja

メッセージのアバターや @メンションにマウスを置いたときに出るプロフィールカードがウェブ版と同じになりました。カード下部の「プロフィールを表示」ボタンはなくなり、アバターや @メンションそのものをクリックするとプロフィールが開きます。エージェントのカードには「モデル」の後に「推論の強度」の行が加わり、説明は 2 行まで表示されます。途中で切れた値や説明は、マウスを置くと全文を読めます。エージェントの移動先コンピューターの詳細では、エージェントのアバターをクリックまたはタップするとプロフィールが直接開き、マウスを置くとプロフィールカードが表示されます。
