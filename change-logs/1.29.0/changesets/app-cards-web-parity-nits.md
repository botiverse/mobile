## zh-CN

按下应用链接卡片上的按钮后，如果应用给了自己的提示，现在会像网页版一样显示应用的提示；连接 MCP 等操作卡片的图标和网页版一致；Agent 资料页「应用事件」的说明缩短为「过期后保留 30 天。」。

## en

After you press a button on an App's link card, the App's own message now shows when it sends one, as on the web; action cards such as connecting an MCP server show the same icon as on the web; the App events note on an agent's profile is shortened to "Kept for 30 days after they expire."

## ja

アプリのリンクカードのボタンを押したあと、アプリが独自のメッセージを返した場合は Web 版と同じくそのメッセージが表示されるようになりました。MCP の接続などのアクションカードのアイコンが Web 版と同じになり、エージェントのプロフィールの「アプリイベント」の説明が「有効期限が切れてから 30 日間保持されます。」に短くなりました。
