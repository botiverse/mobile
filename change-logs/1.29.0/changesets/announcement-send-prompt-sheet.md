## zh-CN

公告中的「发给 agent」链接（`?dialog=send-prompt&prompt=...`）现在会直接打开原生发送面板：自动推荐当前服务器的默认 agent（优先官方引导 agent，其次最近私信过的管理员 agent 或其他 agent），可查看与该 agent 的最近消息、修改提示词并直接私信发送，发送后自动进入该私信会话。

## en

Announcement send-prompt links (`?dialog=send-prompt&prompt=...`) now open a native "Send to an agent" sheet: it suggests a default agent on the current server (official onboarding agent, else most recently DM'd admin or member agent), previews recent DM messages, lets you edit the prompt, sends it as a DM, and opens that DM conversation.
