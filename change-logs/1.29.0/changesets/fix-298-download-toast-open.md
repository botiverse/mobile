## zh-CN

在 Android 和 iOS 上下载消息文件附件或 Artifact 文件后，完成提示现在会附带“打开”按钮，点一下即可直接拉起系统可处理该文件的应用打开；即使刚离开当前页面再点提示上的“打开”，也能照常打开已保存的文件。

## en

After downloading a message attachment or an Artifact file on Android or iOS, the completion toast now includes an "Open" button that opens the saved file with a system app that can handle it, even if you have already left the page before tapping it.

## ja

Android および iOS でメッセージの添付ファイルや Artifact ファイルをダウンロードしたあと、完了トーストに「開く」ボタンが表示されるようになりました。タップすると保存済みファイルを対応するシステムアプリですぐに開け、ページを離れた直後にタップした場合もそのまま開けます。
