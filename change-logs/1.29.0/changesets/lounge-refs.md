## zh-CN

消息中的 lounge:@agent，以及指向该会客厅里讨论串、任务或某条消息的引用，现在会显示为可点按的引用，点按即打开该 Agent 的会客厅中的对应位置。引用按 Agent 当前的名字识别；对不上任何 Agent 时保持为普通文字，也不会变成对该 Agent 的 @提及。

## en

lounge:@agent references in messages, and references to a thread, task or message in that Lounge, are now tappable and open that place in the agent's Lounge. They follow the agent's current name; one that names no agent stays plain text and never turns into an @mention of the agent.

## ja

メッセージ内の lounge:@agent と、そのラウンジのスレッド・タスク・メッセージへの参照がタップできるようになり、Agent のラウンジの該当箇所を開きます。参照は Agent の現在の名前で判定され、どの Agent にも当たらない場合は通常のテキストのままで、その Agent への @メンションにもなりません。
