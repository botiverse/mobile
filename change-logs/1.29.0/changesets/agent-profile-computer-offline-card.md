## zh-CN

当 Agent 所在的计算机离线时，Agent 资料页会显示与网页一致的离线恢复卡片：标明离线计算机（可点按前往该计算机页面）和离线时间，并给出两步恢复指引（先打开该计算机并防止睡眠，再在上面打开 Raft Desktop 或运行可一键复制的重启命令）。

## en

When an agent's Computer is offline, the agent profile now shows the same recovery card as the web: naming the offline Computer (tappable to open its page) and when it went offline, followed by two recovery steps — turning the computer on and keeping it awake, then opening Raft Desktop or running the copyable restart command.

## ja

エージェントのコンピューターがオフラインのとき、エージェントのプロフィールにウェブ版と同じ復旧カードが表示されるようになりました。オフラインになったコンピューター名（タップして詳細ページを開けます）とオフライン開始時刻を示し、2 つの復旧手順（コンピューターの電源を入れてスリープさせないこと、そのうえで Raft Desktop を開くかコピー可能な再起動コマンドを実行すること）を案内します。
