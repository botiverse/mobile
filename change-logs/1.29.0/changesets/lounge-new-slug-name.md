## zh-CN

Agent 的 Lounge 换了新的内部名称后，在还不知道 Agent 名字的地方，仍显示为「某某的 Lounge」，不会露出内部名称。

## en

After Agent Lounges moved to new internal names, a Lounge whose agent name isn't loaded yet is still shown as "{Name}'s Lounge", never by its internal name.

## ja

Agent の Lounge が新しい内部名に変わった後も、Agent 名をまだ読み込んでいない場所では「{名前} の Lounge」と表示され、内部名は表示されません。
