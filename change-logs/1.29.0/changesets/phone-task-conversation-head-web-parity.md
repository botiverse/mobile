## zh-CN
对齐手机端任务会话顶部信息与网页端：短对话内容直接从顶部开始不再留出大片空白，状态与负责人同排显示，负责人改为头像加姓名（分配给自己时显示为「你」），补齐「来源」的「未记录」状态，「创建人」改为纯文本展示，会话起点文案改为「回复的开头」。

## en
Aligned the task conversation header with the web: short conversations now start at the top without blank space above the header, Status and Assignee sit on one row, Assignee shows an avatar and name ("You" when assigned to yourself), Source displays "Not recorded" when no source message was recorded, "Created by" renders as plain text, and the top boundary copy now reads "Beginning of replies".

## ja
タスク会話ヘッダーを Web 版に揃えました。短い会話でも先頭の上部に余白が出ないよう上から配置し、ステータスと担当者を 1 行に並べて表示します。担当者はアバターと名前（自分の場合は「あなた」）で表示し、ソース未記録時は「記録なし」を表示、作成者はプレーンテキスト表示、先頭ラベルは「返信の先頭」に統一しました。
