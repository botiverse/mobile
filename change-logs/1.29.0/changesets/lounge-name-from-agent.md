## zh-CN

Agent 的会客厅一律以 Agent 当前的名字命名；还不知道名字时显示为「会客厅」，不再从会客厅的内部名称推测名字，也不会露出内部名称。

## en

An agent's Lounge is always named after the agent's current name. While that name isn't known yet it reads "Lounge": no name is guessed from the Lounge's internal name, and the internal name never shows.

## ja

Agent のラウンジは常に Agent の現在の名前で表示されます。名前がまだ分からない間は「ラウンジ」と表示し、ラウンジの内部名から名前を推測したり、内部名を表示したりすることはありません。
