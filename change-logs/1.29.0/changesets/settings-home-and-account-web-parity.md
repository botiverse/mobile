## zh-CN
对齐设置与账户页布局与网页端：账户页将「修改密码」（或未设密码时的「设置密码」）移至个人资料卡正下方并补齐设备登录失效提示，「已连接账户」拆为独立分组与合并行列表，将「产品分析」调整到「会话」之前并补齐分组标题与「删除账户」按钮图标；同时将宽屏设置侧边栏的分组间距与外链箭头尺寸对齐网页规范。

## en
Aligned the Settings and Account pages with the web: moved Change password (or Set a password) directly below the profile card with the device-login notice, gave Connected accounts its own section with grouped list rows, placed Product analytics above Session with its section header and added the trash icon to Delete account, and matched the wide Settings sidebar group spacing and external-link icon size to the web.

## ja
設定およびアカウント画面のレイアウトを Web 版に揃えました。アカウント画面では「パスワードを変更」（未設定時は「パスワードを設定」）をプロフィールカードの直下に移動し、デバイスログイン失効の注意バナーを追加。「連携アカウント」を独立セクションとグループ行に分離し、「プロダクト分析」を「セッション」の前に配置して見出しを追加、アカウント削除ボタンにアイコンを付けました。あわせてワイド画面の設定サイドバーのグループ余白と外部リンクアイコンサイズも Web に統一しました。
