## zh-CN

在消息中右键点击 Artifact 卡片（或聚焦卡片后按 Shift+F10 / 菜单键），现在会打开该 Artifact 自己的菜单（打开、复制链接），不再打开消息菜单；触控长按、多选模式及已删除卡片仍保留消息菜单。同时移除了 Artifact 卡片、Artifact 查看器及应用内 Raft 网页中多余的「在新页面打开 / 在浏览器中打开」入口。

## en

Right-clicking an Artifact card in a message (or pressing Shift+F10 / the ContextMenu key while focused) now opens the Artifact's own menu (Open, Copy link) instead of the message menu, while touch long-press, select mode, and deleted cards keep the message menu. Also removed the redundant "Open in new page / Open in browser" buttons from Artifact cards, the in-app Artifact viewer, and embedded Raft web pages.

## ja

メッセージ内の Artifact カードを右クリック（またはフォーカス中に Shift+F10 / メニューキーを押下）すると、メッセージメニューではなく Artifact 自身のメニュー（開く、リンクをコピー）が開くようになりました（タッチ長押し・選択モード・削除済みカードでは従来どおりメッセージメニューが開きます）。あわせて、Artifact カード・Artifact ビューア・アプリ内 Raft ウェブページの不要な「新しいページで開く / ブラウザで開く」ボタンを削除しました。
