## zh-CN

「已保存」列表的样式和网页版一致：行与行之间稍有间隔，选中行的高亮改为两侧内缩的圆角。频道名和发送者名称过长时会一起截断并显示省略号，「消息列」标记和时间始终完整显示。

## en

Saved rows now look like the web's list: rows sit slightly apart, and the selected row's highlight is a rounded shape set in from the edges. Long channel and sender names now shorten together with an ellipsis, so the Thread label and the time always show in full.
