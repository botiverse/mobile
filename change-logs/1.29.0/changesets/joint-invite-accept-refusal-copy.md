## zh-CN
- 接受外部频道邀请被拒绝时，找不到邀请、无管理员权限、邀请已不可接受、频道已归档四种情况不再直接显示英文提示，而是按当前语言显示对应说明并保留 Trace ID。

## en
- Accepting an external channel invite now shows localized explanations (with Trace ID) instead of raw server messages when the invite is not found, requires a server admin, is no longer acceptable, or the channel is archived.

## ja
- 外部チャンネルの招待を承諾できなかった場合（招待が見つからない・サーバー管理者権限がない・承諾できない状態・アーカイブ済みチャンネル）、サーバーの英語文ではなく各言語の説明文（Trace ID 付き）を表示するようにしました。
