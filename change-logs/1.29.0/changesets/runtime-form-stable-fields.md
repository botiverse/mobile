## zh-CN

Agent 运行时设置的各个字段和网页一致：每个字段下面固定留一行提示，出现错误时下面的字段不再跳动；列表旁的刷新按钮和网页一样大。创建 Agent 时额度已满的提示里，「升级以获得更多」不再从中间断行。

## en

The agent runtime settings match the web: every field keeps a line for its message, so an error no longer moves the fields below it, and a list's refresh button is the web's size. In the create-agent limit notice, "Upgrade for more" no longer breaks across two lines.
