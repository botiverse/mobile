## zh-CN

没有 Agent 在会话里工作或输入时，最新一条消息下方不再多留一行空白，与网页一致。「N 个 Agent 正在这里工作」或「… 正在输入…」出现时，停在最新消息处的列表会随之上移，最新消息完整显示在这一行上方，这一行消失后再回到原处；已经向上翻看较早的消息时，屏幕上的消息不会移动。

## en

While no agent is working or typing in a conversation, the newest message no longer has an extra line of blank space under it, as on the web. When "N agents working here" or "… is typing…" appears, a list resting at the newest message moves up with it so the newest message stays whole above that line, and moves back down when the line goes; if you have scrolled up to earlier messages, nothing on screen moves.

## ja

会話でエージェントが作業中・入力中でないときは、Web と同じく、最新メッセージの下に余分な 1 行分の余白が残らなくなりました。「エージェント N 個がここで作業中」や「…が入力中…」が表示されると、最新メッセージの位置にある一覧はそれに合わせて上に動き、最新メッセージがこの行の上に欠けずに表示されます。行が消えると元の位置に戻ります。以前のメッセージまでスクロールしている場合、画面上のメッセージは動きません。
