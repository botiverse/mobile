## zh-CN

“设置 › 外观”现在与网页版保持一致：合并为单一“外观”分组，去掉每项下方的冗余说明文字与底部“已保存到此设备”提示，消息字号与预览紧密连接在同一卡片中。在电脑版、运行在 Mac 上的 iPad 应用以及连接了硬件键盘的移动设备上，“外观”页新增与网页版一致的“键盘”分组，可选择“发送消息的按键”（Enter 或 ⌘Enter / Ctrl+Enter，随账户同步）；切换为 ⌘Enter / Ctrl+Enter 后，按 Enter 换行、按 ⌘Enter / Ctrl+Enter 发送，输入框工具栏在输入时也会显示对应的发送快捷键提示。未连接硬件键盘的纯触控手机不会显示该硬件键盘分组。

## en

Settings › Appearance now matches the web layout: items are consolidated into a single Appearance section without per-item descriptions or the "Saved on this device." footer, with the message font size control and live preview attached in one group. On Compose desktop, the iPad app on Mac, and mobile devices with a hardware keyboard connected, Appearance adds the Keyboard section with the account-synced "Send messages with" option (Enter or ⌘Enter / Ctrl+Enter) alongside Keyboard shortcuts; in ⌘Enter / Ctrl+Enter mode, Enter inserts a newline, ⌘Enter / Ctrl+Enter sends, and the composer shows a subtle send-key hint while typing. Touch-only mobile devices without a hardware keyboard keep the hardware Keyboard section hidden.

## ja

「設定 › 外観」がウェブ版と同じ構成になりました。すべての項目を 1 つの「外観」セクションにまとめ、各項目ごとの説明文や下部の「このデバイスに保存されます。」の表示を省き、メッセージの文字サイズとプレビューを 1 つのグループ内でつなげて表示します。デスクトップ版、Mac 上の iPad アプリ、およびハードウェアキーボードを接続したモバイル端末では、ウェブ版と同じ「キーボード」セクションを追加し、アカウント間で同期される「メッセージの送信キー」（Enter または ⌘Enter / Ctrl+Enter）とキーボードショートカットを表示します。⌘Enter / Ctrl+Enter モードでは Enter で改行、⌘Enter / Ctrl+Enter で送信でき、入力中には送信キーのヒントも表示されます。ハードウェアキーボードを接続していないタッチ操作のみのモバイル端末では表示されません。
