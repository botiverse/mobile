## zh-CN

服务器所有者和管理员可以看 Agent 的迁移记录：在 Agent 资料页或计算机详情页点「查看迁移记录」，按 Agent、计算机、结果和时间筛选，也可以搜索计算机或 Agent。

## en

Server owners and admins can see where agents have moved: open "View migration log" on an agent's profile or a computer's page, filter by agent, computer, result and time, or search computers and agents.

## ja

サーバーのオーナーと管理者は、エージェントの移行の記録を確認できます。エージェントのプロフィールまたはコンピューターの詳細で「移行記録を見る」を開き、エージェント、コンピューター、結果、期間で絞り込んだり、コンピューターやエージェントを検索したりできます。
