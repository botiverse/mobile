## zh-CN

修复宽屏布局下在「任务」页点击尚无讨论的待办任务时，错误弹出全屏窗口并显示返回箭头的问题；现在与其他任务一样直接在列表右侧栏打开，标题栏末尾显示「展开」和关闭按钮（×），点击左侧列表中的其他任务可直接切换。

## en

Fixed an issue in the wide layout where opening a task with no discussion yet from the Tasks page opened a full-screen overlay with a Back button instead of the right-hand task column; it now opens beside the Tasks list with Expand and Close (×) controls and switches cleanly when tapping another task in the list.
