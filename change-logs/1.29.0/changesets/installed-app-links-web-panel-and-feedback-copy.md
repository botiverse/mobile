## zh-CN

修复消息中已安装的 Raft App 链接（如 Stamp 链接及链接卡片中的跨源按钮）意外跳转到系统浏览器的问题，现在会直接在从底部升起的统一网页面板中打开；同时，在反馈工单详情中点击「复制链接」时，剪贴板内容现在会一并附带截断后的反馈摘要与链接。

## en

Fixed links to installed Raft Apps in chat (including plain/labelled message links and cross-origin buttons on App link cards such as Stamp) opening in the external system browser instead of the unified bottom-rising web panel; copying a feedback ticket link now also includes a truncated single-line excerpt of the feedback message above the URL.

## ja

チャット内のインストール済み Raft アプリへのリンク（通常のメッセージリンクや Stamp などのアプリリンクカード上のクロスオリジンボタン）が外部ブラウザーで開かれてしまう問題を修正し、画面下から立ち上がる統一 Web パネルで開くようにしました。また、フィードバックチケットの「リンクをコピー」では、URL の上にフィードバック本文の短い要約も併せてコピーされるようになりました。
