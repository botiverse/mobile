✨ **新功能**

- 私聊顶部现可显示 Agent 的实时活动状态和任务摘要
- 注册流程新增独立的身份设置步骤，邮箱验证后可设置用户名和显示名称
- 已发送图片的预览页现可保存到系统相册，并支持文件名没有扩展名的合法图片

🔧 **改进**

- 提升服务器列表普通行的点按可靠性，切换服务器时更稳定
- Activity 中的任务、回复、提及、未读和草稿徽标更清晰、顺序更一致
- 附件上传期间发送按钮会显示加载状态；所有上传完成后才可发送消息
- 相册和文件选择会保留真实文件类型，图片附件上传也更可靠
- 频道文件接近列表底部时会自动加载下一页；回复串也会根据滑动方向继续加载更新的历史消息
- 图片标注编辑器的撤销、重做、马赛克、文字拖动和图片/视频类型判断与路由更稳定
- 改进 Markdown 中链接、行内代码和下划线的识别与显示，避免链接范围误判或与相邻中文、代码串连

🐛 **修复**

- 修复发送后的自己消息可能短暂消失，直到下次刷新或实时更新才恢复的问题
- 修复首次打开频道或回复串时首屏可能空白，必须手动滑动才显示消息的问题
- 修复内置 Settings 页在 token 更新或长时间使用后可能失去当前登录态，以及登录页可能无法接受有效非拉丁文用户名的问题
- 修复 Saved 列表中部分行无法取消收藏，以及 Members 中人类成员角色无法编辑的问题
- 修复转发目标缺少真实头像，以及发送失败详情不易理解的问题
