## zh-CN

设置 › 主题的「由你的助理更改」现在仅显示主题与边框装饰变更，侧边栏移动、置顶与整理记录归入助理「最近的更改」与外观 › 助理。

## en

Settings › Theme now lists only assistant changes to the server theme and border art; sidebar move, pin, and arrange entries move to the assistant's Recent changes and Appearance › Assistant.

## ja

「設定 › テーマ」のアシスタント変更履歴にテーマと枠装飾の変更のみを表示するよう調整し、サイドバーの移動・固定・並び替え履歴はアシスタントの最近の変更および「外観 › アシスタント」にまとめました。
