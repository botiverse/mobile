## zh-CN

优化了主页侧边栏与对话顶栏中的 Agent 未读提示：侧边栏合并后的 Agent 行现在会按边分别显示未读数（私聊带锁图标，会客厅带沙发图标，两边都有未读时并排展示；未归属到任一边的未读仍显示纯总数），点击仍按上次打开的一边进入；对话顶栏头像切换按钮在另一边有未读时，改为在头像右上角直接显示未读数贴纸并在无障碍与悬停提示中标明具体位置（私聊或会客厅）。

## en

Agent sidebar rows and conversation headers now show which side (Private chat vs Lounge) unread messages are on. Merged agent rows display one unread count per side with unread messages—Private chat after a lock icon and Lounge after the sofa icon, side by side when both have unread (or a plain total with no side icon if unread belongs to neither side)—while keeping click behavior unchanged. In the conversation header, the avatar switcher now displays the other side's unread count as a compact sticker on the top corner of the avatar (replacing the corner dot) with side-specific tooltip and accessibility labels across all locales.

## ja

エージェントのサイドバー行と会話ヘッダーで、未読メッセージがどちら側（プライベートチャットかラウンジか）にあるかが分かるようになりました。統合されたエージェント行では未読がある側ごとに件数を表示し（プライベートチャットは鍵アイコン、ラウンジはソファアイコン、両方ある場合は並べて表示、どちらにも属さない未読はアイコンなしの合計件数）、タップ時の動作は従来どおりです。会話ヘッダーの切り替えボタンでは、反対側に未読がある場合にアバター右上に件数バッジを表示し、ツールチップとアクセシビリティラベルでも側を明示します。
