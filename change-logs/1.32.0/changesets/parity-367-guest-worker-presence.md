## zh-CN

访客（Guest）查看正在运行 Worker 的 Agent 时，现在仅显示运行状态（「正通过 Worker 工作」），不再展示具体的 Worker 数量。

## en

Guests viewing an agent with running Workers now see presence-only status ("Working through Workers") instead of the running Worker count.

## ja

ゲストが Worker を実行中のエージェントを表示する際、Worker の件数ではなく稼働中であることのみ（「Worker を通じて作業中」）を表示するようになりました。
