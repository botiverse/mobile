## zh-CN
当 Agent 所在 Computer 离线时，编辑运行时配置不再给当前运行时显示「未安装」后缀，并保持当前运行时可编辑保存；同时将 Cursor 运行时的默认显示名称由「Cursor CLI」统一更名为「Cursor」。

## en
When an agent's Computer is offline, editing its runtime config keeps the current runtime editable without appending "(not installed)"; the Cursor runtime display name is also updated from "Cursor CLI" to "Cursor".

## ja
Agent の Computer がオフラインのとき、ランタイム設定の編集で現在のランタイムに「(未インストール)」を付けず編集可能なまま維持するようにしました。あわせてランタイムの表示名を「Cursor CLI」から「Cursor」に統一しました。
