## zh-CN
服务器所有者与管理员现在可以在他人个人助理的详情页 `⋯` 菜单中通过「暂停助理」确认弹窗即时暂停该助理，并在详情页头像下方同步查看只读的暂停状态提示横幅（包含暂停人及暂停时间，仅所有者可重新启动）。

## en
Server owners and admins can now pause another member's personal assistant from the `⋯` overflow menu on its profile page via a confirmation dialog, and non-owner viewers now see the read-only paused status banner under the assistant's profile hero.

## ja
サーバーのオーナーおよび管理者は、他のメンバーのパーソナルアシスタント詳細ページの `⋯` メニューから確認ダイアログを経て「アシスタントを一時停止」できるようになりました。また、オーナー以外の閲覧者にも一時停止状態の読み取り専用バナーが表示されるようになりました。
