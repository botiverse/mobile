## zh-CN
在 Computer 详情页补齐已安装 Qwen Code 的「连接服务商（Connect provider）」卡片状态与两步配置弹窗（支持服务商分组、接入点选择或自定义 Base URL / 模型名与 API Key 配置，8 语言文案对齐网页端）；同时将未安装运行时芯片在触屏设备上的点击行为升级为底部弹窗（`RaftSheet`），桌面端继续保留悬停浮卡。

## en
Added Qwen Code "Connect provider" support on the Computer detail runtime chip, including configured/unconfigured card badges and the two-step provider setup dialog (grouped provider list, endpoint selector or custom Base URL/model fields, and API key entry across all 8 locales). Also updated uninstalled runtime chips to open a bottom sheet on touch devices while preserving the pinned hover popover on fine-pointer desktops.
