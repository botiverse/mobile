## 版本级总结

这个区间不是一个单点大功能，而是一轮密集的产品完善与稳定性收敛，主题包括：

1. **Thread 与输入器正确性**：permalink/父消息身份、task 投影、reply 路由、mention、Markdown、代码块、附件、未读锚点与消息状态同步。
2. **跨 store / process owner 收敛**：Members、已读回执、Tasks、realtime 终点、前台 reconciliation、session generation fence 和旧结果拒绝。
3. **滚动与渲染稳定性**：viewport ownership、lazy-list supply、held refresh、图片请求合并、cache/fanout 和平台重绘修复。
4. **多平台成熟度**：Android task/launcher/media，OHOS shell/render/network，iOS 通知，以及 shared 跨端编译与 runtime 门禁。
5. **产品打磨**：本地化、Settings/账号页、图标/颜色/字体、对话框、搜索筛选、成员身份和 Web 视觉对齐。
6. **发版信心**：扩充视觉 fixture、夜间 audit lens、确定性竞态测试、hosted 编译/设备门禁、签名/发布自动化和依赖溯源。

## 如何转成 Hands 更新日志

1. 只选择已随最终包交付、用户可感知的条目。
2. 同一流程的多次修复折叠成一条用户表达，不枚举内部迭代。
3. 新能力放 New，可感知的体验优化放 Improved，回归/正确性问题放 Fixed。
4. 每条文案都要与最终构建 exact 复核；本文档终点只是 source snapshot，不是发布承诺。
5. 生成语义一致的 `zh-CN.md` 和 `en.md`；排除 commit/PR 编号、CI 历史、内部架构和未在候选包上完成的验收。
