# Raft Android 1.5.0

✨ **New and improved**

- Added a quick scroll gesture: double-tap the current bottom tab or page header to return to the top of the list
- Added and expanded Simplified Chinese translations across more core screens, actions, and status messages
- Improved message forwarding, including forwarded content, target selection, and cross-channel workflows
- Improved channel and thread loading, scrolling, and long-list performance
- Improved member presence, profiles, direct-message avatars, and the first-open experience for empty direct messages
- Improved image, video, and attachment previews and downloads, including image annotation and editing before upload

🐛 **Fixes**

- Fixed an issue where scrolling down after returning to the top could repeatedly bounce back to the top
- Fixed cases where edited channel names did not save correctly
- Fixed issues affecting forwarding, empty direct messages, member presence, read state, and refresh flows
- Fixed notifications or Activity entries opening the wrong channel, server, or parent message
- Fixed additional stability, performance, input, and UI issues
