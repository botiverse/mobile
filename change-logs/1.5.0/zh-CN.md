# Raft Android 1.5.0

> 第一版更新日志草案。发布前仍需结合 Alpha smoke 结果与产品 review 定稿。

✨ **新功能**

- 新增消息转发流程：可选择目标会话，预览转发内容，并以统一样式展示转发的消息、Markdown 与附件
- 图片发送前支持标注与编辑；媒体选择器支持视频，图片工具栏与预览交互同步优化
- 附件下载后可导出到用户文件；图片与文件预览在加载过程中保留缩略图，减少空白等待
- 代码块新增常驻复制按钮，代码、邮箱与行内 Markdown 内容显示更准确
- 设置中新增管理、电脑与应用市场入口，相关页面在应用内打开

🔧 **改进**

- 优化对话流加载、回复串与长列表状态保持，减少重复刷新和返回后位置丢失
- 优化图片请求、解码与缓存：相同图片合并加载，画廊切换和失败重试更稳定，降低重复网络与卡顿
- Members 数据改为进程级共享读取，多个窗口和页面复用同一份成员列表，减少后台重复刷新
- 优化 Markdown 与 JSON 后台解析、输入建议排序和页面预热，降低滚动、输入与切换页面时的主线程压力
- Home、Activity、Thread、Tasks 与通知共享更一致的实时消息、未读、已读回执和任务状态
- 新增并扩展简体中文界面翻译，覆盖更多核心页面、操作和状态提示
- 双击当前底部标签可快速回到列表顶部；分页、下拉刷新和服务器切换的视口保持更稳定

🐛 **修复**

- 修复通知或 Activity 打开回复时跳到错误频道、错误服务器或错误父消息的问题
- 修复联合频道回复中的成员提及候选、父频道身份和通知标题不准确的问题
- 修复已读状态在多个页面或窗口间不同步、旧请求覆盖新状态，以及返回 Activity 后列表未恢复的问题
- 修复 Thread 中任务标签消失、旧任务快照遮住新状态、状态菜单锚点错位等问题
- 修复频道资料编辑不保存、创建频道名称校验缺失、反馈草稿丢失和部分设置状态未及时刷新的问题
- 修复弹窗后的点击穿透、消息长按区域过小、输入建议闪烁、附件标签和图片缩略图显示异常
- 修复 Android 首次登录、通知点击和应用链接可能创建错误任务栈或重复页面的问题
- 修复代码块、引用、Badge、图标、字体、时间戳和多处页面间距与网页端不一致的问题
