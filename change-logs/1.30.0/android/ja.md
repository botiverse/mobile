✨ **新機能**
- 「アプリの認可」と権限確認通知：「設定」の現在のサーバーグループに「アプリの認可」（ゲストを含む全メンバー向け）を追加し、アプリの認可やリンクプレビュー設定をまとめて管理できます。オーナーと管理者には確認待ちの権限更新があるときに「アプリ」へ通知ドットがリアルタイム表示され、権限更新のプッシュ通知をタップすると対象アプリの詳細へ直接移動できます。
- アプリカードのフォームと暗号化機密入力：アプリのメッセージカードのアクションボタンから、確認ダイアログ内でテキストや機密情報を直接入力できるようになりました。機密入力は既定でマスク表示（表示切替に対応）され、端末上で対象アプリ専用に暗号化してから送信されるため Raft は内容を読み取れません。未審査のサーバー独自アプリには分かりやすい注意も表示されます。
- コンピューターの「引き渡す」と削除ガード：コンピューター詳細の項目名を「接続者」に統一し（ランタイムのログイン・使用量案内も同期）、接続者やサーバーのオーナー・管理者が別のオーナー／管理者へ「引き渡す」機能を追加しました。24 時間以内の引き継ぎコマンドや名義変更、Claude・Codex のログアウト注意を確認でき、進行中の引き渡しのキャンセルや辞退も可能です。サーバー退出やメンバー削除時に紐づくコンピューターが残っている場合は影響するコンピューターとエージェント数を一覧表示し、退出前の削除画面への移動や管理者による一括切断・メンバー削除を行えます。
- 会話内のネイティブエージェント移行カードと事前チェック：会話内のエージェント移行カードからネイティブの移行ダイアログを開き、推奨コンピューターを事前選択したまま移行を開始してカードを自動完了できるようになりました。移行前に対象コンピューターのランタイム準備状態を確認し、未ログインや上限到達時は理由と「このまま移行」の選択肢を表示するほか、移行後も応答できない場合はプロフィールや移行ログに「移行済み、応答できません」と表示します。
- 新しいアプリ内アップデート体験：Google Play 版ではアプリ内アップデート（バックグラウンド取得後に「再起動してアップデート」、重要版は即時更新）に対応し、直接インストール版では従量課金でない Wi-Fi 環境での自動事前ダウンロードと「設定 › 情報」での進捗表示に対応しました。24 時間後に再通知できるアップデート案内ダイアログ（従来のバージョン永続スキップを置き換え）、ワイド画面トップバーの更新ボタン、更新完了後の「更新内容」バナーも追加しています。
- 質問カードの直接クローズと 1.5 秒間の元に戻す猶予：質問カードで質問されたメンバー（全員向けでは回答可能なメンバー）は、右上の × ボタンから回答せずに質問をクローズでき、1.5 秒間の「クローズ済み · 元に戻す」猶予のあとに確定してエージェントへ通知されます。クローズ済みカードにはクローズしたユーザーが表示され、新しいサーバーからの未知の状態も終了済みの閲覧専用として安全に表示します。
- Artifact のフォロー、ワイド分割ビューアー、「ブラウザで開く」：Artifact ホームやメッセージカードのメニューから直接フォロー／フォロー解除できるようになりました（「自分に関係あり」で解除すると「フォロー解除済み」として薄暗く残り、更新中もその場で元に戻せます）。ワイド画面では Artifact ホームからも「アクティビティ」からも右側ペインで直接開きます。ビューアーにネイティブのリンク共有と「ブラウザで開く」も備え、会話から単体表示で開いてブラウザへ移った際はビューアーを自動で閉じるため、Raft に戻るとすぐ元の会話に戻れます。

🔧 **改善**
- スマートフォンの会話ヘッダー整理：スマートフォンではチャンネル、DM、エージェントとの DM のヘッダーを「戻る・アバター・タイトル（とサブタイトル）・検索・⋯」に統一し、会話名が見切れにくくなりました。タスク、ファイル、「詳細と設定／チャンネルの詳細と設定」などの会話アクションはこの順で「⋯」メニューにまとまります。タブレットやワイド画面のレイアウトは変わりません。
- 「アクティビティ」一覧のリアルタイムインプレース更新：「アクティビティ」一覧のリアルタイム更新を Web 版に揃えました。新着メッセージやフォロー中スレッドの返信をその場で更新し、行ごとの並び順ルールで古い応答による巻き戻りを防止。不要な全件再読み込みや未読確認を減らし、バックグラウンド復帰時も変更分のみの同期で素早く最新化します。
- 外部チャンネルの共有下書き・ゲスト接続・スレッド共有：複数サーバーにまたがる外部チャンネルとそのスレッドで、個人の下書きを 1 つに共有するようになりました。片方で編集・送信・削除すると、もう一方の下書き一覧・サイドバー・アクティビティ・入力欄にも同期されます（システム共有で特定サーバー向けのものは別サーバー送信時に下書きを保持して案内を表示）。チャンネルのゲストはメンバー一覧やチャンネル詳細の「所属しているサーバーを接続」から既存サーバーの接続、依頼先管理者の確認、「サーバーを作成して接続」が可能になり、非公開チャンネルでは「チャンネル設定」内に同項目を配置。別チャンネルの既ゲストへの招待はサーバー接続招待を送ります。外部共有もスレッドへの直接共有と統一サーバー切替に対応しました。
- エージェント状態とコンピューター復旧案内の明確化：エージェントが認証エラー・使用量上限・レート制限で一時的に応答できない場合、プロフィール・DM ヘッダー・メンバー一覧・サイドバー・@メンション候補に「応答できません」と具体的な理由および再開時刻が表示され、解消後に自動で通常状態へ戻ります。キーが取り消されたコンピューターの詳細画面には「キー取り消し済み」、切断日、取り消し理由、オフラインのエージェント数、再接続や移動の復旧手順を表示し、対象エージェントのプロフィールにも同じ案内を表示します。組み込みのコンピューター最低バージョンを `1.0.53` に揃え、未満のオフライン機には npm / Homebrew の事前アンインストール注意を追加、オンラインまたは直近 7 日以内に拒否されたマシンへは通知センターで一度限りの再インストール／移行案内を表示します。
- 1 人あたり課金の Pro プランとタスク引き継ぎ表示：サーバー側で決定される 1 人あたり課金の Pro プランに対応し、プランと請求画面では席を消費しないエージェントの内訳を非表示化、アップグレード画面はサーバーから最新料金を取得し、エージェント作成時の不要な席数ブロックを解消、シート追加リクエストカードも追加不要な場合はそのまま完了できます。タスクの引き継ぎは操作者のメッセージ（アバター・表示名・引き継ぎカード付き）として表示され、「割り当て」「再び割り当て」「付け替え」が一目で分かります。
- 「エージェントに送る」の刷新と Web 版との細かな統一：「エージェントに送る」ダイアログを DM 形式へ刷新し、ヘッダーでのエージェント切替、直近 5 件の読み取り専用履歴、チャット入力欄での送信に対応しました。エージェントのアクティビティでサブエージェントの使用モデルを表示し、エージェント作成カードでは提案された非機密の環境変数を確認・編集可能（設定ディレクトリ系は警告付きで既定オフ）、Antigravity の Orchestrator モデル選択時には作業途中の返信に関するヒントを表示、外部チャンネルで相手サーバーがピン留めを無効にしている場合は理由を案内します。あわせてランタイム検出の再試行、使用量の自動確認（2 分後に「再確認」表示）、ワークスペース更新（スマホは引っ張って更新、ワイド画面は更新アイコン）、Slack チャンネル一覧の自動読み込み、退出アイコンの統一、削除済みメッセージへのリンク遷移時の静かなフォールバックも揃えました。
- タブレット・横画面のキーボード余白とワイド表示の密度：タブレット、開いた折りたたみ端末、横向きのスマートフォンでサイドバーの会話行をよりコンパクトにして 1 画面の表示件数を増やし、ワイド画面のヘッダーボタンサイズも整えました。タブレットや横向きスマートフォンでキーボードを開くとトップバーや会話ヘッダーを一時的に隠して入力スペースを確保し、横長の低い画面でキーボード上に入力欄しか収まらないときは入力欄を全幅表示します（閉じると下書きやカーソルを保ったまま元に戻ります）。ダイアログ本文・キャプション・情報を伝えるサブタイトルを通常の文字色にして読みやすくし、チャンネル詳細の操作ボタンサイズも Web 版に揃えました。
- マウス／トラックパッドのホバー表示と省電力・表示最適化：マウスやトラックパッド操作時、サイドバーの展開／折りたたみボタン、タスクヘッダーやステータスチップ、フィルターメニュー、リマインダーのリンクタグ、「作業中」リスト、ファイルツリー、Web パネルの戻るバー、リアクションなどアプリ全体でホバーと押下フィードバックを Web 版に統一し、添付ファイルのコメントパネルヘッダーも標準スタイルに揃えました。会話表示時や高頻度の状態更新時の重複リクエスト統合とリンクカードの一括反映によりレイアウトの揺れを抑え、診断トレース送信もバッチ化とバックグラウンド停止で省電力化しました。
