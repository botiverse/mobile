## zh-CN

在 Agent 会客厅与私聊会话页中，顶部头像升级为切换菜单按钮：头像角标展示当前所在侧（沙发图标表示会客厅，锁图标表示私聊），另一侧有未读时显示提醒圆点；点按头像弹出菜单可在「会客厅」与「私聊」之间就地切换（附可见范围说明与对侧未读数）或「查看资料」，并移除顶部下方的会客厅/私聊标签条。

## en

In Agent Lounge and Agent private chat headers, the agent avatar is now a switcher menu button carrying a corner mark for the active side (sofa for Lounge, lock for Private chat) and an attention dot when the other side has unread messages. Tapping the avatar opens a menu to switch in place between Lounge and Private chat (with audience descriptions and opposite-side unread counts) or open View profile, replacing the under-header tab strip.

## ja

エージェントのラウンジとプライベートチャットのヘッダーで、アバターが切り替えメニューボタンになりました。現在の会話（ラウンジはソファ、プライベートチャットは鍵）を示すコーナーバッジと、もう一方に未読があるときの通知ドットが表示され、タップすると表示範囲の説明・未読件数付きのメニューから切り替えや「プロフィールを表示」を行えます。ヘッダー下のタブバーは廃止されました。
