## zh-CN

消息发送后出现的未通知 @ 提及提示条现在会像消息正文一样显示对方的显示名，而不再只显示原始账号名；找不到对应成员或身份类型不匹配时仍回退为原始句柄。

## en

The pending mention action banner below a sent message now resolves display names from the server and channel roster so targets match how they appear in the message body, falling back to the raw handle when unknown.

## ja

メッセージ送信後に表示される未通知のメンション案内バナーでも、メッセージ本文と同じくサーバーやチャンネルのメンバー一覧から解決した表示名を使うようになり、一致しない場合のみ元のハンドルにフォールバックします。
