## zh-CN

优化应用内更新提醒的文案与交互细节：更新详情仅展示实际下载体积，不再出现增量/完整包等技术术语；重要更新弹窗自动清理更新说明中的原始 Markdown 语法，并在未下载完成时在版本栏内展示实际下载大小；首页与未登录页更新横幅在更新就绪时切换为「新版本已就绪」及「安装 / 重启以更新」操作；升级完成后的「查看更新日志」提示改为 8 秒可滑走轻提示，与桌面端保持一致。

## en

Polished in-app update prompts and copy: update details now show only the actual download size without patch/fallback/APK jargon; the important-update dialog strips raw Markdown from changelog previews and displays the actual download size alongside the version summary before download completes; Home and signed-out update banners switch to "Update ready to install" with an Install / Restart action once ready; and the post-update "What's new" notice is now a dismissible 8-second toast matching Raft Desktop.

## ja

アプリ内アップデートの案内文言と UI を改善しました。更新詳細ではパッチや APK などの技術用語を出さず実際のダウンロードサイズのみを表示し、重要アップデートダイアログでは更新内容プレビューの生の Markdown 記法を除去したうえで未ダウンロード時にサイズを併記します。ホームおよび未ログイン画面のバナーは準備完了時に「アップデートの準備ができました」と「インストール / 再起動してアップデート」に切り替わり、更新後の「更新内容」通知はデスクトップ版と同じ 8 秒間表示のスワイプ解除可能なトーストになりました。
