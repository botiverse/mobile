## zh-CN

离开服务器或移除成员时，如果对方仍关联着在线或未删除的 Computer，页面会明确列出受影响的 Computer 及 Agent 数量：离开服务器前可一键跳转到对应 Computer 页面删除，管理员移除成员时则支持一步断开这些 Computer 并移除成员；若名下仍有已交接的 Computer，离开前也会给出退出登录提醒。

## en

When leaving a server or removing a member who still has attached Computers, the confirmation dialog now lists each blocking Computer and its agent counts: leaving links straight to deleting each Computer first, while admins removing a member can disconnect those Computers and remove the member in one step; leaving with handed-over Computers also shows a non-blocking sign-out reminder.

## ja

サーバー退出やメンバー削除の際、対象メンバーが紐づけた Computer が残っている場合は影響を受ける Computer とエージェント数を一覧表示するようになりました。退出時は該当 Computer の削除画面へ直接移動でき、管理者によるメンバー削除では Computer の切断と削除を一度に実行できます。引き継ぎ済みの Computer がある場合も退出前にリマインダーが表示されます。
