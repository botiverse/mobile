## zh-CN

现在可以直接在对话中的 Agent 迁移卡片（`agent:migrate`）里打开原生迁移弹窗并预选建议计算机，启动后自动将卡片标记为已完成；同时支持目标计算机运行时预检拒绝提示与「仍然迁移」覆盖选项，以及迁移完成后 Agent 无法响应的提醒横幅和迁移日志状态徽章。

## en

You can now run agent migration action cards (`agent:migrate`) natively in-app with the suggested computer preselected and automatic card completion once the move starts. Agent migration also now handles target runtime preflight refusals with a "Move anyway" override, unverified preflight notices, and "Moved, can't respond" warnings on the agent profile and migration log.

## ja

チャット内のエージェント移行カード（`agent:migrate`）からネイティブの移行ダイアログを直接開き、推奨コンピューターを事前選択した状態で移行を開始してカードを自動完了できるようになりました。また、移行先ランタイムの事前チェック拒否と「このまま移行」による上書き、未確認時の通知、およびエージェント詳細・移行ログでの「移行済み、応答できません」表示にも対応しました。
