## zh-CN

桌面版输入框的「文件」和「添加图片」按钮现在会打开系统自带的文件选择窗口，可以一次选多个文件或图片发送（「添加图片」只列出图片）。附件的「下载」会弹出系统的存储窗口，由你选择保存位置和文件名。通过「添加图片」发送的图片和直接粘贴的截图会和手机上一样先压缩：最长边不超过 2048 像素，并按照片的拍摄方向摆正；在图片编辑页勾选「原图」则按原样发送。通过「文件」选择或从访达粘贴的文件保持原样。

## en

On desktop, the composer's Attach file and Add image buttons now open the system file picker, where you can choose several files or images at once (Add image lists images only). Download on an attachment opens the system save window so you choose where it goes and what it is called. Images sent through Add image, and pasted screenshots, are compressed as on mobile: the longest side is at most 2048 pixels and photos are turned the right way up; select Original image in the image editor to send them as they are. Files chosen with Attach file or pasted from Finder are sent unchanged.

## ja

デスクトップ版の入力欄の「ファイル」と「画像を追加」ボタンで、システムのファイル選択ウィンドウが開くようになりました。複数のファイルや画像をまとめて選べます（「画像を追加」では画像のみ表示）。添付ファイルの「ダウンロード」ではシステムの保存ウィンドウが開き、保存先とファイル名を選べます。「画像を追加」から送る画像と貼り付けたスクリーンショットは、モバイルと同じく圧縮されます。長辺は最大 2048 ピクセルになり、写真の向きも正しく直ります。画像の編集画面で「元画像」を選ぶと元のまま送信します。「ファイル」で選んだファイルや Finder から貼り付けたファイルはそのまま送信されます。
