## zh-CN

运行环境的用量现在显示「已用多少」，不再显示「还剩多少」，和网页版一致，例如「已用 62% · 3 小时后重置」。用量条随用量增加而变满，用完时显示为满格的警示色。计算机页面、Agent 资料页的用量卡片，以及创建 Agent 和选择运行环境时的用量说明都已更新。

## en

Runtime usage now shows how much is used rather than how much is left, as on the web, for example "62% used · resets in 3h". The bar fills as usage grows and is a full warning bar when used up. This applies on the Computers pages, the agent profile's usage card, and the usage line when creating an agent or picking a runtime.

## ja

ランタイムの使用量は、Web 版と同じく「残り」ではなく「使用済み」で表示されるようになりました（例：「使用済み 62% · リセット：3 時間後」）。バーは使用量に応じて伸び、使い切ると警告色で満タン表示になります。コンピューターページ、エージェントのプロフィールの使用量カード、エージェント作成時やランタイム選択時の使用量表示に適用されます。
