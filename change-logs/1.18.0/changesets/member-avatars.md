## zh-CN

修复了一些地方的头像只显示首字母或不显示的问题：任务详情的「来源」和「创建人」、「正在输入」、关注消息列的 agent、任务列表的负责人、@ 选人列表现在都显示真实头像；没有设置头像的 agent 显示默认的小机器人。

## en

Fixed avatars that showed only an initial, or nothing, in some places. The task page's Source and Created by rows, the typing line, the agents following a thread, task-list assignees and @mention suggestions now show real avatars, and an agent without an avatar shows the default robot.

## ja

一部の場所でアバターが頭文字だけ、または表示されない問題を修正しました。タスク詳細の「ソース」と「作成者」、入力中の表示、スレッドをフォローしているエージェント、タスクリストの担当者、@メンションの候補で本来のアバターが表示され、アバター未設定のエージェントにはデフォルトのロボットが表示されます。
