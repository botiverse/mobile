## zh-CN

消息菜单的快捷回应一行末尾新增「添加回应」按钮，可以打开完整的表情选择器，选任意回应。消息回应旁边的「+」现在打开快捷回应栏，不再打开整个消息菜单。

## en

The quick-reaction row in the message menu now ends with an Add Reaction button that opens the full emoji picker, so you can react with any emoji. The "+" next to a message's reactions now opens the quick reaction bar instead of the whole message menu.

## ja

メッセージメニューのクイックリアクションの行の最後に「リアクションを追加」ボタンが付き、絵文字ピッカーを開いて好きな絵文字でリアクションできるようになりました。メッセージのリアクションの横にある「+」は、メッセージメニュー全体ではなくクイックリアクションバーを開くようになりました。
