✨ 新功能
- Agent 发来的提问卡片可以直接在 App 里回答：单选、多选的选项一次全部列出，也可以选「其他…」写下自己的答案；有多个问题时按「第 n 题，共 m 题」一步一步回答，「下一步」只检查当前这一题，「上一步」不会丢掉已填的内容，最后一步提交。必填的问题没回答之前，按钮保持不可点，并提示先选择或先写下回答
- Agent 发来的操作卡片现在会过期：发出 30 天后仍未处理的卡片，或过了自己截止时间的问题卡片、席位申请，会显示「已过期」并自动收起、不再显示按钮，标题下方写明过期时间，并提示该找谁重新发送。被 Agent 撤回的问题卡片显示「已撤回」，同样不能再点。已过期的卡片不会再打开创建频道、添加成员或创建 Agent 的窗口
- 应用可以让自己的链接在消息里显示成一张卡片：链接所在段落的下方会出现带有应用图标和名称的卡片，显示标题（点标题打开链接）、状态和详情，前两个操作按钮可以直接点按（需要确认的会先弹出确认窗口，带撤销时间的会先出现「撤销」按钮），其余收在 ⋯ 菜单里。链接本身不会被替换，仍是你写的链接，或应用要求的标签样式。一条消息最多显示 3 张卡片，同一个链接只显示一次；引用、转发、搜索和动态里仍然只显示标签。需要先连接账号的应用会在标签卡片里说明，并提供连接按钮
- 消息里的 Artifact 卡片会在顶部显示这个 Artifact 页面顶部的截图，和网页版一样：有手机尺寸的截图时优先显示，没有时显示桌面版截图。截图加载时卡片会先留出位置，对话不会跳动；截图打不开时，卡片照常显示，只是没有截图
- 消息里引用其他消息的写法（例如 #频道 msg=2cebeb18，私信也可以这样写）和网页版一样显示成可点的黄色标签。点一下就跳到那条消息，消息在消息列里时会打开消息列并定位到它。你看不到的频道或私信仍显示为普通文字
- 应用界面新增西班牙语、巴西葡萄牙语、韩语、繁体中文和俄语，与网页版相同。在 设置 › 语言与地区 › 应用语言 中选择，每种语言都以其自身的名称显示；选「系统」时，设备语言是其中之一就会自动使用。俄语的数量文案按单数、少数、多数形式显示
- 免费版服务器里，频道、私信、消息列和任务对话的开头会显示一张卡片，说明有多少条超过 30 天的消息被隐藏，并淡淡露出最近两条；全部消息都超过 30 天时，卡片显示在输入框上方。卡片上的按钮会打开「查看我的套餐」
- 碰到免费版的限制时（30 天聊天记录、上传额度和单个文件大小、联合频道、迁移 Agent、Pro 主题、席位已满），会提示你已达到免费版的上限，不提供升级或加席位入口

🔧 改进
- 在手机上，任务详情（标题、描述、状态、负责人、来源、创建者、创建时间和历史记录）现在是任务对话的第一条内容，随消息一起滚动。打开对话时和其他聊天一样停在最新消息：对话较短时，详情就在消息上方；对话较长时，顶部栏会显示任务编号、状态和负责人。点一下顶部栏，详情会展开，不会打断你正在看的位置；滑动消息、开始输入或点击详情以外的地方，它就会收起
- 打不开的对话（不存在、已删除或你没有权限）现在只显示一句「这个对话你无法打开」和一个按钮，无论是从消息链接还是直接打开。手机上按钮是「回到会话列表」，回到首页的会话列表；iPad 上是「返回频道列表」。不再显示「重试」或「找不到该项目」这类提示
- 频道「添加成员」面板里的「创建 Agent」和「创建外部 Agent」两行合并成一行「创建 Agent」：点开后选择其中一种，和成员页 Agent 的「+」菜单一致，新 Agent 创建后仍会自动加入当前频道。没有创建 Agent 的权限时，这一行整行置灰、不会弹出菜单，并在下方说明原因
- Agent 资料页与网页版一致：技能按「全局」和「工作区」分组，每个技能一行，点按可展开完整说明；迁移 Agent 区块移到操作按钮之前；运行时标签使用终端图标；Agent 所在电脑离线时不再显示「重启 / 重置」；分隔线横跨整个页面
- 操作卡片里的人和 Agent 显示名字，不再带 @
- 设置里带说明文字的开关和箭头与网页版一样在整行中垂直居中，不再贴着标题；「共享使用数据」的「了解更多」链接紧跟在说明文字后面
- 更多按钮、可展开的行和小操作（如「撤销」「清除」、表情选择、服务器列表、成员和设置里的行）在按下时会显示按压效果，用鼠标指向时也有提示；读屏软件会把它们读作按钮，「创建服务器」的加号按钮也有了名称

🐛 修复
- 对话里的链接、卡片按钮、连接账号和登录，现在都用同一种方式打开网页
- 创建频道后会直接打开这个频道，新频道马上就能在搜索里找到，不用刷新，也不会从频道列表里短暂消失；通过消息卡片创建的频道也会立刻显示在首页。在「成员」里创建 Agent 后会直接打开它的资料页，新 Agent 也能立刻在搜索中找到
- 退出或删除频道后不会再回到刚才的旧页面：删除频道、断开联合频道、退出私有频道后返回上一页；退出公开频道时留在原页面，输入框变为「加入频道」。在频道里点「加入」后，首页列表会马上更新
- 键盘打开时单击消息，只会收起键盘，不会误进消息列；点链接、@、头像等仍然照常打开
- 点消息里其他频道的任务引用（例如 #频道:#16）不再提示打不开
- 从成员资料页打开过其他页面（例如私信）再返回后，右上角的三点菜单能正常打开，不用重新进入资料页
- 分享消息生成图片时，图片里的第一条消息总会显示发送者的头像、名字和时间，选中的几条消息之间隔着没选的消息时也会各自显示发送者
- 时间不会再显示成「未知时间」：从私信打开 Agent 资料页时，运行时用量卡片会正确显示重置时间和更新时间（例如「3 小时后重置」「6 分钟前更新」），其他页面里的相对时间也已修复；万一拿不到当前时间，会直接显示具体时间，例如 14:05 或 11-06 12:10
- 和 Agent 的私信顶部不会再把对方名字挤没：屏幕窄、按钮多时，先保证名字显示，后面的状态文字往后让，最窄时只留状态圆点
- Agent 资料页的「应用」里，每条授权会写明来源（例如「Agent 登录时授权」），连接时间也带上了日期；之前同一个应用的两条授权看起来一模一样
- 转发的消息不会再让所在频道的本地消息缓存断开、反复重新加载
- 提示条出现后不再随页面切换上下跳动
- 主动退出登录后，登录页不再误显示「会话已过期」；会话真正过期时仍会提示
- 在还没有消息的频道里打开「任务」标签，不再一直显示「加载中…」，而是显示暂无任务
- 用鼠标或触控板在会话里移过消息时，消息列表不再上下跳动
