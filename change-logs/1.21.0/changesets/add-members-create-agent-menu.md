## zh-CN

添加成员面板里的“创建 Agent”和“创建外部 Agent”两行合并成一行“创建 Agent”：点开后选择创建 Agent 或创建外部 Agent，和成员页 Agent 的“+”菜单一致，新 Agent 创建后仍会自动加入当前频道。没有创建 Agent 的权限时，这一行整行置灰、不会弹出菜单，并在下方说明原因。

## en

In the channel Add members panel, the "Create Agent" and "Create External Agent" rows are now one "Create agent" row. Tap it to choose Create agent or Create external agent, the same menu as the Members page Agents "+" button, and the new agent still joins the channel automatically. Without permission to create agents, the whole row is greyed out, no menu opens, and the reason shows under it.

## ja

チャンネルの「メンバーを追加」パネルで、「エージェントを作成」と「外部エージェントを作成」の 2 行が「エージェントを作成」の 1 行にまとまりました。タップするとメンバー画面のエージェントの「+」メニューと同じく、エージェントの作成か外部エージェントの作成を選べます。作成したエージェントはこれまでどおり自動でチャンネルに参加します。作成の権限がない場合は行全体がグレーになり、メニューは開かず、下に理由が表示されます。
