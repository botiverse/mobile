## zh-CN

Agent 发来的操作卡片现在会过期：卡片发出 30 天后仍未处理，或者问题卡片、席位申请过了自己的截止时间，就会显示“已过期”并自动收起，不再显示按钮，标题下方会写明过期时间，并提示你让 Agent 重新发一张。被 Agent 撤回的问题卡片会显示“已撤回”，同样不能再点。已经过期的卡片不会再打开创建频道、添加成员或创建 Agent 的窗口。

## en

Action cards from agents now expire: a card left for 30 days, or a question card or seat request past its own deadline, says Expired, folds up and shows no buttons, with a line under the title saying when it expired and to ask the agent to send a new one. A question card the agent withdrew says Withdrawn and can't be used either. An expired card no longer opens the create channel, add members or create agent windows.

## ja

エージェントから届いたアクションカードに有効期限ができました。送信から 30 日間操作されなかったカードや、期限を過ぎた質問カード・シート追加リクエストは「期限切れ」と表示されて折りたたまれ、ボタンは表示されません。タイトルの下には期限が切れた日時と、エージェントに新しいカードを送ってもらうよう案内が表示されます。エージェントが取り下げた質問カードは「取り下げ済み」と表示され、こちらも操作できません。期限切れのカードから、チャンネル作成・メンバー追加・エージェント作成の画面が開くことはなくなりました。
