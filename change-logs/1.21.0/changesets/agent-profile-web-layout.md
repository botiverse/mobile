## zh-CN

Agent 资料页与网页版保持一致：技能按「全局」和「工作区」分组，每个技能一行显示，点按可展开完整说明；迁移 Agent 区块移到操作按钮之前；运行时标签使用终端图标；Agent 所在电脑离线时不再显示「重启 / 重置」；分隔线横跨整个页面。

## en

The agent profile now matches the web: skills are grouped under Global and Workspace, one line per skill that you can tap to read its full description; the agent migration section sits before the actions; the runtime tag uses the terminal icon; Restart / reset is no longer offered while the agent's computer is offline; and section dividers span the whole page. Several English labels there now use sentence case, as on the web.
