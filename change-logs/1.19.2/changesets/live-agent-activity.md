## zh-CN

首页顶栏的铃铛旁边会显示正在工作的 agent 头像和人数，点开「工作中」可以看到每个 agent 正在做什么，点一行进入它的资料页，和网页一致。可以在 设置 › 外观 里用「实时 Agent 动态」开关关闭。

## en

The Home top bar now shows the agents that are working right now, as avatars and a count next to the bell. Tap them to open Working now and see what each agent is doing; tap a row to open that agent's profile, as on the web. You can turn this off with Live agent activity in Settings › Appearance.

## ja

ホームのトップバーのベルの横に、いま作業中の agent のアイコンと人数が表示されるようになりました。タップすると「作業中」が開き、各 agent が何をしているかを確認できます。行をタップするとその agent のプロフィールが開きます（ウェブ版と同じ）。設定 › 外観 の「エージェントのライブアクティビティ」でオフにできます。
