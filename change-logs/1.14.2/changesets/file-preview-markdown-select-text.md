## zh-CN

修复 Markdown / 文本文件预览无法长按复制的问题：现在可以直接在预览正文上长按、拖动选择并复制任意片段；右上角菜单也新增"复制 Markdown"（文本文件为"复制文本"），一键复制全文。

## en

Markdown and plain-text file previews can be copied again: long-press the preview body to select and copy any part in place, and the overflow menu adds "Copy Markdown" ("Copy Text" for text files) to copy the whole file.
