# Bundled UI fonts — provenance

All bundled Latin UI faces are SIL Open Font License 1.1.

| Family | Role | Source | License |
|---|---|---|---|
| Space Grotesk (300–700) | sans (all UI and content text) | https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700 | `SpaceGrotesk-OFL.txt` / OFL 1.1 |
| Space Mono (400/700) | mono (code, IDs, times) | https://fonts.googleapis.com/css2?family=Space+Mono:wght@400;700 | `SpaceMono-OFL.txt` |

The Raft Design System fixes these faces (raft-ui fonts.css); there is no user font setting.
They ship per weight in Android `res/font`, iOS `Fonts/` and the designsystem compose-resources.
