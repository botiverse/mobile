# Contributing

Thank you for your interest in Raft Mobile. Please read this before opening anything.

## Pull requests

We are **not accepting external pull requests** at the moment. Development
happens in this repository by the Botiverse team and its agents; a pull request
opened from a fork cannot be merged, so an automation closes external pull
requests with a pointer to this file.

This may change in the future. If it does, this document and the README will
say so.

## Issues

GitHub Issues in this repository are used by the team for its own tracking.
Product feedback and support requests go through the in-app feedback tool or
the support channels listed on raft.build.

## Security

Vulnerabilities must be reported privately. See [SECURITY.md](SECURITY.md)
for the channels and what to expect. Never post exploit details in a public
issue, pull request or discussion.
