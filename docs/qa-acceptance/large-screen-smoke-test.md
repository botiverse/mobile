# Raft 大屏发版冒烟测试清单（1.29+）

> **用途**：发版前由 QA 跑一遍的固定大屏回归冒烟清单，覆盖平板触控、宽屏键鼠、折叠屏/横竖屏与 Compose 桌面版，防止多栏布局、断点、手势与键鼠交互回归。  
> **适用范围**：1.29.0 起每次发版（切 `release/X.Y.Z` 后的候选包，或切版前 `main` 预检）。  
> **口径**：对应[Mobile Release SOP](../mobile-release-sop.md)§6.2；结果只能填 `PASS` / `FAIL` / `NOT RUN`（标明原因），不同设备席位独立记录、不互相推断。

---

## 1. 测试席位与记录表

每次发版请填写以下候选包绑定信息：

- **版本号 / Build**：`1.29.0+<short-sha>`（Android `versionCode` / iOS `CFBundleVersion` / macOS DMG）
- **测试账号与服务器**：含至少 1 个长历史频道、1 个带关注讨论串和 Artifact 的频道、1 个任务列表、1 台在线/待升级计算机
- **执行人 & 日期（UTC+8）**：

| 席位 | 目标形态 | 推荐设备 / 模拟器 | 覆盖分组 | 结论 |
| --- | --- | --- | --- | --- |
| **席位 A：平板触控（必测）** | 纯手指触控，不接键鼠 | iPad 竖/横屏（建议含 iPad mini 竖屏或 Split View）或安卓平板 / 折叠屏内屏 | 组 1–4 | `PASS / FAIL / NOT RUN` |
| **席位 B：宽屏键鼠（必测）** | 宽屏 + 鼠标/触控板/硬键盘 | iPad + 妙控键盘/触控板，或 Compose 桌面版（macOS DMG，宽窗 + 窄窗） | 组 1–6 | `PASS / FAIL / NOT RUN` |
| **席位 C：手机横屏 & 开关（抽测）** | 窄屏旋转 / 关闭桌面布局 | 常规手机横屏，或平板关闭「大屏使用桌面布局」 | 组 1（LS-02/03） | `PASS / FAIL / NOT RUN` |

## 3. 阻断口径与回归提单

- **阻断外发（P0）**：任意席位出现崩溃/卡死、白屏、切换 Tab 丢主会话、左侧列表收起后无法展开、滚轮翻页卡死、桌面 WebView 切服卡死。
- **非阻断但需记单（P1/P2）**：局部间距/对齐误差、次要文案或悬停样式偏差——报到 `#proj-mobile` 并附截图/录屏、设备型号与窗口尺寸、版本号 + build，由 Mobile DRI 决定修进本版或排下版。
- **执行节奏**：每次切版（`release/X.Y.Z`）后，与[Mobile Release SOP](../mobile-release-sop.md)§6.2 手机端冒烟并行交给 QA 执行，结果汇总贴回当期发版 Issue。
